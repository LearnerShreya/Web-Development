1. Heading Tag

The heading tags (<h1> to <h6>) define headings in HTML. The <h1> tag represents the most important heading, while <h6> is the least important. Example:

<h6>Least Important Heading</h6>

OUTPUT:
Least Important Heading

Note: HTML does not include tags beyond <h6> because six levels provide adequate structure and readability. CSS can be used to add more styles if necessary.

2. Paragraph Tag

The <p> tag defines a block of text, or a paragraph. It automatically adds spacing around the text. Example:

<p>This is a paragraph.</p>

OUTPUT:

This is a paragraph.

3. Horizontal Rule Tag

The <hr> tag inserts a horizontal line across the page, often used to separate sections. Example:

6. Elements, Tags, and Content

In HTML, an element is a part of a webpage, like a title or paragraph. Each element has:

  • Tags: Words inside angle brackets (<>) that tell the browser how to display the content. Most elements have an opening tag and a closing tag.

Example of Tags and Content

Here’s an example of an HTML element with tags and content:

  <h2>This is a heading</h2>

In this example:

  • Opening Tag: <h2>
  • Content: The text "This is a heading"
  • Closing Tag: </h2>

Explanation

Each part includes:

  • Element: The whole section, including the opening tag, content, and closing tag.
  • Tag: Tags are the words inside angle brackets, like <h2>. They often come in pairs: an opening tag (<h2>) and a closing tag (</h2>). Some, like <br>, are self-closing.
  • Content: The actual text inside the tags. In this example, "This is a heading" is the content.

Attributes

HTML tags can also have attributes to provide additional information. Attributes are written inside the opening tag and generally come as name-value pairs.

Example of an Attribute

Here’s an example of an HTML element with an attribute:

  <a href="https://example.com">Visit Example</a>

In this example:

  • Element: <a>Visit Example</a>
  • Attribute: href="https://example.com" specifies the URL the link goes to.
  • Value: "https://example.com" is the value assigned to the href attribute.

OUTPUT:

This is a heading

With attributes, you can add more details to your elements, like links, IDs, classes, etc., making HTML more functional and flexible.
