Emmet Cheat Sheet Notes

Introduction

Emmet is a toolkit that speeds up HTML and CSS coding by allowing you to type shortcuts that expand into complete tags and structures. Here’s a quick reference to get started!

Basic Syntax

Nested Elements

  • Code: li*3
    Generates three <li> elements: 
    <li></li> <li></li> <li></li>
  • Code: p>p
    Creates a nested <p> inside another: 
    <p><p></p></p>
  • Code: ul>li*3
    Generates a <ul> with three <li> items: 
    <ul><li></li><li></li><li></li></ul>
  • Code: p>nav>ul
    Creates a <p> containing a <nav> with a <ul>: 
    <p><nav><ul></ul></nav></p>

Side-by-Side Elements

  • Code: p+nav
    Creates a <p> followed by a <nav>: 
    <p></p><nav></nav>
  • Code: h1+h2+h3+h4+h5+h6
    Generates all six heading levels in sequence: 
    <h1></h1><h2></h2>...<h6></h6>

Text Content

  • Code: p{my name is shreya}
    Generates a <p> with content: 
    <p>my name is shreya</p>

Classes and IDs

  • Code: p.first
    Adds class "first" to a <p>: 
    <p class="first"></p>
  • Code: p.first{my name is}
    Adds text with class "first": 
    <p class="first">my name is</p>
  • Code: p#second
    Adds an ID "second" to a <p>: 
    <p id="second"></p>
  • Code: p#second{my name is}
    Adds text with ID "second": 
    <p id="second">my name is</p>
  • Code: header.first#second{my name is}
    Combines class "first" and ID "second" on a <header>: 
    <header class="first" id="second">my name is</header>

Conclusion

Emmet shortcuts can significantly speed up HTML and CSS coding. Practice using these expressions to become more efficient in your development workflow!
