List, Anchor, and Image

1. Lists in HTML

Lists help organize items in a structured format. HTML offers three types of lists:

  • Unordered List (<ul>)

    An unordered list displays items with bullet points. You can customize the bullet style using list-style-type.

    • disc: Solid circle (default)
    • circle: Hollow circle
    • square: Square bullets

    Example:

    <ul style="list-style-type:circle;">
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>
  • Ordered List (<ol>)

    An ordered list displays items with numbers or letters. You can set different numbering styles using the type attribute.

    • 1: Numeric (default)
    • A or a: Uppercase or lowercase letters
    • I or i: Roman numerals (uppercase or lowercase)

    Example:

    <ol type="A">
    <li>Step 1</li>
    <li>Step 2</li>
    <li>Step 3</li>
</ol>
  • Nested Lists

    You can nest lists within each other to create a multi-level structure.

    Example:

    <ul>
    <li>Main Item 1
        <ul>
            <li>Sub Item 1.1</li>
            <li>Sub Item 1.2</li>
        </ul>
    </li>
</ul>

2. Anchor Tags (<a>)

The <a> tag creates hyperlinks to link to other pages, external sites, or specific sections of the same page.

  • Basic Syntax

    To create a link, use href to define the target URL.

    Example:

    <a href="https://www.example.com">Visit Example</a>

    Result: Visit Example

  • Opening Links in a New Tab

    Use target="_blank" to open a link in a new tab.

    Example:

    <a href="https://www.example.com" target="_blank">Open in New Tab</a>

    Result: Open in New Tab

  • Anchor Links (Internal Navigation)

    Use an ID with # to link to a specific section within the same page.

    Example:

    <a href="#section">Go to Section</a>
<h2 id="section">Target Section</h2>

    Go to Section

    Target Section

3. Image Tags (<img>)

The <img> tag is used to embed images. Including alt text provides a description for users with visual impairments or if the image fails to load.

  • Basic Syntax

    To display an image, set the src attribute with the image URL and provide alt text.

    Example:

    <img src="https://example.com/image.jpg" alt="Description of image">
  • Adjusting Image Size

    You can set the height and width using height and width attributes (in pixels).

    Example:

    <img src="https://example.com/image.jpg" alt="Example Image" height="100" width="200">
  • Alt Text

    Providing alt text is essential for accessibility and SEO. It describes the content of the image.

    Example:

    <img src="https://example.com/logo.jpg" alt="Company Logo">
  • Embedding Icons and Logos

    Embedding icons and logos is a great way to link favorite resources or create a visually engaging list of go-to sites.

    Example:

    <ul class="icon-list">
    <li><a href="https://www.google.com" target="_blank">
        <img src="https://www.google.com/favicon.ico" alt="Google Icon">Google</a></li>
    <li><a href="https://www.github.com" target="_blank">
        <img src="https://github.githubassets.com/favicons/favicon.png" alt="GitHub Icon">GitHub</a></li>
    <li><a href="https://www.stackoverflow.com" target="_blank">
        <img src="https://cdn.sstatic.net/Sites/stackoverflow/Img/favicon.ico" alt="Stack Overflow Icon">Stack Overflow</a></li>
</ul>

    Result:

    • Google
    • GitHub
    • Stack Overflow
