HTML Form Attributes Used in Health Details Form

1. for

The for attribute in a <label> element associates the label with a specific input element. This improves accessibility and allows users to click on the label to focus on the input. 

<label for="fname">Full Name</label>

2. id

The id attribute uniquely identifies an element within the document. It's essential for linking labels to inputs and for CSS styling or JavaScript manipulation. 

<input type="text" id="fname">

3. name

The name attribute specifies the name of the input field. It's used to reference the form data after submission and can be used in scripts to access the input values. 

<input type="text" name="full name">

4. type

The type attribute defines the type of input element, determining what kind of data is expected. Common types include text, date, tel, email, radio, checkbox, and submit. 

<input type="date" id="dob">

5. value

The value attribute specifies the initial value of the input element. It can also define what is submitted with the form for radio and checkbox inputs. 

<option value="A+">A+</option>

6. option

The <option> element defines a single choice in a dropdown list, which is created using the <select> element. 

<select name="blood group">
        <option value="A+">A+</option>
    </select>

7. select

The <select> element creates a dropdown list. It can contain multiple <option> elements, allowing the user to choose one option. 

<select name="gender">

8. textarea

The <textarea> element defines a multi-line text input field. It's useful for capturing longer text, such as descriptions or comments. 

<textarea name="conditins"></textarea>

9. checkbox

The <input type="checkbox"> element allows the user to select one or more options. Each checkbox can be checked or unchecked independently. 

<input type="checkbox" name="pollen" id="pl">

10. radio

The <input type="radio"> element allows the user to select one option from a set. All radio buttons with the same name attribute are grouped together. 

<input type="radio" name="lenses" id="yes">

11. button

The <button> element is used to create a clickable button. It can trigger form submission or execute JavaScript functions. 

<button>Submit</button>

Summary of HTML Form Attributes

  • for: Connects labels with inputs for better accessibility.
  • id: Uniquely identifies elements for styling and scripting.
  • name: References the input data after form submission.
  • type: Defines the kind of data expected from the input.
  • value: Specifies the initial or submitted value of inputs.
  • option: Defines choices in a dropdown list.
  • select: Creates a dropdown list for user choices.
  • textarea: Multi-line text input for longer responses.
  • checkbox: Allows independent selection of multiple options.
  • radio: Groups options for single selection.
  • button: Triggers form submission or JavaScript actions.
