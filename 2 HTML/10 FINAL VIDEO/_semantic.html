Semantic HTML Tags

What are Semantic Tags?

Semantic tags clearly describe their meaning in a human- and machine-readable way. They provide structure and accessibility to web pages.

Examples of Semantic Tags

1. <header>

Defines the header section of a document or a section.

2. <nav>

Represents a section of the page intended for navigation links.

3. <main>

Specifies the main content of the document.

4. <section>

Defines a section in the document.

5. <article>

Represents an independent piece of content, like a blog post or news article.

6. <aside>

Contains content related to the main content, like sidebars.

7. <footer>

Defines the footer for a document or section.

8. <figure>

Specifies content, like an image with a caption, that is referenced in the main text.

9. <figcaption>

Provides a caption for a <figure> element.

10. <time>

Represents a specific time or date.

Note: Semantic tags enhance SEO, improve accessibility, and provide a clearer structure compared to non-semantic tags like <div> or <span>.

Non-Semantic Tags

Non-semantic tags don’t convey any specific meaning about their content. They are used for layout purposes but don’t indicate content type or structure.

  • <div>: Block element, takes the full width, starts on a new line. A generic container used to group content without adding any meaning.
    • Like a room in a house.

  • <span>: Inline element, takes only as much space as needed, stays in the same line. An inline container used to style parts of text without affecting the structure.
    • Like a label on an item.
