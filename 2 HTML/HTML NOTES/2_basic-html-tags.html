Basic HTML Tags

<html>: Root Element

The <html> tag is the root element of an HTML document. All other elements are contained within this tag.

Example:

<html>
    <head>...</head>
    <body>...</body>
</html>

<head>: Metadata Container

The <head> element contains metadata about the HTML document, such as the title, character encoding, and linked external files like stylesheets and scripts.

Example:

<head>
    <meta charset="UTF-8">
    <title>Document Title</title>
</head>

<body>: Content Container

The <body> element contains the visible content of the HTML document, such as text, images, and other media.

Example:

<body>
    <h1>Welcome</h1>
    <p>This is a paragraph of text.</p>
</body>

<title>: Title of the Document

The <title> element defines the title of the HTML document. This title is displayed on the browser's title bar or tab.

Example:

<title>My Web Page</title>

<p>: Paragraphs

The <p> element is used to define paragraphs of text.

Example:

<p>This is a paragraph.</p>

Output:

This is a paragraph.

<h1> to <h6>: Headings

The <h1> to <h6> tags are used to define headings of different levels. <h1> is the highest level, and <h6> is the lowest.

Example:

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Output:

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

<br>: Line Breaks

The <br> tag is used to insert a line break within text. It is an empty tag, meaning it doesn't have a closing counterpart.

Example:

This is a paragraph with a line break.<br>
This is the next line.

Output:

This is a paragraph with a line break.
This is the next line.

<hr>: Horizontal Rules

The <hr> tag is used to create a horizontal rule (line) that separates sections or content. It is a self-closing tag.

Example:

Section 1 content.
<hr>
Section 2 content.

Output:

Section 1 content.

Section 2 content.

<pre>: Preformatted Text

The <pre> tag is used to display preformatted text, preserving whitespace, line breaks, and indentation.

Example:

<pre>
    This is preformatted text.
    Whitespace and
    line breaks are preserved.
</pre>

Output:

    This is preformatted text.
    Whitespace and
    line breaks are preserved.
