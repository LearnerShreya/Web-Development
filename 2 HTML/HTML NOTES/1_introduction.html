Introduction to HTML

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language for creating and designing web pages.

  • HyperText: Refers to the ability to link to other pages or documents.
  • Markup Language: A system for annotating a document in a way that is syntactically distinguishable from the text.

Key Characteristics:

  • Platform Independent: Can run on any operating system with a browser.
  • Structure-Based: Focuses on structuring the content on the web.
  • Foundation for Web Development: Forms the base layer of a web page, often styled with CSS and made interactive with JavaScript.

History of HTML

HTML was invented by Tim Berners-Lee at CERN in 1989.

Key milestones in the evolution of HTML:

  • 1991: The first version was introduced as HTML Tags.
  • 1995: HTML 2.0 became the first standard version.
  • 1997: HTML 4.0 was introduced, widely used for modern web development.
  • 2014: HTML5 was released with improved multimedia support, semantic tags, and APIs.

HTML Versions (HTML5 and Earlier)

  • HTML 1.0: The original version with basic tags like <p>, <h1>.
  • HTML 2.0: Enhanced version with more functionality like forms.
  • HTML 3.2: Introduced support for tables, scripting, and improved presentation.
  • HTML 4.01: Added the ability to use stylesheets.
  • HTML5: Current version with modern features:
    • Semantic elements: <header>, <footer>, <article>, <section>.
    • Multimedia support: <audio>, <video>.
    • APIs: Canvas, Geolocation, Web Storage.

HTML Syntax and Structure

HTML documents are made up of elements enclosed in tags. Tags typically come in pairs (e.g., <p> and </p>).

Basic Syntax Example:

    <tagname attribute="value">Content</tagname>
  • Tags can have attributes to define additional information.
  • HTML is not case-sensitive (e.g., <html> is the same as <HTML>).
  • Comments can be added using <!-- comment -->.

Basic Anatomy of an HTML Document

An HTML document consists of the following components:

  • Document Type Declaration: Declares the document type and version of HTML. Syntax: <!DOCTYPE html>.
  • Root Element: <html> wraps all HTML content.
  • Head Section: <head> contains metadata like title, character encoding, and linked resources.
  • Body Section: <body> contains all visible content.

Example:

    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>My First HTML Page</title>
    </head>
    <body>
        <h1>Welcome to HTML</h1>
        <p>This is a basic HTML document.</p>
    </body>
    </html>

HTML Editors and Tools

Some tools for writing HTML:

  • Text Editors: Notepad, TextEdit, Visual Studio Code.
  • Online Editors: CodePen, JSFiddle, Replit.
  • IDEs: IntelliJ IDEA, WebStorm.

How Browsers Render HTML

  • Parsing: Browsers read the HTML file and convert it into a DOM tree.
  • Rendering: Styles (CSS) are applied, and JavaScript is executed.
  • Interaction: Users interact with the rendered page, triggering JavaScript events.

Popular browsers include Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari.
