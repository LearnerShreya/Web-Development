HTML Text Formatting Tags

Learn the usage of common HTML text formatting tags with examples.

1. Text Formatting Tags

<b>: Bold Text

The tag is used to display text in bold. It is typically used for strong emphasis.

Usage: Use for text that needs to stand out for emphasis.

Example:

<p>This is a <b>bold</b> text.</p>

Output:

This is a bold text.

<i>: Italic Text

The tag is used to display text in italics. It is typically used for emphasis or to indicate special meaning.

Usage: Use for text that needs to be emphasized or styled differently.

Example:

<p>This is an <i>italic</i> text.</p>

Output:

This is an italic text.

<u>: Underlined Text

The tag is used to underline text, typically for highlighting or marking important information.

Usage: Use for text that needs to be underlined for emphasis.

Example:

<p>This is an <u>underlined</u> text.</p>

Output:

This is an underlined text.

3. Text Markup Tags

<code>: Inline Code

The tag is used to represent inline code snippets or programming commands.

Usage: Use to highlight code or technical terms within text.

Example:

<p>Use the <code>print()</code> function in Python.</p>

Output:

Use the print() function in Python.

<kbd>: Keyboard Input

The tag is used to represent keyboard input. It is used when showing how to input commands or keys from a keyboard.

Usage: Use when showing keyboard inputs or user interactions.

Example:

<p>Press <kbd>Ctrl</kbd> + <kbd>S</kbd> to save the document.</p>

Output:

Press Ctrl + S to save the document.

4. Quotation and Citation

<blockquote>: Block Quotation

The

tag is used to define a block quotation, usually from an external source. It indents the quoted text and typically includes a citation.

Usage: Use

to highlight lengthy quotations or citations from other sources.

Example:

<blockquote>This is a famous quote from Albert Einstein.</blockquote>

Output:

This is a famous quote from Albert Einstein.

<q>: Inline Quotation

The tag is used for short inline quotations. Unlike the

tag, it is used for quoting a few words or a short phrase.

Usage: Use for brief quotes inside a paragraph or sentence.

Example:

<p>Albert Einstein said, <q>Imagination is more important than knowledge.</q></p>

Output:

Albert Einstein said, Imagination is more important than knowledge.

<cite>: Citation

The tag is used to define the citation of a source, typically in academic or professional contexts. It is usually displayed in italics and should be used in combination with other tags like

and to provide references.

Usage: Use when citing an external source or reference.

Example:

<p>This quote is cited from <cite>Albert Einstein's works</cite>.</p>

Output:

This quote is cited from Albert Einstein's works.

5. Marking and Highlighting

<mark>: Highlighted Text

The tag is used to highlight text, typically for emphasis or to indicate a search term. The highlighted text is rendered with a yellow background by default, but you can customize the style using CSS.

Usage: Use to highlight key information, search terms, or critical content.

Example:

<p>Find the <mark>highlighted</mark> text in this paragraph.</p>

Output:

Find the highlighted text in this paragraph.
