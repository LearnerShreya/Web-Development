In-depth Notes on HTML Media

Comprehensive guide to HTML media elements, including images, audio, video, embedding external content, APIs, and best practices.

1. Introduction to HTML Media

HTML media refers to elements used to display multimedia content like images, audio, and video directly within a webpage. Key elements include:

  • <img> for images
  • <audio> for audio
  • <video> for videos
  • <embed> and <iframe> for external content

2. HTML Media Elements

2.1 <img>: Embedding Images

The <img> tag is used to embed images.

Attributes:

  • src: Specifies the URL of the image.
  • alt: Provides alternative text if the image cannot load.
  • width and height: Define dimensions.
  • loading: Lazy-loads images (lazy, eager).

Best Practices:

  • Use optimized formats (e.g., WebP, JPEG, PNG).
  • Include the alt attribute for accessibility.
  • Implement lazy loading for faster page loads.

2.2 <audio>: Embedding Audio

The <audio> tag allows audio playback.

Attributes:

  • src: URL of the audio file.
  • controls: Adds play, pause, and volume controls.
  • autoplay: Automatically plays the audio.
  • loop: Repeats the audio.
  • muted: Mutes the audio.
  • preload: Loading behavior (none, metadata, auto).

Supported Formats:

  • MP3
  • OGG
  • WAV

Best Practices:

  • Provide multiple formats for compatibility.
  • Use fallback text for unsupported browsers.

2.3 <video>: Embedding Videos

The <video> tag allows video playback.

Attributes:

  • src: URL of the video file.
  • controls: Adds play, pause, and volume controls.
  • autoplay: Automatically plays the video.
  • loop: Repeats the video.
  • muted: Mutes the video.
  • poster: Specifies an image before playback starts.
  • preload: Loading behavior (none, metadata, auto).

3. HTML Media API

Programmatically control audio and video using JavaScript.

Methods:

  • play(): Starts playback.
  • pause(): Pauses playback.
  • load(): Reloads the media element.

Properties:

  • currentTime: Get/set current playback time.
  • volume: Get/set volume.
  • muted: Get/set mute state.
  • duration: Duration of the media.
  • paused: Indicates if playback is paused.
