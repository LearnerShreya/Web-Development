How Images are Stored in Binary

In digital storage, images are represented by a collection of pixels, each storing color information as binary data. Here’s a simple breakdown of how this works and why it matters.

1. Pixels: The Basic Unit of Images

An image is made up of small dots called pixels. Each pixel holds color information in the form of binary numbers.

Example:

Imagine a 2x2 pixel image:

Pixel (1,1): 11111111 00000000 00000000 (Red)

Pixel (1,2): 00000000 11111111 00000000 (Green)

Pixel (2,1): 00000000 00000000 11111111 (Blue)

Pixel (2,2): 11111111 11111111 11111111 (White)

2. Color Depth: Defining Color Detail

Color depth is the number of bits used to store color for each pixel. Common depths include:

  • 8-bit (Grayscale): Uses 1 byte per pixel, with 256 possible shades.
  • 24-bit (True Color): Uses 3 bytes (1 for Red, 1 for Green, 1 for Blue), allowing 16.7 million colors.
  • 32-bit (RGBA): Adds an extra 8 bits for transparency, storing data in 4 bytes per pixel.

Example:

A pixel in 24-bit color depth for red would be:

11111111 00000000 00000000 (Red in RGB)

3. Resolution and File Size

Resolution is the number of pixels in an image, described by width x height (e.g., 1920x1080). Resolution and color depth determine the file size:

  • A higher resolution (more pixels) increases file size.
  • A higher color depth (more bits per pixel) also increases file size.

Example:

A 100x100 image with 24-bit color depth would require:

100 x 100 x 3 bytes = 30,000 bytes (30 KB)

4. Image Compression Formats

Different formats use different ways of compressing image data:

  • JPEG: Uses lossy compression, reducing file size by discarding some detail.
  • PNG: Uses lossless compression, preserving all pixel data.
  • BMP: Stores pixel data directly without compression, leading to larger file sizes.

5. Putting It All Together

Here’s an example of how a small image might look in binary:

Example:

In a 2x2 RGB image, each pixel uses 3 bytes (24 bits) of binary data:

Pixel (1,1): 11111111 00000000 00000000 (Red)
Pixel (1,2): 00000000 11111111 00000000 (Green)
Pixel (2,1): 00000000 00000000 11111111 (Blue)
Pixel (2,2): 11111111 11111111 11111111 (White)

Summary

  • Images are stored in binary, with each pixel’s color represented by binary values.
  • Color depth affects both color detail and file size.
  • Resolution and color depth together determine file size.
  • Formats like JPEG, PNG, and BMP balance quality and file size differently.
