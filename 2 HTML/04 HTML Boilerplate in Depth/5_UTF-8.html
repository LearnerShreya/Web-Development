UTF-8 Character Encoding

  • 1-byte character:
    • First bit: 0
    • Representation: 0xxxxxxx
    • Example: The binary value for "A" (65 in decimal) is represented as 01000001, where the first bit is 0.
  • 2-byte character:
    • First two bits: 11
    • Representation: 110xxxxx 10xxxxxx
    • Example: The binary representation of the character "é" is 11000011 10101001, where the first byte starts with 11.
  • 3-byte character:
    • First three bits: 111
    • Representation: 1110xxxx 10xxxxxx 10xxxxxx
    • Example: The Hindi letter "अ" (U+0905) is encoded as E0 A4 85, which in binary is 11100000 10100100 10000101.
  • 4-byte character:
    • First four bits: 1111
    • Representation: 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx
    • Example: An emoji or rare symbol would have a representation starting with 1111.

UTF-8 Byte Structure

  • 1-byte character (for ASCII characters like English letters):
    • Starts with 0xxxxxxx, where x is the actual data (7 bits for ASCII).
    • Example: The letter "A" (65 in decimal) is represented as 01000001 in binary.
  • 2-byte character:
    • Starts with 110xxxxx 10xxxxxx (the first 5 bits in the first byte and the 6 bits in the second byte contain the actual data).
    • Example: The character "é" (Latin letter with an accent) is represented by two bytes: 11000011 10101001 in binary.
  • 3-byte character (for characters like Hindi letters):
    • Starts with 1110xxxx 10xxxxxx 10xxxxxx (the first 4 bits in the first byte, 6 bits in the second byte, and 6 bits in the third byte contain the actual data).
    • Example: The Hindi letter "अ" (U+0905) is represented by three bytes: E0 A4 85 in hexadecimal or 11100000 10100100 10000101 in binary.
  • 4-byte character (for emojis or rare symbols):
    • Starts with 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx.
