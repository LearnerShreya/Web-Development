CSS animations allow you to add life to your web elements, making them move, scale, rotate, and more. Below are detailed notes on animation properties with examples and their implementation.

@keyframes

The @keyframes rule defines the steps of an animation. You can specify styles for various percentages (or points) of the animation timeline.

Syntax:


@keyframes animationName {
    0%   { /* Initial State */ }
    50%  { /* Midpoint State */ }
    100% { /* Final State */ }
}

animation-name

Defines the name of the @keyframes to apply to an element.

Example:


.animation-box {
    animation-name: moveExample;
}

animation-duration

Specifies the length of time for one cycle of the animation.

Example:


.animation-box {
    animation-duration: 3s;
}

animation-timing-function

Sets the speed curve of the animation (e.g., ease, linear, ease-in, etc.).

Example:


.animation-box {
    animation-timing-function: ease-in-out;
}

animation-iteration-count

Defines how many times the animation runs. You can use infinite for continuous playback.

Example:


.animation-box {
    animation-iteration-count: infinite;
}

animation-direction

Specifies the direction of the animation (e.g., normal, reverse, alternate, etc.).

Example:


.animation-box {
    animation-direction: alternate;
}
