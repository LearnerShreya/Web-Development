CSS Animation Properties

A Complete Guide with Examples

Transparent Textures

@keyframes

Definition: The @keyframes rule defines intermediate steps for an animation.

Syntax:


@keyframes slideIn {
    0%   { transform: translateX(-100%); opacity: 0; } /* Start */
    50%  { transform: translateX(-50%); opacity: 0.5; } /* Midpoint */
    100% { transform: translateX(0); opacity: 1; } /* End */
}

Visual Example:

This text slides in from the left.

animation-name

Definition: Specifies the name of the @keyframes animation.

Example:


.element {
    animation-name: slideIn;
}

animation-duration

Definition: Specifies how long the animation runs.

Example:


.element {
    animation-duration: 3s; /* 3 seconds */
}

animation-delay

Definition: Specifies the time to wait before the animation starts.

Example:


.element {
    animation-delay: 2s; /* Waits 2 seconds before starting */
}

animation-iteration-count

Definition: Specifies the number of times the animation should repeat.

Values:

  • 1: Runs once (default).
  • infinite: Repeats indefinitely.
  • n: Repeats n times.

Example:


.element {
    animation-iteration-count: infinite;
}

animation-timing-function

Definition: Specifies how the animation progresses over time.

Values:

  • linear: Uniform speed throughout the animation.
  • ease: Starts slow, accelerates, then slows down.
  • ease-in: Starts slow and speeds up.
  • ease-out: Starts fast and slows down.
  • ease-in-out: Starts slow, speeds up, then slows down.
  • cubic-bezier(): Custom timing curve.

Example:


.element {
    animation-timing-function: ease-in-out;
}

Visual Example:

This text eases in and out smoothly.

animation-direction

Definition: Specifies whether the animation plays forward, backward, or alternates.

Values:

  • normal: Plays forward (default).
  • reverse: Plays backward.
  • alternate: Alternates forward and backward.
  • alternate-reverse: Alternates backward and forward.

Example:


.element {
    animation-direction: alternate;
}

animation-fill-mode

Definition: Specifies how styles are applied before/after the animation.

Values:

  • none: Default. No styles applied outside the animation.
  • forwards: Retains the final keyframe styles.
  • backwards: Applies the first keyframe styles before the animation starts.
  • both: Applies both forwards and backwards styles.

Example:


.element {
    animation-fill-mode: forwards;
}

animation (Shorthand)

Definition: A shorthand for all animation properties.

Syntax:


animation: name duration timing-function delay iteration-count direction fill-mode;

Example:


.element {
    animation: slideIn 3s ease-in 1s infinite alternate forwards;
}
