Projects

Text-to-ISL Translator:

This innovative project was developed as a prototype solution for the Smart India Hackathon, aiming to bridge the communication gap between hearing individuals and the deaf community. The system provides real-time translation of textual content into Indian Sign Language (ISL), making it an invaluable tool for promoting inclusivity and accessibility. Designed with a robust tech stack that includes Python, Machine Learning algorithms, OpenCV for gesture recognition, and Flask for web-based functionality, the project ensures precise and fluid translations. This prototype not only supports accurate sign language rendering but also emphasizes user-friendly interaction with an intuitive interface. Its implementation addresses significant social challenges by empowering the deaf community in India, paving the way for broader communication accessibility and fostering inclusivity in education, workplaces, and day-to-day interactions.

Interactive Solar System:

This project is a highly engaging and visually immersive representation of the solar system, offering users an interactive way to explore celestial bodies. It features animated planetary orbits, with each planet moving dynamically around the Sun. A tooltip system adds an educational layer by displaying detailed information about the Sun, planets, and Earth's Moon when hovered over. With a responsive design that ensures a smooth and consistent experience across all devices, this project serves as an excellent tool for learning astronomy in an interactive and captivating manner. Developed using a tech stack comprising HTML, CSS, and JavaScript, it showcases the seamless integration of aesthetics and functionality. The use of CSS animations brings life to the planets’ movements, while JavaScript powers the dynamic tooltip interactivity, making it a perfect blend of design and technology for astronomy enthusiasts of all ages.
