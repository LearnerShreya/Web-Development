Projects

Real-Time Text-to-Indian Sign Language (ISL) Translatior

This project is a prototype solution developed for the Smart India Hackathon (SIH) that translates textual language into Indian Sign Language (ISL) in real time and vice versa. The system is designed with a robust backend for seamless ISL translation, integrated with a web interface for accessibility. This initiative aims to improve communication and accessibility for the deaf community in India, with plans to evolve the prototype into a full-scale solution.
