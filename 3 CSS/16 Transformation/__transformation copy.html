Interactive Guide to CSS 2D and 3D Transformations

This guide demonstrates various CSS transformations with interactive examples. Hover over each box to see the transformation effect in action.

1. translate() Transformation

Description: translate() moves an element along the X and/or Y axes. It’s useful for adjusting an element’s position without affecting its surrounding elements.

Hover effect: Moves 50px right and 20px down.

Translate 
/* Moves element 50px right and 20px down on hover */
.box {
    transition: transform 0.5s;
}
.box:hover {
    transform: translate(50px, 20px);
}
Note:
  • Single value in translate() affects the X-axis only.
  • Double values affect X-axis (horizontal) and Y-axis (vertical) respectively.
  • Positive X-axis values move the element to the right; negative values move it to the left.
  • Positive Y-axis values move the element down; negative values move it up.

2. scale() Transformation

Description: scale() resizes an element. It can scale the element proportionally or independently along X and Y axes.

Hover effect: Enlarges to 1.5 times its original size.

Scale 
/* Scales the element to 1.5 times its size on hover */
.box:hover {
    transform: scale(1.5);
}
Note:
  • With one value, scale() applies the scaling factor uniformly to both X and Y axes.
  • With two values, the first value scales the X-axis, and the second value scales the Y-axis.
  • A value of 1 maintains the original size; values less than 1 shrink the element.

3. rotate() Transformation

Description: rotate() rotates an element clockwise by a specified degree.

Hover effect: Rotates 45 degrees clockwise.

Rotate 
/* Rotates the element 45 degrees clockwise on hover */
.box:hover {
    transform: rotate(45deg);
}
Note:
  • Positive degree values rotate the element clockwise.
  • Negative degree values rotate the element counter-clockwise.

4. skew() Transformation

Description: skew() tilts an element along the X or Y axis, creating a slanted shape.

Hover effect: Skews the box by 20 degrees along the X-axis.

Skew 
/* Skews the element by 20 degrees along the X-axis on hover */
.box:hover {
    transform: skewX(20deg);
}
Note:
  • skewX() tilts the element horizontally, while skewY() tilts it vertically.
  • Positive values tilt in the specified axis's direction; negative values tilt the opposite way.

5. Chaining Transformations

Description: Multiple transformations can be combined in a single transform property. They’re applied in the sequence they appear. You can chain different transformations like translate(), scale(), and rotate() to create complex effects.

Hover effect: Combines translate, rotate, and scale transformations.

Chain 
/* Combines translate, rotate, and scale on hover */
    .box:hover {
        transform: translate(20px, 10px) rotate(45deg) scale(1.2);
    }

Note: Chaining transformations allows you to apply multiple transformations to an element in one go. They will be applied in the order they are written. The transformations are combined without resetting each other.

6. transform-origin Property

Description: The transform-origin property specifies the point of origin for transformations. By default, it is set to the center of the element, but you can adjust it to change how the transformation behaves.

Hover effect: Changes the origin of rotation to the bottom-right corner.

Origin 
/* Changes the rotation origin to the bottom-right corner */
.box:hover {
    transform-origin: bottom right;
    transform: rotate(45deg);
}
Note:
  • transform-origin can accept values like top left, center, bottom right, and specific length or percentage values.
  • It determines the pivot point around which the transformations such as rotation, scaling, and skewing occur.

7. 3D Transformations

Description: 3D transformations allow you to move, rotate, scale, and transform elements in three-dimensional space. This introduces the concept of depth, giving the illusion that elements are placed in a 3D environment.

Note: To achieve a 3D effect, you'll need to apply a perspective property on the container of the 3D elements. This defines the distance from the viewer's eye to the element, which creates the depth.

RotateY 
/* Apply rotation along the Y-axis in 3D space */
.box:hover {
    transform: rotateY(45deg);
}
Note:
  • rotateX() rotates the element around the X-axis (horizontal axis).
  • rotateY() rotates the element around the Y-axis (vertical axis).
  • rotateZ() rotates the element around the Z-axis (perpendicular to the screen).
  • 3D transformations require a 3D context, which is established by setting perspective on a parent element.
3D Move 
/* Apply 3D rotation along the X-axis and translation along the Z-axis */
.box:hover {
    transform: rotateX(30deg) translateZ(50px);
}
Note:
  • translateZ() moves the element along the Z-axis, away from or towards the viewer.
  • Combining rotateX(), rotateY(), and translateZ() creates advanced 3D effects.
