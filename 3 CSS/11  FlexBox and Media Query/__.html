Media Queries in CSS

Introduction to Media Queries

Media queries are used to apply different CSS styles based on the device's characteristics, such as its screen size, resolution, orientation, and more. This technique is essential for creating responsive designs, ensuring your website or application looks good on various devices, including mobile, tablet, and desktop screens.

Syntax of a Media Query

The basic syntax for a media query is as follows:

@media (media-feature: value) {
  /* CSS styles go here */
}

Example Media Query for Screen Width

Here's a common example of a media query that applies different background colors to a box depending on the screen width:

/* Change background color for screens wider than 768px */
@media (min-width: 768px) {
  .responsive-box {
    background-color: #b0c4de;
  }
}

/* Change background color for screens wider than 1024px */
@media (min-width: 1024px) {
  .responsive-box {
    background-color: #8fbc8f;
  }
}

Media Features in Media Queries

Here are some common media features used in media queries:

  • min-width and max-width: Apply styles based on minimum or maximum width of the viewport.
  • min-height and max-height: Apply styles based on minimum or maximum height of the viewport.
  • orientation: Apply styles based on device orientation, either landscape or portrait.
  • resolution: Target specific screen resolutions, often used for high-definition screens.

Conclusion

Media queries are essential for responsive web design. They allow you to adapt your layout and style depending on the device's capabilities, ensuring a consistent and optimized user experience across all devices.
