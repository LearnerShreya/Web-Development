Media Queries: A Complete Guide

What Are Media Queries?

Media queries are CSS techniques that allow you to apply different styles to elements based on specific conditions like screen size, device orientation, or resolution. Media queries help create responsive web designs that adapt to various devices.

Basic Syntax of Media Queries

The general syntax for a media query is:

@media media-type and (media-feature: condition) {
    /* CSS rules go here */
}

Example: @media screen and (max-width: 600px) { /* styles */ }

1. Media Types

The media type specifies the category of device the styles should apply to. The common media types include:

  • screen: for screens like desktops, tablets, and mobile devices.
  • print: for printed documents.
  • all: for all devices.

2. Media Features

Media features define the conditions that must be met for the styles to apply. These include:

Width and Height

Media queries can target the width and height of the viewport.

@media screen and (max-width: 768px) {
    /* Styles for screens smaller than 768px */
}

@media screen and (min-width: 1024px) {
    /* Styles for screens larger than 1024px */
}

Aspect Ratio

Specifies the ratio of the viewport's width to height.

@media screen and (aspect-ratio: 16/9) {
    /* Styles for 16:9 screen ratio */
}

Orientation

Determines if the device is in portrait or landscape mode.

@media screen and (orientation: portrait) {
    /* Styles for portrait mode */
}

Mobile-First vs. Desktop-First Approaches

Media queries can be implemented using either a Mobile-First or Desktop-First approach.

Mobile-First Approach

In this approach, styles are initially designed for smaller screens, and media queries are added to style larger screens. Typically, min-width is used to scale up the design.

/* Mobile-First Example */
@media screen and (min-width: 600px) {
    /* Styles for larger screens */
}

Desktop-First Approach

In this approach, styles are initially designed for larger screens, and media queries are added for smaller screens. This approach often uses max-width to adjust for smaller screens.

/* Desktop-First Example */
@media screen and (max-width: 600px) {
    /* Styles for smaller screens */
}

Combining Multiple Conditions

You can combine multiple conditions in a media query using and, not, and only operators.

/* Combining multiple conditions */
@media screen and (min-width: 768px) and (orientation: landscape) {
    /* Styles for landscape mode on screens larger than 768px */
}

Advanced Features

Resolution

The resolution feature applies styles based on the display's pixel density.

@media screen and (min-resolution: 300dpi) {
    /* Styles for high-resolution displays */
}

Prefers Color Scheme

Targets users who prefer light or dark themes.

@media (prefers-color-scheme: dark) {
    /* Styles for dark mode */
}

Conclusion

Media queries provide a powerful way to create responsive designs by adapting the layout and styling based on device characteristics. Using the right approach and media features, you can ensure a seamless experience across various devices.
