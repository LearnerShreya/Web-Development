Media Queries

Media Queries Overview

Media queries are used to apply different CSS styles based on device characteristics like screen size, orientation, or resolution. The syntax follows:

@media media-type and (condition) { /* CSS styles go here */ }

Media Types

  • screen: Targets screen devices like desktops, tablets, and phones.
  • print: Targets print media for printers.
  • all: Targets all device types.

Common Media Features

  • Width and Height: Sets styles based on the width and height of the viewport.
  • aspect-ratio: Specifies the ratio of the width to the height of the viewport (e.g., @media screen and (aspect-ratio: 16/9)).
  • orientation: Targets the orientation of the device, either portrait or landscape (e.g., @media screen and (orientation: portrait)).

Mobile-First vs. Desktop-First Approaches

A Mobile-First approach starts with styling for small screens and progressively adds styles for larger screens. This approach typically uses min-width in media queries.

A Desktop-First approach starts with styling for larger screens and then adjusts for smaller screens. This approach often uses max-width in media queries.

/* Mobile-First Example */
@media screen and (min-width: 600px) { /* Styles for larger screens */ }

/* Desktop-First Example */
@media screen and (max-width: 600px) { /* Styles for smaller screens */ }

Conclusion

Media queries and flexbox work together to create responsive, flexible layouts that adapt to various devices and screen sizes, enhancing user experience.
