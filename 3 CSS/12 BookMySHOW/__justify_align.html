Difference Between justify-content: center; and align-items: center;

The justify-content and align-items properties are used in CSS Flexbox and Grid layouts for aligning items, but each aligns elements along a different axis:

1. justify-content: center;

  • Aligns items horizontally along the main axis.
  • By default, the main axis is horizontal (left to right) when flex-direction is row.
  • Setting justify-content: center; centers items horizontally in the container.

2. align-items: center;

  • Aligns items vertically along the cross axis, which is perpendicular to the main axis.
  • When flex-direction is row, the cross axis is vertical (top to bottom).
  • Setting align-items: center; centers items vertically in the container.

Example in a Flexbox Container

In the following example, items are centered both horizontally and vertically within the container using justify-content: center; and align-items: center; together:

Item 1
Item 2

.container {
    display: flex;
    justify-content: center; /* Centers items horizontally */
    align-items: center;     /* Centers items vertically */
    height: 200px;
    border: 1px solid black;
}
.item {
    width: 50px;
    height: 50px;
    background-color: lightblue;
    text-align: center;
    line-height: 50px;
}

Visual Summary

  • Horizontal Alignment (justify-content): Centers items along the main axis (left to right).
  • Vertical Alignment (align-items): Centers items along the cross axis (top to bottom).

Combining justify-content: center; and align-items: center; centers items both horizontally and vertically in a flex container.
