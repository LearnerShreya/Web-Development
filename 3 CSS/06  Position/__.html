CSS Positioning Explained

1. Static Position

Static is the default positioning method. Elements with position: static; are placed in the normal flow of the document. You cannot apply top, left, right, or bottom properties to elements with static positioning.

This is a static positioned box.

Code:

.static-box {
    position: static;
    background-color: steelblue;
}

2. Relative Position

A relative positioned element is positioned relative to its normal position in the document. You can use the top, left, right, and bottom properties to move it from where it would normally be. The space for the element is still preserved in the layout.

This is a relative positioned box.

Code:

.relative-box {
    position: relative;
    top: 20px;
    left: 30px;
    background-color: darkorange;
}

3. Absolute Position

An absolute positioned element is removed from the normal document flow and is positioned relative to the nearest positioned ancestor (with position: relative;, absolute;, or fixed;). If there is no positioned ancestor, it will be positioned relative to the document body (viewport).

This is an absolute positioned box.

Code:

.absolute-box-container {
    position: relative;
    width: 300px;
    height: 150px;
    background-color: lightgray;
}

.absolute-box {
    position: absolute;
    top: 20px;
    left: 20px;
    background-color: darkred;
}

4. Fixed Position

A fixed positioned element is removed from the document flow and positioned relative to the browser window. It will remain fixed in place even when the page is scrolled. This is often used for elements like sticky headers or floating buttons.

This is a fixed positioned box.

Code:

.fixed-box {
    position: fixed;
    top: 20px;
    right: 20px;
    background-color: darkgreen;
}

5. Sticky Position

A sticky positioned element behaves like a relative element until a certain point is reached, after which it becomes "fixed" and stays visible on the screen while scrolling. It is useful for elements that should stick to the top of the viewport when scrolling, like sticky navigation bars.

This is a sticky positioned box.

Scroll down to see the sticky effect in action. This box will stick to the top of the viewport when you scroll.

Code:

.sticky-box {
    position: sticky;
    top: 0;
    background-color: purple;
}
