CSS Positioning: Simple Explanations

1. Why is Padding Used Instead of Margin?

Padding is used inside an element, between the content and its border. It pushes the content away from the edges of the element, making the content look more spacious.

Margin, on the other hand, is used outside an element, creating space between the element and other elements. Padding is generally used when you want to create space inside the element (e.g., inside a box or a button), while margin is used to create space outside the element (e.g., space between two boxes or elements).

In the context of the header in the example, padding was used to keep the content away from the edges of the container, while margin would have created space outside the header element.

2. Which Position Types Leave Their Original Position?

In CSS, the following position types determine whether the element will "leave" its original position in the document flow:

  • Static Positioning: This is the default. The element stays in the normal flow of the document and does not "leave" its place. Everything follows it naturally.
  • Relative Positioning: This element "leaves" its original position, but only in relation to where it was originally. It still takes up space in the document, so it doesn't affect the layout of surrounding elements.
  • Absolute Positioning: This element is completely removed from the document flow. It "leaves" the normal flow and is positioned relative to its nearest positioned ancestor. If there is no such ancestor, it is positioned relative to the entire document (viewport).
  • Fixed Positioning: This also removes the element from the document flow. The element stays fixed in place on the screen (relative to the viewport), no matter how you scroll the page.
  • Sticky Positioning: This behaves like relative positioning until a certain scroll point is reached, after which it behaves like a fixed position. The element "leaves" its relative position at the scroll point, sticking to the top or bottom of the screen.

So, the elements that "leave" their original positions are those using absolute, fixed, and sticky positioning. They are removed from the normal document flow and positioned based on the viewport or a positioned ancestor.

CSS Positioning: Key Points

Padding vs. Margin

  • Padding: Inside the element, adds space between content and the element's edges.
  • Margin: Outside the element, adds space between the element and others.

Position Types

  • Static: Does not leave its original position (default behavior).
  • Relative: Moves relative to its original position but still takes up space.
  • Absolute: Completely removed from the normal flow, positioned relative to an ancestor.
  • Fixed: Stays fixed relative to the viewport, even when scrolling.
  • Sticky: Acts like relative until a scroll point, then behaves like fixed.
