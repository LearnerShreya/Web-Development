Notes on CSS Properties and Units

1. Display Property

The display property controls the layout of an element. Different values:

  • inline: The element does not start on a new line and takes up only as much width as needed.
  • block: The element starts on a new line and takes up the full width available.
  • inline-block: Behaves like inline but allows setting width and height.

2. Background Color

The background-color property sets the background color of an element. Example:

background-color: orange;

3. Width and Height Properties

These properties define the width and height of an element. They can use various units, including:

  • px (Pixels): A fixed unit representing screen pixels.
  • vw (Viewport Width): 1vw is 1% of the viewport’s width.
  • vh (Viewport Height): 1vh is 1% of the viewport’s height.
  • rem (Root EM): Relative to the root element’s font size.
  • em (EM): Relative to the font size of the element itself.
  • % (Percentage): Relative to the size of the parent element.

Examples:

width: 25vw;
height: 40vh;

4. Margin Property

The margin property controls the space outside an element. It can be applied to specific sides:

  • margin-left, margin-right, margin-top, margin-bottom

Setting margin: auto; horizontally centers an element.

margin: 10px;
margin-left: auto;

5. Border Properties

The border property defines the border of an element:

  • border-radius: Rounds the corners of an element. Example: border-radius: 100vh;
  • border: Defines the width, style, and color. Example: border: 100px solid red; (commented out in the code)

6. Universal Selector (*)

The universal selector * applies styles to all elements in the document. It’s useful for applying a global reset, such as:

* {
    margin: 0;
}

Units Used in Width and Height Properties

  • px: Fixed pixels, used for specific and fixed layouts.
  • vw: Viewport width, dynamic based on the viewport’s width. 1vw is 1% of the viewport width.
  • vh: Viewport height, dynamic based on the viewport’s height. 1vh is 1% of the viewport height.
  • rem: Root EM, relative to the root element’s font size, ideal for scalable layouts.
  • em: Relative to the element's font size, useful for proportional layouts.
  • %: Percentage, relative to the size of the parent element, allowing flexible layouts.

Summary

This document covers the basic CSS properties used for layout and styling:

  • Display properties like inline, block, and inline-block to control element layout.
  • Background-color to set the background color.
  • Width and Height properties with units such as px, vw, vh, rem, em, and %.
  • Margin properties to manage spacing outside an element.
  • Border properties to add borders and rounded corners.
  • The universal selector * for global styling.
