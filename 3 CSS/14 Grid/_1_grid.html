CSS Grid In-Depth Guide

CSS Grid is a powerful layout system that allows for creating complex, responsive layouts with ease. It provides a two-dimensional approach, meaning it can handle both rows and columns simultaneously. Let's go through each main concept in CSS Grid.

1. Setting Up a Grid Container

To start using CSS Grid, set the display property to grid on a container element. This turns the container into a grid layout.

Item 1
Item 2
Item 3

.container {
  display: grid;
}

Setting display: grid; alone doesn’t define any specific layout, so items stack in one column by default.

2. Defining Columns and Rows with grid-template-columns and grid-template-rows

Define the columns and rows by specifying grid-template-columns and grid-template-rows properties.

Item 1
Item 2
Item 3

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 equal columns */
  grid-template-rows: 100px 200px;    /* 2 rows with different heights */
}

This creates a grid with three equal-width columns and two rows of differing heights.

3. Using repeat() for Simplification

The repeat() function makes it easy to define repeated columns or rows.

Item 1
Item 2
Item 3

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 equal columns */
}

The code above is a shortcut for creating 3 equal columns. You can also use repeat() for complex patterns.

4. Adding Gaps Between Grid Items

The gap property adds space between rows and columns without needing to add margins to each grid item.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px; /* Adds 10px space between items */
}

5. Spanning Columns and Rows

To make an item span across multiple columns or rows, use the grid-column and grid-row properties.

Item 2
Item 3
Item 4 (Spans 2 Columns)

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 100px 100px;
}

.item1 {
  grid-column: 1 / 3; /* Spans across two columns */
}

.item4 {
  grid-row: 2 / 3;
  grid-column: 2 / 4; /* Spans across two columns */
}

In this example, "Item 1" spans two columns, and "Item 4" spans two columns in the second row.

6. Naming Grid Areas with grid-template-areas

Named areas can make layouts more intuitive. Define areas using grid-template-areas and assign items to those areas with grid-area.

.container {
  display: grid;
  grid-template-areas:
    'header header header'
    'sidebar content content'
    'footer footer footer';
  grid-template-columns: 1fr 2fr 2fr;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer { grid-area: footer; }

This layout makes use of defined areas, making the structure easier to understand.

7. Responsive Grids with auto-fit and auto-fill

To create a responsive grid, use repeat() with auto-fit or auto-fill in combination with minmax() to adjust columns based on available space.

  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 10px;
}

In this example, the grid adjusts the number of columns to fit the available space, making it responsive.

CSS Grid: auto-fit, auto-fill, and place-items

Learn how to use auto-fit, auto-fill, and place-items in CSS Grid to create flexible and well-aligned layouts. These properties make it easy to control the size, fit, and alignment of grid items within a responsive design.

1. auto-fit

auto-fit adjusts the layout by collapsing empty columns, making items expand to fill the available space. This creates flexible, responsive columns without gaps.

Item 1
Item 2
Item 3
Item 4

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 10px;
}

2. auto-fill

auto-fill fills the grid with as many columns as possible, even if they remain empty. This can result in extra empty spaces if there are fewer items than columns.

Item 1
Item 2
Item 3
Item 4

.container {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 10px;
}

3. place-items for Alignment

The place-items property is a shorthand that sets both align-items (vertical) and justify-items (horizontal) alignment in a single line, making it easy to position items within each grid cell.

Syntax: place-items: align justify;

Example: place-items: end center; positions items at the bottom (end) vertically and centers them horizontally in each cell.

Aligned Item 1
Aligned Item 2
Aligned Item 3

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  place-items: end center; /* Aligns items to the end vertically and centers horizontally */
  gap: 10px;
}

Possible values for place-items include:

  • place-items: start; - Aligns items to the top-left of each cell.
  • place-items: center; - Centers items vertically and horizontally.
  • place-items: stretch; - Stretches items to fill each cell fully.

Summary

  • auto-fit: Expands items to fill available space, collapsing empty columns to prevent gaps.
  • auto-fill: Fills available width by adding columns, even if they remain empty.
  • place-items: A shorthand for setting vertical and horizontal alignment within each grid cell.

Conclusion

CSS Grid provides a flexible and powerful way to create complex layouts. Experiment with these properties to understand how they work together!
