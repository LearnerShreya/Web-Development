Notes on padding in CSS

The padding property in CSS is used to define the space between the content of an element and its border. It is an important part of the box model.

Syntax

padding: top right bottom left;

Values are specified in a clockwise order:

  • Top: Padding at the top.
  • Right: Padding on the right.
  • Bottom: Padding at the bottom.
  • Left: Padding on the left.

Shorthand Examples

Here are some common shorthand examples:

  • padding: 20px; — Applies 20px padding to all four sides.
  • padding: 10px 15px; — 10px to top and bottom, 15px to left and right.
  • padding: 5px 10px 15px; — 5px to top, 10px to left and right, 15px to bottom.
  • padding: 5px 10px 15px 20px; — 5px to top, 10px to right, 15px to bottom, 20px to left.
    • +-------------------------+
|         (top)           |
|         (5px)           |
|                         |
|  (left)        (right)  |
|   (20px)       (10px)   |
|                         |
|       (bottom)          |
|        (20px)           |
+-------------------------+

Important Notes

  • The padding values can be specified in units like px, em, rem, percentages, or other valid CSS units.
  • Padding is different from margin, which is the space outside the element's border.
  • Padding affects the size of an element, as it increases the space within the border.
