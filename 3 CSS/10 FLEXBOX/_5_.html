Flexbox Comprehensive Guide

Flexbox, short for Flexible Box Layout, is a powerful CSS module designed to create flexible and efficient layouts. It provides an easy and clean way to arrange, align, and distribute space among items within a container, even when their size is unknown or dynamic. This guide will walk you through the core concepts and properties of Flexbox, enabling you to build responsive and adaptable web designs.

Core Concepts

Main Axis

Definition: The primary axis along which flex items are laid out.

Default Direction: Horizontal (left to right).

Influence: Controlled by the flex-direction property.

Cross Axis

Definition: The axis perpendicular to the main axis.

Default Direction: Vertical (top to bottom).

Influence: Determines how items are aligned vertically when the main axis is horizontal.

1. Flex-Direction

The flex-direction property defines the direction of the main axis, determining how flex items are placed within the flex container.

1.1 Row (Default)

Description: Items align horizontally from left to right.

.container { display: flex; flex-direction: row; }

1.2 Row-Reverse

Description: Items align horizontally from right to left.

.container { display: flex; flex-direction: row-reverse; }

1.3 Column

Description: Items align vertically from top to bottom.

.container { display: flex; flex-direction: column; }

1.4 Column-Reverse

Description: Items align vertically from bottom to top.

.container { display: flex; flex-direction: column-reverse; }

2. Justify-Content

The justify-content property aligns flex items along the main axis. It controls the distribution of space between and around items.

2.1 Flex-Start

.container { display: flex; justify-content: flex-start; }

2.2 Flex-End

.container { display: flex; justify-content: flex-end; }

2.3 Center

.container { display: flex; justify-content: center; }

2.4 Space-Between

.container { display: flex; justify-content: space-between; }

2.5 Space-Around

.container { display: flex; justify-content: space-around; }

2.6 Space-Evenly

.container { display: flex; justify-content: space-evenly; }

3. Align-Items

The align-items property aligns flex items along the cross axis. It controls the default alignment for all items within the container.

3.1 Flex-Start

.container { display: flex; align-items: flex-start; }

3.2 Flex-End

.container { display: flex; align-items: flex-end; }

3.3 Center

.container { display: flex; align-items: center; }

3.4 Stretch (Default)

.container { display: flex; align-items: stretch; }

3.5 Baseline

.container { display: flex; align-items: baseline; }

4. Flex-Wrap

4.1 Nowrap (Default)

.container { display: flex; flex-wrap: nowrap; }

4.2 Wrap

.container { display: flex; flex-wrap: wrap; }

4.3 Wrap-Reverse

.container { display: flex; flex-wrap: wrap-reverse; }
