Detailed Flexbox Guide

1. Flex Direction

The flex-direction property sets the direction of the main axis along which the flex items are placed.

1.1 Row

flex-direction: row; arranges items from left to right (default direction).

Code Example:

.container { display: flex; flex-direction: row; }

Visual Example:

1
2
3
Key Note: This is the default direction and works well for most layouts that need horizontal alignment.
Use Case: Use row for horizontal layouts like navigation menus or rows of items.

1.2 Row-Reverse

flex-direction: row-reverse; arranges items from right to left.

Code Example:

.container { display: flex; flex-direction: row-reverse; }

Visual Example:

1
2
3
Key Note: Reverses the item order visually but does not change the document flow order.
Use Case: row-reverse is useful for RTL (right-to-left) layouts or when needing reverse order for animation effects.

1.3 Column

flex-direction: column; arranges items from top to bottom.

Code Example:

.container { display: flex; flex-direction: column; }

Visual Example:

1
2
3
Key Note: Aligns items vertically, useful for stacked item layouts.
Use Case: column is commonly used in mobile layouts or sidebars.

1.4 Column-Reverse

flex-direction: column-reverse; arranges items from bottom to top.

Code Example:

.container { display: flex; flex-direction: column-reverse; }

Visual Example:

1
2
3
Key Note: Like column, but reverses the visual order.
Use Case: Use column-reverse for animations where items appear from the bottom up.

2. Justify Content

The justify-content property aligns flex items along the main axis.

2.1 Flex-Start

justify-content: flex-start; aligns items at the start of the container (default).

Code Example:

.container { display: flex; justify-content: flex-start; }

Visual Example:

1
2
3
Key Note: flex-start is the default and aligns items to the left in a row.
Use Case: Common for lists or aligning items to the start.

2.2 Flex-End

justify-content: flex-end; aligns items at the end of the container.

Code Example:

.container { display: flex; justify-content: flex-end; }

Visual Example:

1
2
3
Key Note: Aligns items to the right (or bottom for column).
Use Case: Useful for alignment to the end in navigation bars or action bars.

2.3 Center

justify-content: center; centers items along the main axis.

Code Example:

.container { display: flex; justify-content: center; }

Visual Example:

1
2
3
Key Note: Centers all items in a row or column.
Use Case: Useful for balanced layouts where items need equal space around them.

2.4 Space-Between

justify-content: space-between; spaces items evenly, with the first item at the start and last at the end.

Code Example:

.container { display: flex; justify-content: space-between; }

Visual Example:

1
2
3
Key Note: Creates even spacing between items, no gaps on edges.
Use Case: Ideal for headers and footers where items need separation.

2.5 Space-Around

justify-content: space-around; spaces items with equal gaps on all sides.

Code Example:

.container { display: flex; justify-content: space-around; }

Key Note: Adds equal spacing on either side, creating a balanced look.
Use Case: Useful for multiple centered elements with even spacing.
