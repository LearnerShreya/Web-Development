CSS Flexbox Guide

Introduction to Flexbox

Flexbox, short for Flexible Box Layout, is a layout model in CSS designed to distribute and align items within a container efficiently, even when their sizes are dynamic or unknown. This guide provides an in-depth look into Flexbox properties, demonstrating their use with examples.

Core Concepts of Flexbox

Main Axis

The primary axis along which flex items are aligned. The direction of the main axis is determined by the flex-direction property.

Cross Axis

The perpendicular axis to the main axis. Alignment along the cross axis is controlled by properties like align-items.

1. Flex-Direction

The flex-direction property specifies the direction of the main axis, affecting how flex items are laid out within the flex container.

Row (Default)

Items are laid out horizontally from left to right.

.container { display: flex; flex-direction: row; }

Row-Reverse

Items are laid out horizontally from right to left.

.container { display: flex; flex-direction: row-reverse; }

Column

Items are laid out vertically from top to bottom.

.container { display: flex; flex-direction: column; }

Column-Reverse

Items are laid out vertically from bottom to top.

.container { display: flex; flex-direction: column-reverse; }

2. Justify-Content

The justify-content property aligns flex items along the main axis. This property is useful for distributing space between items.

Flex-Start

.container { display: flex; justify-content: flex-start; }

Flex-End

.container { display: flex; justify-content: flex-end; }

Center

.container { display: flex; justify-content: center; }

Space-Between

.container { display: flex; justify-content: space-between; }

Space-Around

.container { display: flex; justify-content: space-around; }

Space-Evenly

.container { display: flex; justify-content: space-evenly; }

3. Align-Items

The align-items property aligns flex items along the cross axis, determining how items are positioned vertically within a row or horizontally within a column.

Flex-Start

.container { display: flex; align-items: flex-start; }

Flex-End

.container { display: flex; align-items: flex-end; }

Center

.container { display: flex; align-items: center; }

Stretch (Default)

.container { display: flex; align-items: stretch; }

Baseline

.container { display: flex; align-items: baseline; }

4. Flex-Wrap

The flex-wrap property controls whether flex items should wrap onto multiple lines within the container.

Nowrap (Default)

.container { display: flex; flex-wrap: nowrap; }

Wrap

.container { display: flex; flex-wrap: wrap; }

Wrap-Reverse

.container { display: flex; flex-wrap: wrap-reverse; }

5. Align-Content

The align-content property aligns rows of flex items along the cross axis when there is extra space.

Flex-Start

.container { display: flex; flex-wrap: wrap; align-content: flex-start; }

Flex-End

.container { display: flex; flex-wrap: wrap; align-content: flex-end; }

Center

.container { display: flex; flex-wrap: wrap; align-content: center; }

Space-Between

.container { display: flex; flex-wrap: wrap; align-content: space-between; }

Space-Around

.container { display: flex; flex-wrap: wrap; align-content: space-around; }

Space-Evenly

.container { display: flex; flex-wrap: wrap; align-content: space-evenly; }

6. Flex Items

6.1 Flex-Grow

.box { flex-grow: 1; }

6.2 Flex-Shrink

.box { flex-shrink: 1; }

6.3 Flex-Basis

.box { flex-basis: 100px; }

6.4 Align-Self

.box { align-self: center; }

Conclusion

Mastering Flexbox provides a solid foundation for building adaptable, responsive web designs. With this guide, you now have the tools to experiment with Flexbox in your projects. Flexbox's versatility ensures it remains a fundamental part of modern web design and development.
