Flexbox Guide

Important Note: Flexbox enables a layout with one main axis (horizontal by default) and a cross axis (vertical by default).

1. Flex-Direction

The flex-direction property defines the direction of the main axis.

1.1 Row (default)

Items align horizontally from left to right.

.container { display: flex; flex-direction: row; }
1
2
3
Key Note:

This is the default layout direction.

Use Case: Standard horizontal layouts.

1.2 Row-Reverse

Items align horizontally from right to left.

.container { display: flex; flex-direction: row-reverse; }
1
2
3
Key Note:

Reverses the direction of items in the row.

Use Case: Used in RTL languages or right-aligned layouts.

1.3 Column

Items align vertically from top to bottom.

.container { display: flex; flex-direction: column; }
1
2
3
Key Note:

Changes the main axis to vertical.

Use Case: Useful for vertical navigation or item stacking.

1.4 Column-Reverse

Items align vertically from bottom to top.

.container { display: flex; flex-direction: column-reverse; }
1
2
3
Key Note:

Reverses the direction of items in the column.

Use Case: Suitable for items that need to appear in reverse order.

2. Justify-Content

Aligns flex items along the main axis.

2.1 Flex-Start

Items align to the start of the container.

.container { justify-content: flex-start; }
1
2
3
Key Note:

This is the default alignment setting.

Use Case: Good for left-aligned layouts.

2.2 Flex-End

Items align to the end of the container.

.container { justify-content: flex-end; }
1
2
3
Key Note:

Aligns items to the end.

Use Case: Useful for right-aligned layouts.

2.3 Center

Centers items along the main axis.

.container { justify-content: center; }

3
Key Note:

Centers items horizontally or vertically based on flex-direction.

Use Case: Useful for centered headers, footers, or content blocks.

2.4 Space-Between

Key Note:
