Comprehensive Flexbox Notes

Main Axis & Cross Axis

The main axis is the primary direction along which flex items are placed (horizontal by default). The cross axis is perpendicular to the main axis (vertical by default).

Key Note: The orientation of the main axis is controlled by flex-direction. By default, the main axis is horizontal.

1. flex-direction

The flex-direction property defines the direction of the main axis.

  • row: Default; items align horizontally from left to right.
  • row-reverse: Items align horizontally from right to left.
  • column: Items align vertically from top to bottom.
  • column-reverse: Items align vertically from bottom to top.

Example:

.container { display: flex; flex-direction: row; }

Important Note: Using row-reverse or column-reverse changes the visual order but does not affect the document flow.

2. justify-content

The justify-content property aligns flex items along the main axis.

  • flex-start: Items align to the start of the container.
  • flex-end: Items align to the end of the container.
  • center: Items are centered along the main axis.
  • space-between: Equal space between items with no space at edges.
  • space-around: Equal space around each item.
  • space-evenly: Equal space between and around items.

Example:

.container { display: flex; justify-content: space-around; }

Key Note: justify-content controls the distribution of free space on the main axis.

3. align-items

The align-items property aligns flex items along the cross axis.

  • flex-start: Aligns items to the start of the cross axis.
  • flex-end: Aligns items to the end of the cross axis.
  • center: Centers items along the cross axis.
  • stretch: Stretches items to fill the container along the cross axis (default).
  • baseline: Aligns items based on their text baseline.

Example:

.container { display: flex; align-items: center; }

4. flex-wrap

The flex-wrap property controls whether flex items should wrap onto multiple lines within the container.

  • nowrap: All items stay on a single line (default).
  • wrap: Items wrap onto multiple lines from top to bottom.
  • wrap-reverse: Items wrap onto multiple lines from bottom to top.

Example:

.container { display: flex; flex-wrap: wrap; }
Key Note: wrap is essential for responsive designs to avoid content overflow.

5. Flex Item Properties

order

The order property sets the visual order of flex items within the container. By default, items have order: 0.

flex-grow

The flex-grow property specifies how much a flex item should grow relative to others when there is extra space.

flex-shrink

The flex-shrink property specifies how much a flex item should shrink relative to others when there is not enough space.

flex-basis

The flex-basis property defines the initial size of a flex item before it grows or shrinks.

align-self

The align-self property allows individual flex items to override the align-items value.

Example:

.box { flex-grow: 1; flex-shrink: 1; flex-basis: 100px; }
