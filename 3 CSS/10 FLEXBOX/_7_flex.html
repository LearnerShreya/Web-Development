CSS Flexbox Guide

Introduction to Flexbox

Flexbox (short for Flexible Box Layout) is a powerful CSS layout model that simplifies the arrangement of elements on a webpage, making them responsive and adaptable to different screen sizes. This guide provides an overview of Flexbox properties with practical examples.

Core Concepts of Flexbox

Main Axis

The main axis is the primary direction of alignment in a Flexbox layout. Its direction is controlled by the flex-direction property.

Cross Axis

The cross axis is perpendicular to the main axis and determines how items align across the secondary direction. The align-items property aligns items along this axis.

1. Flex-Direction

The flex-direction property determines the direction of the main axis in a flex container. It can be set to four different values:

Row (Default)

Items are arranged in a horizontal row, left to right.

.container { display: flex; flex-direction: row; }

Row-Reverse

Items are arranged in a horizontal row, right to left.

.container { display: flex; flex-direction: row-reverse; }

Column

Items are arranged in a vertical column, top to bottom.

.container { display: flex; flex-direction: column; }

Column-Reverse

Items are arranged in a vertical column, bottom to top.

.container { display: flex; flex-direction: column-reverse; }

2. Justify-Content

The justify-content property aligns flex items along the main axis.

Flex-Start

.container { display: flex; justify-content: flex-start; }

Flex-End

.container { display: flex; justify-content: flex-end; }

Center

.container { display: flex; justify-content: center; }

Space-Between

.container { display: flex; justify-content: space-between; }

Space-Around

.container { display: flex; justify-content: space-around; }

Space-Evenly

.container { display: flex; justify-content: space-evenly; }

3. Align-Items

The align-items property aligns flex items along the cross axis.

Flex-Start

.container { display: flex; align-items: flex-start; }

Flex-End

.container { display: flex; align-items: flex-end; }

Center

.container { display: flex; align-items: center; }

Stretch (Default)

.container { display: flex; align-items: stretch; }

Baseline

.container { display: flex; align-items: baseline; }

4. Flex-Wrap

The flex-wrap property determines if flex items should wrap onto multiple lines within the container.

Nowrap (Default)

.container { display: flex; flex-wrap: nowrap; }

Wrap

.container { display: flex; flex-wrap: wrap; }

Wrap-Reverse

.container { display: flex; flex-wrap: wrap-reverse; }

5. Align-Content

The align-content property aligns rows of flex items along the cross axis when there is extra space in the container.

Flex-Start

.container { display: flex; flex-wrap: wrap; align-content: flex-start; }

Flex-End

.container { display: flex; flex-wrap: wrap; align-content: flex-end; }

Center

.container { display: flex; flex-wrap: wrap; align-content: center; }

Space-Between

.container { display: flex; flex-wrap: wrap; align-content: space-between; }

Space-Around

.container { display: flex; flex-wrap: wrap; align-content: space-around; }

Space-Evenly

.container { display: flex; flex-wrap: wrap; align-content: space-evenly; }

6. Flex Items

6.1 Flex-Grow

.box { flex-grow: 1; }

6.2 Flex-Shrink

.box { flex-shrink: 1; }

6.3 Flex-Basis

.box { flex-basis: 100px; }

6.4 Align-Self

.box { align-self: center; }

Conclusion

Mastering Flexbox provides a solid foundation for creating responsive web layouts. This guide introduces you to the key properties that make Flexbox powerful and versatile in modern web design.
