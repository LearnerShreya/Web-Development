Flexbox Comprehensive Notes

Main Axis & Cross Axis

The main axis is the primary axis along which flex items are placed (horizontal by default), while the cross axis is perpendicular to the main axis (vertical by default).

1. flex-direction

The flex-direction property determines the direction of the main axis:

  • row: Default; items align horizontally from left to right.
  • row-reverse: Items align horizontally from right to left.
  • column: Items align vertically from top to bottom.
  • column-reverse: Items align vertically from bottom to top.

Example:

.container { display: flex; flex-direction: row; }

Key Notes:

Use row for typical horizontal layouts and column for vertical stacking.

2. justify-content

The justify-content property aligns items along the main axis:

  • flex-start: Items align to the start of the container.
  • flex-end: Items align to the end of the container.
  • center: Items are centered along the main axis.
  • space-between: Equal space between items, no space at edges.
  • space-around: Equal space around items.
  • space-evenly: Equal space between and around items.

Example:

.container { display: flex; justify-content: space-around; }

Key Notes:

Important: Use justify-content based on how you want space distributed along the main axis.

3. align-items

The align-items property aligns items along the cross axis:

  • flex-start: Aligns items to the start of the cross axis.
  • flex-end: Aligns items to the end of the cross axis.
  • center: Centers items along the cross axis.
  • stretch: Stretches items to fill container along the cross axis (default).
  • baseline: Aligns items based on their text baseline.

4. flex-wrap

The flex-wrap property controls item wrapping:

  • nowrap: Items stay on a single line (default).
  • wrap: Items wrap onto multiple lines from top to bottom.
  • wrap-reverse: Items wrap onto multiple lines from bottom to top.

5. align-content

Controls how multiple rows are aligned within a container:

  • flex-start, flex-end, center, space-between, space-around, space-evenly

6. Flex Item Properties

order

Controls the visual order of flex items. order: 0; is default.

flex-grow

Defines how much a flex item grows relative to others when extra space is available.

flex-shrink

Defines how much a flex item shrinks relative to others when space is limited.

flex-basis

Sets the initial size of an item before growth or shrinkage.

align-self

Overrides align-items for individual flex items.

Summary

Flexbox is a powerful layout model for creating responsive layouts with ease. Understanding properties like flex-direction, justify-content, and align-items allows you to control layout direction, alignment, and distribution of space within the container.
