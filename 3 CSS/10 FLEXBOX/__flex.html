Flexbox Comprehensive Guide

Flexbox is a one-dimensional layout system in CSS that makes it easy to design flexible and responsive layouts, either horizontally or vertically.

Flexible Box Layout, is a powerful CSS module designed to create flexible and efficient layouts. It provides an easy and clean way to arrange, align, and distribute space among items within a container, even when their size is unknown or dynamic. This guide will walk you through the core concepts and properties of Flexbox, enabling you to build responsive and adaptable web designs.

Key Concepts

  • Flex Container: The element that holds the flex items.
  • Flex Items: The children of the flex container that will be laid out using flexbox.
  • Flex Direction: Defines the direction of the flex items (row, column, row-reverse, column-reverse).
  • Justify Content: Controls the alignment of items along the main axis.
  • Align Items: Controls the alignment of items along the cross axis.
  • Align Self: Allows individual flex items to be aligned differently from the rest.

Common Properties

  • display: flex; Makes the container a flex container.
  • flex-direction: row; Aligns the items in a row.
  • justify-content: center; Centers the items along the main axis.
  • align-items: center; Centers the items along the cross axis.
  • flex-wrap: wrap; Allows the items to wrap onto multiple lines if needed.
  • flex-grow: Defines the ability for an item to grow relative to the others.

Why Use Flexbox?

Flexbox makes it easier to design flexible and responsive layouts without relying on floats or positioning. It helps avoid many common layout issues and simplifies complex designs.

Note: Flexbox works best when you need a layout that adapts to various screen sizes and content types.

1. Core Concepts

Flex Item

Flexbox (Flexible Box) is a layout model that provides an easy and clean way to arrange items within a container. It works by distributing space along a one-dimensional axis, either horizontally or vertically.

  • Flex Container: The parent element that holds all the flex items. You make an element a flex container by setting its display property to flex.
  • Flex Items: The child elements within the flex container. These elements will be arranged and sized according to flexbox properties.
  • Main Axis: The primary axis along which flex items are aligned. The direction can be horizontal (row) or vertical (column) depending on the flex container's direction.
  • Cross Axis: The axis perpendicular to the main axis. If the main axis is horizontal, the cross axis is vertical and vice versa.

1.1. Main Axis

The main axis is the primary axis along which flex items are placed. It is determined by the flex-direction property. The main axis can be horizontal (row) or vertical (column).

The main axis is the primary axis along which flex items are placed. It depends on the flex container's flex-direction property:

8. Summary

Flexbox is a powerful layout system in CSS that allows us to create complex layouts with minimal code. The core concepts of Flexbox revolve around the flex container and the flex items inside it. The flex container acts as a parent that controls the layout of its children, or flex items. Below is a summary of key concepts and properties in Flexbox that help manage layout structure and alignment.

Core Concepts

The Flexbox layout model is based on two main axes: the Main Axis and the Cross Axis.

  • Main Axis: The axis along which flex items are placed (can be horizontal or vertical, depending on the flex-direction property).
  • Cross Axis: The axis perpendicular to the main axis, used to align items along the opposite direction.

Flex-Direction

The flex-direction property defines the direction in which the flex items are arranged within the flex container.

  • Row (Default): Flex items are arranged horizontally from left to right.
  • Row-Reverse: Flex items are arranged horizontally from right to left.
  • Column: Flex items are arranged vertically from top to bottom.
  • Column-Reverse: Flex items are arranged vertically from bottom to top.

Justify-Content

The justify-content property aligns the flex items along the main axis. It defines the distribution of space between and around the items within the container.

  • Flex-Start: Items are aligned at the start of the container.
  • Flex-End: Items are aligned at the end of the container.
  • Center: Items are centered within the container.
  • Space-Between: Items are spaced evenly with the first item at the start and the last item at the end.
  • Space-Around: Items are spaced evenly with equal space around each item.
  • Space-Evenly: Items are spaced evenly with equal space between them and on the ends.

Align-Items

The align-items property aligns the flex items along the cross axis. It defines how items are positioned vertically (for a row direction) or horizontally (for a column direction).

  • Flex-Start: Items are aligned to the start of the cross axis.
  • Flex-End: Items are aligned to the end of the cross axis.
  • Center: Items are centered along the cross axis.
  • Stretch (Default): Items stretch to fill the container along the cross axis.
  • Baseline: Items are aligned to the baseline of the container.

Flex-Wrap

The flex-wrap property controls whether the flex items should wrap onto the next line if there is not enough space.

  • Nowrap (Default): Items do not wrap and stay on a single line.
  • Wrap: Items wrap onto the next line when needed.
  • Wrap-Reverse: Items wrap onto the next line in the opposite direction.

Align-Content

The align-content property is used when there is extra space along the cross axis. It defines how the lines of flex items are distributed in the container.

  • Flex-Start: Lines are packed to the start of the container.
  • Flex-End: Lines are packed to the end of the container.
  • Center: Lines are centered within the container.
  • Space-Between: Lines are spaced evenly with the first line at the start and the last line at the end.
  • Space-Around: Lines are spaced evenly with equal space around each line.
  • Space-Evenly: Lines are spaced evenly with equal space between them and on the ends.

Flex Items

The flex items inside a flex container are controlled with several properties that allow individual items to behave differently from others:

  • Order: Controls the order in which flex items appear in the container. By default, all items have the same order value (0).
  • Flex-Grow: Determines how much a flex item will grow relative to other items. If all items have a value of 1, they will grow equally to fill the space.
  • Flex-Shrink: Determines how much a flex item will shrink if there is not enough space in the container. Items with a value of 0 will not shrink.
  • Flex-Basis: Defines the initial size of a flex item before space is distributed. It can be set in pixels, percentages, or other units.
  • Align-Self: Allows individual items to override the align-items setting, controlling their alignment along the cross axis.

By combining these properties, Flexbox allows us to create flexible, responsive layouts that can adjust to different screen sizes and content amounts.

flex: [flex-grow] [flex-shrink] [flex-basis];

Flexbox is a layout module in CSS that allows elements within a container to be aligned and distributed based on defined properties. A common way to define flexbox properties is with the flex shorthand:
flex: [flex-grow] [flex-shrink] [flex-basis];

.flex-item {
  flex: 1 1 200px;
}
