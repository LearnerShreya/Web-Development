CSS Transitions: Comprehensive Guide

1. Transition Property

The transition-property specifies which CSS property to animate. Only animatable properties like background-color, width, opacity, and transform can be transitioned. You can specify multiple properties, separated by commas.

Example: Transition on background-color only

Hover Me

.property-example {
    background-color: royalblue;
    transition-property: background-color;
    transition-duration: 2s;
}
.property-example:hover {
    background-color: tomato;
}

Using all as the Property

To apply a transition to all animatable properties, use transition-property: all;:

Hover Me

.transition-all {
    background-color: darkorchid;
    transition: all 2s ease-in-out;
}
.transition-all:hover {
    width: 250px;
    background-color: mediumseagreen;
    transform: rotate(15deg);
}

2. Transition Duration

The transition-duration defines how long the transition should take to complete, specified in seconds (s) or milliseconds (ms).

Example: Duration of 1 second vs. 3 seconds

Hover Me (1s)
Hover Me (3s)

.duration-1s {
    background-color: darkseagreen;
    transition-duration: 1s;
}
.duration-3s {
    background-color: darkseagreen;
    transition-duration: 3s;
}
.duration-1s:hover, .duration-3s:hover {
    width: 300px;
}

Notice the different speeds of the transitions on hover.

3. Transition Timing Function

The transition-timing-function controls the speed of the transition over its duration. Common values include:

  • linear: Constant speed throughout.
  • ease: Starts slow, speeds up, then slows down.
  • ease-in: Slow start, speeding up towards the end.
  • ease-out: Fast start, slowing towards the end.
  • ease-in-out: Slow start and end, faster middle.

Example: Linear vs. Ease Timing Functions

Hover Me (linear)
Hover Me (ease)

.linear {
    background-color: coral;
    transition-timing-function: linear;
}
.ease {
    background-color: coral;
    transition-timing-function: ease;
}
.linear:hover, .ease:hover {
    width: 300px;
}

Notice the difference in speed behavior between linear and ease.

4. Transition Delay

The transition-delay property specifies a delay before the transition starts, giving a pause effect before the animation begins.

Example: No Delay vs. 1-Second Delay

Hover Me (0s delay)
Hover Me (1s delay)

.delay-0 {
    background-color: slateblue;
    transition-delay: 0s;
}
.delay-1 {
    background-color: slateblue;
    transition-delay: 1s;
}
.delay-0:hover, .delay-1:hover {
    width: 300px;
}

Hover over each box to see how a 1-second delay affects the transition.

5. Compound Transitions: Multiple Properties with Different Durations

You can apply different durations for different properties in a single transition, using commas to separate them.

Hover Me

.compound-transition {
    background-color: royalblue;
    transition: width 2s, background-color 1s, transform 3s;
}
.compound-transition:hover {
    width: 300px;
    background-color: tomato;
    transform: rotate(20deg);
}

This example shows three properties (width, background-color, transform) each with a different duration, creating a staggered effect.
