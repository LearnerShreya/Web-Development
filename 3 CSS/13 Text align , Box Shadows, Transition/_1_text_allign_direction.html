Text Alignment and Direction in CSS

This document provides a detailed explanation of CSS properties used for text alignment and direction control, including examples and visual outputs.

Difference between align-right and rtl (right-to-left)
  • text-align: right : controls horizontal alignment within a container.
  • direction: rtl : changes the reading direction, impacting text flow and layout more broadly.
1. text-align

The text-align property sets the horizontal alignment of text within a block-level element.

  • left: Aligns text to the left.
  • right: Aligns text to the right.
  • center: Centers the text.
  • justify: Stretches the text so each line has equal width.

This text is justified, meaning it stretches to fit the full width of the container.

    /* Code Example */
    p {
        text-align: left; /* Or right, center, justify */
    }

Summary: The text-align property is used to define the alignment of text within a block. It can be aligned left, right, centered, or justified based on the requirement.

2. direction

The direction property sets the text direction within an element.

  • ltr: Left-to-right direction, commonly used for Latin-based languages.
  • rtl: Right-to-left direction, typically used for Arabic and Hebrew languages.

Text with direction: ltr is displayed from left to right.

النص بdirection: rtl يظهر من اليمين إلى اليسار.

    /* Code Example */
    p {
        direction: rtl; /* Or ltr */
    }

Summary: The direction property defines the direction of text flow, either left-to-right (ltr) or right-to-left (rtl), depending on the language of the content.

3. unicode-bidi

The unicode-bidi property is used in combination with direction to handle text that includes multiple languages or writing directions.

  • normal: Default; the element does not create an additional level of embedding.
  • bidi-override: Forces the element to respect the direction set, overriding any embedded content direction.

Using unicode-bidi: bidi-override with direction: rtl can force all content in a specific direction.

Text שלום mixed within LTR with bidi-override applied.

    /* Code Example */
    p {
        unicode-bidi: bidi-override;
    }

Summary: The unicode-bidi property allows control over bidirectional text, especially when content in mixed languages needs to be consistently aligned.

4. text-align-last

The text-align-last property aligns the last line of a block of text differently than the others. It only affects text when text-align is set to justify.

  • left: Aligns the last line to the left.
  • right: Aligns the last line to the right.
  • center: Centers the last line.
  • justify: Justifies the last line.

This paragraph has text-align: justify with text-align-last: right, so the last line is aligned to the right.

This paragraph has text-align-last: center, so the last line is centered.

    /* Code Example */
    p {
        text-align: justify;
        text-align-last: right; /* Or left, center, justify */
    }

Summary: The text-align-last property allows the last line of a justified block to be aligned differently, offering more flexibility in text formatting.

5. vertical-align

The vertical-align property sets the vertical alignment of inline or table-cell elements.

  • baseline: Aligns the baseline of the element with the baseline of the parent element.
  • sub: Aligns the text as a subscript.
  • super: Aligns the text as a superscript.

Text with vertical-align: baseline Baseline

Text with vertical-align: sub Subscript

Text with vertical-align: super Superscript

    /* Code Example */
    span {
        vertical-align: sub; /* Or super, baseline */
    }

Summary: The vertical-align property controls the vertical positioning of inline elements, allowing for subscript, superscript, or baseline alignment.

  • text-align: Controls horizontal alignment of text within block-level elements. It can align text to the left, right, center, or fully justify it.
  • direction: Controls the direction in which text flows. It is essential for languages with different reading directions, such as Arabic (RTL - Right to Left) and English (LTR - Left to Right).
  • unicode-bidi: This property is useful when dealing with mixed-direction text. The bidi-override value forces a single direction for the text within an element, overriding the default direction.
  • text-align-last: This property only works when the text is justified. It allows customization of the alignment of the last line in a block of text that has a justified alignment.
  • vertical-align: This property adjusts the vertical alignment of inline-level elements, such as text or images, within a line or table cell. It can be set to baseline, subscript, or superscript to control how text aligns relative to other content.
