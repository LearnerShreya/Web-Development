Comprehensive CSS Styling Notes on Text, Shadows, and Transitions

1. Text Alignment and Direction

Align text horizontally, set text direction, and manage text flow with CSS properties.

  • text-align: Controls horizontal alignment (options: left, right, center, justify).
  • direction: Sets text flow direction (options: ltr for left-to-right, rtl for right-to-left).
  • unicode-bidi: Works with direction to override text flow for complex text layouts.
  • text-align-last: Aligns the last line of text in a paragraph (options: left, right, center, justify).
  • vertical-align: Aligns inline or inline-block elements vertically (options: baseline, sub, super, etc.).
Example:
text-align: justify; direction: rtl;

Use Case: Useful in multilingual websites to display content in left-to-right and right-to-left languages.

2. Text Decoration

Control text decoration with lines, colors, and styles.

  • text-decoration-line: Specifies the decoration line type (options: underline, line-through, overline).
  • text-decoration-color: Sets color of the decoration line.
  • text-decoration-style: Changes the line style (options: solid, dotted, dashed, etc.).
  • text-decoration-thickness: Specifies the thickness of the line decoration.
Example:
text-decoration-line: underline; text-decoration-color: red; text-decoration-style: dashed;

Use Case: Highlight important links or headings with distinct decoration styles.

3. Text Transformation

Change the case of text with text-transform.

  • text-transform: Transforms text to uppercase, lowercase, or capitalize each word (options: uppercase, lowercase, capitalize).
Example:
text-transform: capitalize;

Use Case: Useful for standardizing headings and labels.

4. Text Spacing

Control spacing around and within text elements.

  • text-indent: Adds indentation to the first line of text.
  • letter-spacing: Adjusts space between letters.
  • line-height: Adjusts line height for text blocks.
  • word-spacing: Adds space between words.
  • white-space: Controls white-space handling within text (e.g., normal, nowrap, pre).
Example:
line-height: 1.8; word-spacing: 0.5em;

Use Case: Improve readability in paragraphs and headings by adjusting line height and spacing.

5. Text Shadow

Add shadow effects to text for depth and emphasis.

  • text-shadow: Applies shadow effects to text with horizontal and vertical offsets, blur radius, and color.
Example:
text-shadow: 2px 2px 5px rgba(0, 0, 0, 0.3);
Shadowed Text

Use Case: Great for adding dimension and emphasis to headers or titles.

6. Box Shadow

Apply shadow effects around elements to add a 3D effect.

  • box-shadow: Includes horizontal offset, vertical offset, blur radius, spread radius, and color.
  • inset: Applies the shadow inside the element.
Example:
box-shadow: 5px 5px 10px rgba(0, 0, 0, 0.5);
Box Shadow

Use Case: Enhance visual hierarchy on buttons, cards, or containers.

7. Transition

Animate CSS property changes smoothly over time.

  • transition: Specifies the property, duration, timing function, and delay for the transition.
  • property: The property to animate (e.g., background-color, width, etc.).
  • duration: Length of time for the transition.
  • timing-function: Specifies how the transition progresses (options: linear, ease, ease-in, ease-out, ease-in-out).
  • delay: Wait time before the transition starts.
Example:
transition: background-color 0.5s ease-in-out;

Use Case: Ideal for creating smooth hover effects on buttons or links.
