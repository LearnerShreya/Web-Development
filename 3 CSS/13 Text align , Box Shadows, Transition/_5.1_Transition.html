CSS Transitions: Understanding Each Property

This guide provides separate examples of how each part of the transition property works in CSS.

1. Transition Property

Use transition-property to define which CSS property you want to animate. Here, we apply it to the background-color property.

Hover over the box to change its background color.

.example-box {
    width: 100px;
    height: 100px;
    background-color: #4CAF50;
    transition-property: background-color;
}
.example-box:hover {
    background-color: #FF5733;
}
2. Transition Duration

transition-duration sets the time taken for the transition. Here we use 2s to make the transition last 2 seconds.

Hover over the box to see the transition duration.

.example-box {
    width: 100px;
    height: 100px;
    background-color: #4CAF50;
    transition-property: background-color;
    transition-duration: 2s;
}
.example-box:hover {
    background-color: #FF5733;
}
3. Transition Timing Function

The transition-timing-function specifies the speed curve. Here, ease-in-out is used for a smooth start and end.

Hover over the box to see the effect of the timing function.

.example-box {
    width: 100px;
    height: 100px;
    background-color: #4CAF50;
    transition-property: background-color;
    transition-duration: 2s;
    transition-timing-function: ease-in-out;
}
.example-box:hover {
    background-color: #FF5733;
}
4. Transition Delay

transition-delay specifies a delay before starting the transition. In this example, there is a 1-second delay before the color change begins.

Hover over the box to observe the delay.

.example-box {
    width: 100px;
    height: 100px;
    background-color: #4CAF50;
    transition-property: background-color;
    transition-duration: 2s;
    transition-delay: 1s;
}
.example-box:hover {
    background-color: #FF5733;
}

Summary of Transition Properties

  • Transition Property: Defines which CSS property is animated (e.g., background-color).
  • Transition Duration: Sets how long the transition takes (e.g., 2s or 500ms).
  • Transition Timing Function: Controls the speed curve of the transition (e.g., ease, linear, ease-in-out).
  • Transition Delay: Specifies a delay before starting the transition.
