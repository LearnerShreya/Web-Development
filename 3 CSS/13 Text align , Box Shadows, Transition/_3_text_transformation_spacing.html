Text Transformation and Spacing in CSS

This document explains the various CSS properties related to text transformation and spacing, with examples and visual output.

1. text-transform

The text-transform property controls the capitalization of text. Possible values include:

  • uppercase: Transforms all letters to uppercase.
  • lowercase: Transforms all letters to lowercase.
  • capitalize: Capitalizes the first letter of each word.

This TEXT is in lowercase.

this text is capitalized.

    /* Code Example */
    p {
        text-transform: uppercase; /* Or lowercase, capitalize */
    }

Summary: The text-transform property modifies the case of text, making it uppercase, lowercase, or capitalized for readability or stylistic purposes.

2. text-indent

The text-indent property specifies the indentation of the first line in a block of text. It is typically used to create a space at the start of a paragraph.

This paragraph has a 30px text indent at the beginning.

    /* Code Example */
    p {
        text-indent: 30px;
    }

Summary: The text-indent property allows you to control the indentation of the first line in a paragraph, enhancing readability.

3. letter-spacing

The letter-spacing property sets the space between characters in a text. It can be used to adjust the density of text, making it more readable or stylized.

This text has a letter spacing of 2px.

This text has a letter spacing of -1px (condensed).

    /* Code Example */
    p {
        letter-spacing: 2px; /* Can be any positive or negative value */
    }

Summary: The letter-spacing property adjusts the spacing between characters in text, improving readability or fitting a specific design style.

4. line-height

The line-height property sets the space between lines of text, known as line spacing. It is crucial for text readability and layout.

This paragraph has a line height of 1.2.

This paragraph has a line height of 2.

    /* Code Example */
    p {
        line-height: 1.5; /* Any unitless number, %, px, or em */
    }

Summary: The line-height property controls the vertical spacing between lines, improving readability and overall aesthetics.

5. word-spacing

The word-spacing property sets the space between words. It helps to control word density and readability.

This paragraph has 5px word spacing.

This paragraph has -2px word spacing (condensed).

    /* Code Example */
    p {
        word-spacing: 5px; /* Can be any positive or negative value */
    }

Summary: The word-spacing property allows control over the space between words, affecting the text's flow and readability.

6. white-space

The white-space property controls how white space inside an element is handled. Possible values include:

  • normal: Collapses white space, and text wraps to fill lines.
  • nowrap: Collapses white space, but text does not wrap.
  • pre: Preserves white space and line breaks as in the original text.
  • pre-wrap: Preserves white space and wraps text when necessary.
  • pre-line: Collapses multiple white spaces, preserving line breaks.

This paragraph does not wrap to the next line, even if it goes beyond the container width.

This paragraph preserves all white space and line breaks.

    /* Code Example */
    p {
        white-space: nowrap; /* Or normal, pre, pre-wrap, pre-line */
    }

Summary: The white-space property dictates how white space and line breaks are handled, preserving or collapsing them based on the needs of the design.

Summary of Text Transformation and Spacing Properties

  • Text Transformation (text-transform): Controls the case of text, converting it to uppercase, lowercase, or capitalized.
  • Text Indentation (text-indent): Sets the indentation for the first line of text in a block, often used to style paragraphs.
  • Letter Spacing (letter-spacing): Adjusts the space between individual characters, affecting the visual density of text.
  • Line Height (line-height): Sets the vertical space between lines, which impacts readability.
  • Word Spacing (word-spacing): Adjusts the space between words, which can improve text flow and readability.
  • White Space (white-space): Determines how white space within text is handled, including wrapping and preservation of spaces and line breaks.
