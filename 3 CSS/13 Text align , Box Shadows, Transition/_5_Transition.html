CSS Transitions

This guide covers the transition property in CSS, which is used to animate changes in CSS properties smoothly.

Understanding the Transition Property

The transition property in CSS allows for smooth, animated changes to CSS properties. It accepts the following parameters:

  • Property: Specifies the CSS property to animate (e.g., background-color, width, opacity). Using all applies the transition to all animatable properties.
  • Duration: Defines the time taken to complete the transition, typically in seconds (s) or milliseconds (ms).
  • Timing-function: Describes how the transition progresses over time, including options such as:
    • linear: A constant transition speed.
    • ease: Starts slow, speeds up, then slows down.
    • ease-in: Starts slow and speeds up.
    • ease-out: Starts fast and slows down.
    • ease-in-out: Starts slow, speeds up, then slows down again.
  • Delay: Sets the delay before the transition starts, in seconds (s) or milliseconds (ms).

Hover over the box to see the transition effect.

    /* Code Example */
    .box {
        width: 100px;
        height: 100px;
        background-color: #4CAF50;
        transition: background-color 2s ease, width 2s ease-in-out, opacity 2s ease-out 1s;
    }
    .box:hover {
        background-color: #FF5733;
        width: 150px;
        opacity: 0.7;
    }
1. Property

The property specifies which CSS property to animate. For instance, using background-color applies the transition only to color changes. Using all animates all changes on the element.

2. Duration

The duration defines the length of the transition. It is essential for controlling the timing, with values such as 2s for two seconds or 500ms for half a second.

3. Timing Function

The timing-function affects the transition speed curve over time. Below are common timing functions:

  • linear: A constant speed.
  • ease: Starts slow, accelerates, then decelerates.
  • ease-in: Starts slowly and accelerates.
  • ease-out: Starts fast and decelerates.
  • ease-in-out: A combination of slow start and end with an acceleration in the middle.
4. Delay

The delay is the time to wait before the transition begins. It allows animations to start after a certain time. For example, a delay of 1s starts the transition one second after the trigger.

Summary of CSS Transition Properties

  • Transition Property: Defines which CSS property is animated.
  • Duration: Controls how long the transition effect takes to complete.
  • Timing Function: Specifies the speed curve of the transition (e.g., linear, ease, ease-in-out).
  • Delay: Sets the time to wait before the transition starts.
