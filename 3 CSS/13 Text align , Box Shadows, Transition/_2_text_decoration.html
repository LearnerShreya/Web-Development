Text Decoration in CSS

This document explains the various text decoration properties in CSS, with detailed examples and visual output.

1. text-decoration-line

The text-decoration-line property specifies which line decoration is applied to the text. Possible values include:

  • overline: Adds a line above the text.
  • line-through: Adds a line through the text, indicating deletion or strikethrough.
  • underline: Adds a line beneath the text, commonly used for links.
  • overline underline: Combines both overline and underline effects.

This text is underlined.

This text has both overline and underline.

    /* Code Example */
    p {
        text-decoration-line: underline; /* Or overline, line-through, or a combination */
    }

Summary: The text-decoration-line property allows you to apply one or more lines (overline, underline, line-through) to text, improving readability or indicating special meaning.

2. text-decoration-color

The text-decoration-color property sets the color of the text decoration line(s).

  • Example: Using a color like red, blue, or any CSS color code.

This text is underlined with a red color.

This text has a strikethrough with blue color.

    /* Code Example */
    p {
        text-decoration-color: red; /* Or any valid color */
    }

Summary: The text-decoration-color property allows you to customize the color of the text decoration, making it stand out or match the page's design theme.

3. text-decoration-style

The text-decoration-style property defines the style of the text decoration line(s). It can take the following values:

  • solid: A solid line (default).
  • dotted: A dotted line.
  • dashed: A dashed line.
  • wavy: A wavy line.

This text is underlined with a dotted line.

This text is underlined with a dashed line.

This text is underlined with a wavy line.

    /* Code Example */
    p {
        text-decoration-style: dotted; /* Or solid, dashed, wavy */
    }

Summary: The text-decoration-style property modifies the appearance of the decoration line, making it solid, dotted, dashed, or wavy depending on the design requirement.

4. text-decoration-thickness

The text-decoration-thickness property controls the thickness of the text decoration line. You can set it using:

  • auto: The default thickness of the line.
  • length: A specific thickness value, such as 2px, 0.1em, etc.

    /* Code Example */
    p {
        text-decoration-thickness: 3px; /* Or auto, 0.1em, etc. */
    }

Summary: The text-decoration-thickness property enables control over the thickness of text decoration lines, allowing you to make them thicker or thinner as per design needs.

  • Text Decoration Line (text-decoration-line): This property allows applying different types of line decorations to text, including overline, underline, and line-through.
  • Text Decoration Color (text-decoration-color): You can specify the color of the line decoration, which can be customized using any valid CSS color (like red, blue, hex, or RGB).
  • Text Decoration Style (text-decoration-style): This property lets you choose the style of the decoration line, such as solid, dotted, dashed, or wavy.
  • Text Decoration Thickness (text-decoration-thickness): Controls the thickness of the text decoration line, allowing values like auto, px, or em for finer control over the appearance of underlines or other decorations.
