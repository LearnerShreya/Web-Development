CSS Styling Notes

Text Alignment and Direction

Use the text-align property to control text alignment, while direction and unicode-bidi manage text direction.

  • text-align: left, right, center, justify
  • direction: ltr, rtl
  • unicode-bidi: bidi-override
Example:
text-align: center;
direction: rtl;

Text Decoration

text-decoration properties allow you to style underlines, overlines, and strikethroughs.

  • text-decoration-line: overline, line-through, underline
  • text-decoration-color: color
  • text-decoration-style: solid, dashed, dotted
Example:
text-decoration-line: underline;
text-decoration-color: red;

Text Transformation

Use text-transform to change text to uppercase, lowercase, or capitalize each word.

  • uppercase: Converts text to uppercase
  • lowercase: Converts text to lowercase
  • capitalize: Capitalizes the first letter of each word
Example:
text-transform: uppercase;

Text Spacing

Properties for adjusting spacing within and between text elements:

  • text-indent: Indents the first line of a paragraph.
  • letter-spacing: Adds space between letters.
  • line-height: Adjusts line spacing.
  • word-spacing: Adds space between words.
  • white-space: Controls how white space is handled.
Example:
line-height: 1.5;
word-spacing: 0.2em;

Text Shadow

Apply shadows to text using the text-shadow property. It includes horizontal offset, vertical offset, blur radius, and color.

Example:
text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);

Box Shadow

The box-shadow property adds shadow effects around an element's frame.

  • h-offset: Moves shadow horizontally
  • v-offset: Moves shadow vertically
  • blur-radius: Amount of blur
  • spread-radius: Expands or contracts the shadow
  • color: Shadow color
Example:
box-shadow: 5px 5px 15px rgba(0, 0, 0, 0.3);

Transition

Animate property changes smoothly with the transition property.

  • property: Specifies the property to animate
  • duration: Time to complete transition
  • timing-function: Speed curve (e.g., ease, linear)
  • delay: Delay before the transition starts
Example:
transition: background-color 1s ease;
