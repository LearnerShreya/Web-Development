Text Shadow and Box Shadow in CSS

This guide covers CSS properties text-shadow and box-shadow with examples and explanations.

1. text-shadow

The text-shadow property adds shadow effects to text. It takes up to four values:

  • Horizontal offset (h-offset): Sets the horizontal distance of the shadow. Positive values move the shadow to the right, while negative values move it to the left.
  • Vertical offset (v-offset): Sets the vertical distance of the shadow. Positive values move the shadow down, while negative values move it up.
  • Blur radius: Controls the blur amount. Higher values create a more blurred shadow.
  • Color: Defines the color of the shadow, which can be set using color names, HEX, RGB, or RGBA values.

This is text with a shadow effect.

    /* Code Example */
    p.shadow-text {
        text-shadow: 2px 2px 5px rgba(0, 0, 0, 0.5);
    }

Summary: The text-shadow property applies shadow to text with options for offset, blur, and color, allowing for different shadow effects to enhance readability or style.

2. box-shadow

The box-shadow property adds shadow effects to boxes (such as div elements). It can take up to five values:

  • Horizontal offset (h-offset): Moves the shadow left or right. Positive values shift the shadow to the right, while negative values shift it to the left.
  • Vertical offset (v-offset): Moves the shadow up or down. Positive values move it down, while negative values move it up.
  • Blur radius: Controls the sharpness of the shadow. Higher values make the shadow more blurred.
  • Spread radius: Expands or shrinks the size of the shadow. Positive values expand, while negative values shrink the shadow.
  • Color: Sets the color of the shadow, which can use any valid color format (HEX, RGB, or RGBA).
Box with shadow
    /* Code Example */
    .shadow-box {
        box-shadow: 5px 5px 10px rgba(0, 0, 0, 0.3);
    }

Summary: The box-shadow property adds a shadow around a box with adjustable offset, blur, spread, and color, allowing for different shadow effects and enhancing depth perception.

3. Inset Box Shadow

The inset keyword can be added to box-shadow to create an inner shadow, making it appear as though the element is recessed.

Box with inset shadow
    /* Code Example */
    .inset-shadow {
        box-shadow: inset 5px 5px 10px rgba(0, 0, 0, 0.3);
    }

Summary: Adding inset to box-shadow creates an inner shadow effect, giving the box a sunken look that can be used for elements like buttons and cards.

Summary of Text Shadow and Box Shadow Properties

  • Text Shadow (text-shadow): Adds shadow effects to text, with options for horizontal and vertical offsets, blur, and color customization.
  • Box Shadow (box-shadow): Adds shadow effects around a box, allowing control over offset, blur, spread, and color.
  • Inset Box Shadow (inset): Adds an inner shadow to a box, creating a recessed effect within the element.
