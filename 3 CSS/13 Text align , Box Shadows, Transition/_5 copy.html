In-Depth Guide to CSS Transitions

Transition Syntax

To create smooth animations, CSS transitions allow you to define how properties change over time. The syntax for transitions is as follows:

transition: property duration timing-function delay;

The above syntax includes four main parts:

  • Property: Specifies which CSS property to animate (e.g., background-color, width, etc.). all can be used to apply transitions to all animatable properties.
  • Duration: Specifies the duration of the transition (e.g., 2s, 500ms).
  • Timing Function: Defines the pace of the transition, with options like linear, ease, ease-in, etc.
  • Delay: Defines a delay before the transition starts (e.g., 1s).

1. Transition Property

The property defines which CSS property will be animated. Only animatable properties, such as background-color, width, and opacity, can be transitioned.

Hover me!

In this example, only the background-color changes over a 2-second duration.

Code Example:


.transition-property {
    background-color: royalblue;
    transition: background-color 2s ease-in-out;
}
.transition-property:hover {
    background-color: tomato;
}

2. Transition Duration

The duration defines how long the transition takes to complete. The value can be specified in seconds (s) or milliseconds (ms).

Hover me!

In this example, the width of the box expands over a 3-second duration.

Code Example:


.transition-duration {
    background-color: darkseagreen;
    transition: width 3s;
}
.transition-duration:hover {
    width: 300px;
}

3. Transition Timing Function

The timing-function defines the speed curve of the transition. Here are common values:

  • linear: Constant speed from start to end.
  • ease: Starts slow, speeds up, and slows down again.
  • ease-in: Starts slow and speeds up towards the end.
  • ease-out: Starts fast and slows down towards the end.
  • ease-in-out: Starts slow, speeds up, then slows down again.
Hover me!

This example uses ease-in for a smoother start in width expansion.

Code Example:


.transition-timing-function {
    background-color: coral;
    transition: width 1.5s ease-in;
}
.transition-timing-function:hover {
    width: 300px;
}

4. Transition Delay

The delay defines a time to wait before the transition starts. This is especially useful for staged or delayed animations.

Hover me!

In this example, a 1-second delay is applied before the width expands.

Code Example:


.transition-delay {
    background-color: slateblue;
    transition: width 2s ease-out 1s; /* 1s delay */
}
.transition-delay:hover {
    width: 300px;
}

5. Applying "All" to Transition Multiple Properties

The all keyword is used to apply the transition effect to all animatable properties in the element.

Hover me!

In this example, several properties change on hover: width, background-color, and transform.

Code Example:


.transition-all {
    background-color: darkorchid;
    transition: all 2s ease-in-out;
}
.transition-all:hover {
    width: 250px;
    background-color: mediumseagreen;
    transform: rotate(15deg);
}

6. Understanding Timing Functions

Each timing function creates a different feel for the transition:

  • linear: Moves at a constant speed from start to finish.
  • ease: Starts slow, speeds up, and slows down.
  • ease-in: Gradually increases in speed.
  • ease-out: Gradually slows down.
  • ease-in-out: Starts slow, speeds up, then slows down again.

Experiment with these functions to find the best fit for your animations.
