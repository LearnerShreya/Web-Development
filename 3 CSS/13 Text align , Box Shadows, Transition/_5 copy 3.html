In-Depth CSS Transitions Guide

This guide provides an in-depth look into CSS transitions, breaking down each component of the transition shorthand property. We'll cover transition-property, transition-duration, transition-timing-function, and transition-delay with visual examples.

1. Transition Property

The transition-property specifies which CSS property should animate when a change occurs. Common properties to animate include:

  • background-color: Animates the color of an element's background.
  • width: Changes the width of an element.
  • transform: Applies transformations like rotation, scaling, and translation.
  • You can also use all to apply the transition to all animatable properties.
Example: Animate background-color, width, and transform
Hover Me

.property-example {
    background-color: teal;
    transition-property: background-color, width, transform;
}
.property-example:hover {
    background-color: darkorange;
    width: 200px;
    transform: rotate(15deg);
}

2. Transition Duration

The transition-duration property specifies how long the transition should take to complete. You can set values in seconds (e.g., 2s) or milliseconds (e.g., 500ms).

It is essential to define duration for smooth animations, as it controls the overall speed of the transition.

Example: Compare Duration of 1 second vs. 3 seconds
1s Duration
3s Duration

.duration-1s {
    transition-duration: 1s;
}
.duration-3s {
    transition-duration: 3s;
}
.duration-1s:hover, .duration-3s:hover {
    width: 300px;
}

3. Transition Timing Function

The transition-timing-function defines the speed curve of the transition. It describes how the transition progresses over its duration. Some common timing functions include:

  • linear: Maintains a constant speed from start to finish.
  • ease: Starts slowly, speeds up, and then slows down toward the end.
  • ease-in: Starts slowly and speeds up.
  • ease-out: Starts quickly and slows down at the end.
  • ease-in-out: Starts slowly, speeds up, and then slows down again.
Example: Different Timing Functions
Linear
Ease-In
Ease-Out
Ease-In-Out

.linear {
    transition-timing-function: linear;
}
.ease-in {
    transition-timing-function: ease-in;
}
.ease-out {
    transition-timing-function: ease-out;
}
.ease-in-out {
    transition-timing-function: ease-in-out;
}
.linear:hover, .ease-in:hover, .ease-out:hover, .ease-in-out:hover {
    width: 300px;
}

4. Transition Delay

The transition-delay property sets a delay before the transition begins. It allows for a pause before the animation starts, creating a more intentional effect.

Setting the transition-delay can be useful for staggered animations or delayed effects.

Example: 0-second vs. 1-second Delay
0s Delay
1s Delay

.delay-0s {
    transition-delay: 0s;
}
.delay-1s {
    transition-delay: 1s;
}
.delay-0s:hover, .delay-1s:hover {
    width: 300px;
}
