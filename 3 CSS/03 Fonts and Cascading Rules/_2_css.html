CSS Cascading: Comprehensive Guide

Understanding the CSS cascading order is crucial to mastering CSS styling. Cascading helps determine which style rules apply when there are conflicts in CSS.

1. Cascading Order

When multiple CSS rules target the same element, the browser determines which rule to apply based on the following order:

  • Inline styles (written within the HTML element) have the highest priority.
  • Internal (embedded) CSS rules (within a <style> tag in the HTML document).
  • External CSS rules (linked via an external .css file) have the lowest priority in the cascade.

Example:

<p style="color: red;">This is an inline style</p>
Output: This is an inline style

2. Specificity

Specificity determines which CSS rule will apply to an element when multiple rules target the same property. Specificity is calculated based on selectors:

  • ID selectors have the highest specificity value.
  • Attribute selectors have similar specificity to class selectors.
  • Class selectors have lower specificity than ID selectors but higher than element selectors.
  • Child and descendant selectors refine specificity but don't override the ID or class level. Both has same priority, that's why one written in last wins here.
  • Element & group element selectors (like <p>, <div>) have the lowest specificity.

Example:

<style>
#unique { color: blue; }
.example { color: green; }
p { color: red; }
</style>
<p id="unique" class="example">This text is blue due to ID specificity.</p>
Output: This text is blue due to ID specificity.

3. Types of CSS

There are three main types of CSS rules, which affect cascading order:

  • Inline CSS - Written directly in the HTML element's style attribute. Highest priority.
  • Internal CSS - Included within a <style> tag in the head section of the HTML document.
  • External CSS - Linked to the HTML document via a <link> tag. Provides easy management and reusability.

Example:

<style>
p { color: green; } /* External/internal style */
</style>
<p style="color: red;">This inline CSS overrides other types.</p>
Output: This inline CSS overrides other types.

4. Using !important

The !important keyword overrides any other styling rules for a specific property, regardless of specificity.

<style>
p { color: blue !important; }
p { color: green; } /* Ignored due to !important */
</style>
<p>This text will be blue due to !important.</p>
Output: This text will be blue due to !important.

CSS Priority Order

1. !important

  • When you add !important to a rule, it tells the browser to always use that rule, no matter what other rules say.
  • Even if other styles have higher specificity or are inline styles, !important will still take precedence.

2. Types (inline, internal, external)

  • Inline Styles: CSS added directly to an HTML tag using the style attribute (e.g., <div style="color: red;">) takes priority over internal and external CSS, as it is closest to the element.
  • Internal Styles: CSS written in a <style> block within the HTML file has more priority than external CSS but is lower than inline styles.
  • External Styles: CSS written in an external file (e.g., styles.css) has the lowest priority among the three types.

3. Specificity

  • The browser calculates specificity based on the selectors used. The more specific the selector, the higher priority it has.
  • ID Selectors (e.g., #header) have the highest specificity.
  • Class and Attribute Selectors (e.g., .button or [type="text"]) have lower specificity than IDs.
  • Element Selectors (e.g., p or h1) have the lowest specificity of all.

4. Order (Cascading)

  • If two or more rules have the same specificity, the browser will use the one that appears last in the CSS file.
  • This way, the styles that come later will "override" the ones that were applied earlier if everything else is equal.

Summary of Priority Order:

  • !important – Always comes first, no exceptions.
  • Types – Inline > Internal > External (closer styles win).
  • Specificity – ID > Class/Attribute > Element (the more specific rule is applied).
  • Order – If everything is the same, the rule that appears last wins.
