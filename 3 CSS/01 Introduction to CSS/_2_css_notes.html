CSS (Cascading Style Sheets) Notes

What is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of HTML or XML documents. It controls how elements are displayed on the page, including layout, colors, fonts, and spacing. CSS allows for the separation of content and design, enabling consistent styling across multiple pages.

1. CSS Syntax

CSS rules are composed of selectors and declarations:

selector {
    property: value;
}
  • Selector: Targets HTML elements to style.
  • Property: Specifies the aspect of the element to style (e.g., color, font-size).
  • Value: Defines the settings for the property (e.g., red, 16px).

2. Types of CSS

  • Inline CSS: Applied directly to an HTML element using the style attribute.
    • <p style="color: red;">This is a red paragraph.</p>
  • Internal CSS: Defined within the <style> tag in the <head> section of an HTML document.
    • <style>
p {
    color: blue;
}
</style>
  • External CSS: Written in a separate .css file and linked to the HTML document using the <link> tag.
    • <link rel="stylesheet" href="styles.css">
    p {
    color: green;
}

3. CSS Selectors

Selectors are used to target HTML elements for styling:

  1. Element Selector: Targets elements by their tag name.
    2. h1 {
    color: blue;
}
  2. Class Selector: Targets elements with a specific class using a dot (.) before the class name.
    3. .intro {
    font-size: 16px;
}
  3. ID Selector: Targets a specific element with an ID using a hash (#).
    4. #main {
    background-color: yellow;
}
  4. Attribute Selector: Targets elements with a specific attribute.
    5. <h1 contenteditable="true"> editable content </h1>
<h1 draggable="true"> draggable content </h1>
    p[draggable] {
    color: purple;
}
div[contenteditable="true"] {
    border: 1px dashed black;
}
  5. Universal Selector: Targets all elements on the page using the * symbol.
    6. * {
    margin: 0;
    padding: 0;
}
  6. Grouping Selector: Combines multiple selectors to apply the same styles.
    7. h1, h2, h3 {
    color: darkgreen;
}
  7. Descendant Selector: Targets elements inside a specific container.
    8. div p {
    color: orange;
}
  8. Child Selector: Targets direct child elements.
    9. div > p {
    font-weight: bold;
}
  9. ID Selector with Class Selector: Targets an element with both a specific ID and class.
    10. #main.highlight {
    background-color: lightblue;
}

4. CSS Box Model

The CSS box model is the structure that wraps every HTML element. It consists of:

  • Content: The text or image inside the element.
  • Padding: Space between the content and the border.
  • Border: A line around the padding.
  • Margin: Space outside the border that separates the element from others.
div {
    margin: 10px;
    padding: 15px;
    border: 2px solid black;
}

5. Responsive Design

Responsive design ensures websites look good on all devices by using techniques like:

  • Media Queries: Apply styles based on device characteristics like screen size.
    • @media (max-width: 600px) {
    body {
        background-color: lightblue;
    }
}
  • Flexbox: A flexible layout system to align and distribute space among elements.
    • .container {
    display: flex;
    justify-content: center;
    align-items: center;
}

6. Common CSS Properties

  • Color and Background:
    • color: red;                  /* Text color */
background-color: yellow;    /* Background color */
  • Fonts and Text:
    • font-family: Arial, sans-serif;
font-size: 16px;
text-align: center;
  • Spacing:
    • margin: 20px;   /* Space outside the element */
padding: 10px;  /* Space inside the element */
  • Borders:
    • border: 1px solid black;
