CSS Notes in Simple Language

  1. <font size="5" color="red">
    This tag changes the size and color of text directly, but it's outdated. Use CSS instead for more control.
  2. How to Add CSS Styles to HTML
    • Inline CSS - Write CSS right inside the HTML tag. Example: <p style="color: red;">Hello</p>
    • Internal CSS - Put CSS in the same HTML file, but in the <style> tag inside the <head>.
    • External CSS - Write CSS in a separate file (usually with a .css extension) and link it to HTML. It’s cleaner and used often for bigger projects.
  3. CSS Selectors (Ways to Select HTML Elements)
    1. Element Selector - Directly targets HTML tags, like p or h1.
    2. Class Selector - Selects elements with a specific class. Use a dot (.) before the class name, like .myClass.
    3. ID Selector - Selects an element with a specific ID. Use a hashtag (#) before the ID, like #myId.
    4. Attribute Selector - Selects elements based on certain attributes. Examples: p[draggable] (any <p> tag with draggable attribute), div[contenteditable="true"] (any <div> that can be edited directly).
    5. Universal Selector - The * symbol selects all elements on the page.
    6. Grouping Selector - Selects multiple elements at once. Example: h1, h2, h3 to style all these headers the same way.
    7. Descendant Selector - Targets an element inside another element. Example: div p { } styles all <p> tags inside a <div>.
    8. Child Selector - Similar to Descendant, but it selects only direct children. Example: div > p will style <p> tags directly under a <div>, but not nested deeper.
    9. ID with Class Selector - Combines an ID and class to select a specific element more precisely. Example: #id.class will select an element with a specific ID and class.
  4. CSS Color
    Used to set colors for text, backgrounds, borders, etc. Colors can be added by name (like "red"), HEX codes (like "#ff0000"), RGB codes (like "rgb(255, 0, 0)"), or HSL values.
