Comprehensive Guide to CSS Concepts

Z-Index

The z-index property specifies the stacking order of elements along the z-axis. Elements with higher z-index values appear in front of elements with lower values. Only works on positioned elements (e.g., position: absolute, relative, fixed, or sticky).

Example:

.box1 { position: absolute; z-index: 1; background-color: lightblue; width: 100px; height: 100px; }
.box2 { position: absolute; z-index: 2; background-color: lightcoral; width: 100px; height: 100px; top: 20px; left: 20px; }
Key Point: Higher z-index values place elements in front of lower values.
Use Case: Use z-index for stacking modal dialogs or pop-ups above other content.
Important Note: z-index only works on elements with a non-static position.

Overflow

The overflow property controls the handling of content that exceeds an element’s box. Options include:

  • hidden: Clips overflowed content.
  • visible: Allows overflow (default).
  • scroll: Adds scrollbars.
  • auto: Adds scrollbars only if content overflows.

Example:

.box { width: 200px; height: 100px; overflow: hidden; background-color: lightgreen; }
Key Point: Use overflow to control scrolling and visibility of content within boxes.
Use Case: Managing text or images within fixed-size containers.
Important Note: Avoid overflow: hidden if you need access to all content.

Float and Clear

The float property moves elements to the left or right, allowing text and inline elements to wrap around them. The clear property prevents elements from wrapping around floated elements.

Example:

.floated { float: left; width: 100px; height: 100px; background-color: lightcoral; }
.clear { clear: both; background-color: lightblue; padding: 10px; }
Key Point: Float aligns elements left or right, clear stops the wrapping effect.
Use Case: Aligning images or creating multi-column layouts with floats.
Important Note: Consider using Flexbox or Grid for layout instead of float for modern design.

Position

The position property specifies how an element is positioned in a document. Options include:

  • static: Default, follows normal flow.
  • relative: Positioned relative to itself.
  • absolute: Positioned relative to nearest positioned ancestor.
  • fixed: Positioned relative to viewport, stays fixed on scroll.
  • sticky: Toggles between relative and fixed based on scroll.

Example:

.fixed { position: fixed; top: 0; }
Key Point: Fixed elements remain visible on scroll; absolute requires a positioned ancestor.
Use Case: Sticky navigation bars, modals, and pop-ups.
Important Note: Avoid overusing fixed elements as they may interfere with layout.

Display

The display property defines how an element displays. Common values:

  • block: Takes full width, starts on a new line.
  • inline: Takes only required width, does not start a new line.
  • inline-block: Like inline but allows height/width.
  • flex: Enables flexbox for flexible layouts.
  • grid: Enables CSS Grid for grid-based layouts.

Example:

.flex-container { display: flex; gap: 10px; }
Key Point: display: flex and display: grid are ideal for modern layouts.
Use Case: Use Flexbox for row-based layouts; Grid for complex grid structures.
Important Note: display: none hides elements visually and from screen readers.
