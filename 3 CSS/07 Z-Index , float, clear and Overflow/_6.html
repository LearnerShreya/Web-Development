CSS Properties - In-Depth Guide

Z-Index

The z-index property controls the stacking order of elements along the z-axis. Elements with higher z-index values are displayed in front of elements with lower values.

.box1 { position: absolute; z-index: 10; background-color: lightcoral; } .box2 { position: absolute; z-index: 5; background-color: lightblue; }
Box 2 (z-index: 5)
Box 1 (z-index: 10)
Higher z-index values bring elements to the front.
Used in dropdowns, modals, and layered designs.
Only works on positioned elements (e.g., with position: relative or absolute).

Overflow

The overflow property determines what happens to content that overflows the boundary of an element.

  • hidden: Clips overflowing content.
  • visible: Displays content outside the boundary.
  • scroll: Adds scrollbars for overflow.
  • auto: Adds scrollbars only if necessary.
.container { width: 150px; height: 50px; overflow: scroll; }

This is an overflowing text example to show how scrollbars appear when overflow is set to scroll.

Controls whether content outside the element's bounds is visible or clipped.
Helpful in sidebars, modals, and contained elements with overflow content.
Using overflow: hidden can cut off important content.

Flow and Clear

The clear property is used to control the flow of floated elements.

  • left: Clears left floats.
  • right: Clears right floats.
  • both: Clears both sides.
.clearfix::after { content: ""; display: table; clear: both; }
Floated Box
Cleared content
Use clear: both to stop floating behavior for new elements.
Prevents layout issues when using floats.
Flexbox and Grid layout are modern alternatives to floats.

CSS on Text

Text Align

The text-align property aligns text horizontally within a container.

  • center: Center-aligns text.
  • left: Left-aligns text.
  • right: Right-aligns text.
  • justify: Justifies text to spread across the container width.
.text-center { text-align: center; }
Centered Text Example
Controls horizontal alignment of text.
Used in headings, paragraphs, and aligning text in containers.
Justified text is often used in articles and formal documents.

Text Align Last

The text-align-last property specifies how the last line of a block of text should align.

p { text-align: justify; text-align-last: center; }
This paragraph is justified across the line, with the last line centered for visual effect.
Affects only the last line in a justified or right-aligned text block.
Used for formal documents to align the last line.

Direction and Unicode-Bidi

The direction and unicode-bidi properties manage text flow for languages with different writing directions.

  • direction: ltr for left-to-right, rtl for right-to-left.
  • unicode-bidi: Ensures proper bidirectional text handling.
.rtl-text { direction: rtl; unicode-bidi: bidi-override; }
This text flows right-to-left using direction: rtl.
The direction property controls text direction, and unicode-bidi ensures proper handling of bidirectional text.
Used in multilingual websites to display right-to-left languages like Arabic and Hebrew.
Ensure proper text handling when mixing left-to-right and right-to-left text in the same content.

CSS on Box Model

Box Sizing

The box-sizing property determines how the width and height of an element are calculated, including padding and borders.

  • content-box: Default, width and height only include the content, not padding or border.
  • border-box: Width and height include padding and border, making it easier to control size.
.box { box-sizing: border-box; width: 100px; padding: 10px; border: 5px solid black; }
Content Box Example
Box-sizing: border-box includes padding and border in the element's total width/height.
Helpful when managing layouts and responsive design.
Use border-box for better control in complex layouts.
