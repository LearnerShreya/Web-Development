Understanding the CSS Clear Property

Introduction

The clear property in CSS is used to control the position of an element relative to floated elements above it. By using clear, you can ensure that an element does not wrap around any floated elements, making layouts predictable and easier to control.

Clear Property Values

  • none: Default value; the element is not affected by any floats.
  • left: Moves the element below left-floated elements.
  • right: Moves the element below right-floated elements.
  • both: Moves the element below both left and right floated elements.

Example: Before Adding Clear

This example shows elements with left and right floats without using the clear property. Notice that the next element wraps around them.

Right Float Box
Content Without Clear

Notice how the "Content Without Clear" box wraps around the floated boxes above.

/* CSS Code for Example: Before Adding Clear */ .left-float { float: left; } .right-float { float: right; } .box { width: 150px; height: 100px; }

Example: After Adding Clear

This example uses clear: both to move the "Clear Both Box" below the floated elements.

Left Float Box
Right Float Box
Clear Both Box (Clear: Both)
Content Below Cleared Element

With clear: both, the "Clear Both Box" and content below it are moved beneath the floated elements.

/* CSS Code for Example: After Adding Clear */ .left-float { float: left; } .right-float { float: right; } .clear { clear: both; }

Using Specific Clear Values

Clear Left

Here, only the left float is cleared, so the "Clear Left Box" sits below the left-floated element only.

Left Float Box
Clear Left Box (Clear: Left)
Content Below Left Clear

Only the left float is cleared, so the content sits next to any right-floated elements.

/* CSS Code for Clear Left */ .left-float { float: left; } .clear { clear: left; }

Clear Right

Here, only the right float is cleared, so the "Clear Right Box" sits below the right-floated element only.

Right Float Box
Clear Right Box (Clear: Right)
Content Below Right Clear

Only the right float is cleared, so the content sits next to any left-floated elements.

/* CSS Code for Clear Right */ .right-float { float: right; } .clear { clear: right; }

Clear Both

This example clears both floats, pushing the "Clear Both Box" below both floated elements.

Left Float Box
Right Float Box
Clear Both Box (Clear: Both)
Content Below Both Clears

With clear: both, the "Clear Both Box" and content below it appear under all floated elements.

/* CSS Code for Clear Both */ .left-float { float: left; } .right-float { float: right; } .clear { clear: both; }

Key Points

  • Use the clear property to prevent wrapping around floated elements.
  • For left floats, use clear: left, for right floats, use clear: right.
  • To clear both, use clear: both, which is useful to reset all floats in a section.
