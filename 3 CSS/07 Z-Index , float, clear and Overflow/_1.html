CSS Concepts

1. Z-Index

Description: The z-index property specifies the stack order of an element. Elements with a higher z-index value appear in front of elements with a lower z-index value. It only works on positioned elements (i.e., elements with position set to absolute, relative, or fixed).

Example:

 
        .box1 {
            position: absolute;
            z-index: 1;
            background-color: lightblue;
        }

        .box2 {
            position: absolute;
            z-index: 2;
            background-color: lightcoral;
        }

Use Case: Use z-index to control which elements appear on top in overlapping scenarios.

Important Note: z-index only applies to positioned elements.

2. Overflow

Description: The overflow property controls what happens to content that exceeds the bounds of its container. It has four values: hidden, visible, scroll, and auto.

  • hidden: Hides the overflow content.
  • visible: Displays overflow content outside the container.
  • scroll: Adds scroll bars for overflowing content.
  • auto: Adds scroll bars only if needed.

Example:

 
        .container {
            width: 200px;
            height: 100px;
            overflow: hidden;
            background-color: lightgreen;
        }

Use Case: overflow is useful for managing large content in fixed-size containers.

3. Flow and Clear

Description: float is used to position elements to the left or right of their container. The clear property is used to control the behavior of following elements after a floating element.

  • left: Floats the element to the left.
  • right: Floats the element to the right.
  • clear: Stops the floating of elements on the specified side (left, right, or both).

Example:

 
        .left-float {
            float: left;
            width: 100px;
            height: 100px;
            background-color: lightcoral;
        }

        .clearfix {
            clear: both;
        }

Use Case: float and clear are often used for positioning and layout adjustments.

4. CSS on Text

4.1 Text Align

Description: The text-align property aligns text within an element. Options include center, left, right, and justify (which aligns text evenly across the line).

Example:

 
        .text-center {
            text-align: center;
        }

Use Case: text-align is useful for formatting text alignment within a block.

4.2 Text-Align-Last

Description: The text-align-last property specifies how the last line of a block or a line right before a line break is aligned.

Example:

 
        .text-align-last-justify {
            text-align-last: justify;
        }

4.3 Direction

Description: The direction property sets the text direction, and unicode-bidi provides support for bidirectional text (e.g., right-to-left for languages like Arabic).

Example:

 
        .rtl {
            direction: rtl;
            unicode-bidi: bidi-override;
        }

Use Case: Useful for handling multi-language content and languages written from right to left.
