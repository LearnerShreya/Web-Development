CSS Concepts Explained

Z-Index

The z-index property specifies the stack order of elements. Higher values appear on top of elements with lower values. Only works on positioned elements (position: relative/absolute/fixed/sticky).

.box1 { position: absolute; z-index: 10; } .box2 { position: absolute; z-index: 5; }
Higher z-index values place elements closer to the front of the page.
Used in dropdown menus, modals, and overlapping elements.
Ensure positioning is set for z-index to take effect.

Overflow

The overflow property controls what happens to content that overflows its container.

  • hidden: Clips content that overflows.
  • visible: Displays overflowing content outside the container.
  • scroll: Adds scrollbars when content overflows.
  • auto: Adds scrollbars only if content overflows.
.container { width: 200px; height: 100px; overflow: scroll; }
Use overflow: scroll to always show scrollbars.
Helpful for scrollable areas like sidebars.
Avoid overflow: hidden if content is important to view.

Flow and Clear

The clear property is used to control the behavior of floating elements.

  • left: No left floating elements allowed.
  • right: No right floating elements allowed.
  • both: No floating elements on either side.
.clearfix::after { content: ""; display: block; clear: both; }
Use clear: both to prevent floats from affecting subsequent elements.
Commonly used in container elements to prevent layout issues with floats.
Modern layouts often use Flexbox or Grid instead of floats.

CSS on Text

Text Align

The text-align property aligns text horizontally within its container.

  • center: Centers text.
  • left: Aligns text to the left.
  • right: Aligns text to the right.
  • justify: Spreads text evenly, adjusting spacing.
.text-center { text-align: center; }
justify is often used in paragraphs for a clean, aligned look.
Center-align headings, justify paragraphs in articles.
Left-alignment is default in left-to-right languages.

Text Align Last

The text-align-last property specifies how the last line of a block or a line-right aligned paragraph should align.

p { text-align: justify; text-align-last: center; }
Only affects the last line of text.
Useful in paragraphs to center the final line of justified text.

Direction and Unicode-Bidi

The direction property sets the text direction, while unicode-bidi ensures proper handling of bidirectional text.

  • direction: ltr (left-to-right) or rtl (right-to-left).
  • unicode-bidi: normal, embed, or bidi-override.
.rtl-text { direction: rtl; unicode-bidi: bidi-override; }
direction controls text flow, essential for languages like Arabic and Hebrew.
Set rtl for right-to-left languages.
Combine with unicode-bidi for mixed-direction text.
