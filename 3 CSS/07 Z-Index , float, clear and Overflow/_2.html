CSS Concepts

1. Z-Index

Description: The z-index property controls the stacking order of elements along the z-axis (depth). Higher z-index values bring elements closer to the viewer, while lower values move them farther back. Only works with positioned elements (with position set to absolute, relative, or fixed).

Example:

 
.box1 {
    position: absolute;
    z-index: 1;
    background-color: lightblue;
}

.box2 {
    position: absolute;
    z-index: 2;
    background-color: lightcoral;
}
Key Point: Use z-index for managing which elements overlap others.
Important Note: Z-index applies only to positioned elements.

2. Overflow

Description: The overflow property manages content that extends beyond the bounds of an element's container. Its values are:

  • hidden: Clips content that overflows, hiding it.
  • visible: Allows content to spill out beyond the container.
  • scroll: Adds scrollbars to see hidden content.
  • auto: Adds scrollbars only when necessary.

Example:

 
.container {
    width: 200px;
    height: 100px;
    overflow: hidden;
    background-color: lightgreen;
}
Key Point: Use overflow to manage how content behaves when it exceeds container size.

3. Float and Clear

Description: float is used to push an element to the left or right of its container, often wrapping other content around it. The clear property is used to control elements' behavior after floating ones.

  • left: Floats the element to the left.
  • right: Floats the element to the right.
  • clear: Stops floating on specified side (left, right, or both).

Example:

 
.left-float {
    float: left;
    width: 100px;
    height: 100px;
    background-color: lightcoral;
}

.clearfix {
    clear: both;
}
Key Point: float and clear are useful for layout adjustments.

4. CSS on Text

4.1 Text Align

Description: text-align aligns text within an element. Options:

  • center: Centers the text.
  • left: Aligns text to the left.
  • right: Aligns text to the right.
  • justify: Stretches text to fill the width.

Example:

 
.text-center {
    text-align: center;
}

4.2 Text-Align-Last

Description: The text-align-last property aligns the last line in a paragraph or block element.

Example:

 
.text-align-last-justify {
    text-align-last: justify;
}

4.3 Direction and Unicode Bidi

Description: The direction property defines text direction. unicode-bidi is used for handling bidirectional text (e.g., right-to-left languages).

Example:

 
.rtl {
    direction: rtl;
    unicode-bidi: bidi-override;
}
Key Point: direction and unicode-bidi are essential for multilingual text support.
