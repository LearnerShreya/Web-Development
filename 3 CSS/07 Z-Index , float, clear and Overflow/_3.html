In-Depth Guide to CSS Concepts

Z-Index

The z-index property controls the stacking order of elements along the z-axis (depth), determining which elements appear in front or behind others. This property only works on positioned elements (elements with position set to absolute, relative, fixed, or sticky).

Example:

.box1 { position: absolute; z-index: 1; background-color: lightblue; width: 100px; height: 100px; }
.box2 { position: absolute; z-index: 2; background-color: lightcoral; width: 100px; height: 100px; top: 20px; left: 20px; }

This code positions two boxes; the box with a higher z-index value appears in front.

Key Point: Higher z-index values bring elements to the front.
Use Case: Use z-index for modal dialogs, pop-ups, or layered images.
Note: z-index only applies to elements with a non-static position.

Overflow

The overflow property controls what happens to content that extends beyond its container's bounds. Options include:

  • hidden: Clips overflowed content.
  • visible: Allows content to overflow (default).
  • scroll: Adds scrollbars for overflowed content.
  • auto: Adds scrollbars only if content overflows.

Example:

.overflow-box { width: 200px; height: 100px; overflow: hidden; background-color: lightgreen; }

In this example, content exceeding 100px height is clipped because of overflow: hidden.

Key Point: Use overflow to manage visibility and scroll behavior.
Use Case: Containers with dynamic content that may exceed the designated size.
Note: Be mindful of overflow in fixed-height containers to avoid unwanted scrolling.

Float and Clear

The float property aligns elements to the left or right of their container, allowing text and inline elements to wrap around. The clear property prevents elements from wrapping around floated elements.

Example:

.floated { float: left; width: 100px; height: 100px; background-color: lightcoral; }
.cleared { clear: both; background-color: lightblue; padding: 10px; }

The floated element will sit beside text, while the cleared element starts below the float.

Key Point: Float helps wrap text around elements; clear resets this behavior.
Use Case: Float images beside text; use clear for content that shouldn't wrap around floats.
Note: Use clear: both; to avoid layout issues, especially in floated layouts.

CSS Text Properties

Text Align

The text-align property sets horizontal alignment for text within a block. Common values include:

  • center: Centers text.
  • left: Aligns text to the left.
  • right: Aligns text to the right.
  • justify: Stretches text to align with both sides.

Example:

.text-center { text-align: center; }

Using text-align: center centers the text within its container.

Key Point: Align text based on desired layout.

Text Decoration

The text-decoration property adds effects like underlining, line-through, or overlining text.

Example:

.underline { text-decoration: underline; }

Underlines text with text-decoration: underline.

Important Note: text-decoration: none; removes underline from links.
