How the Code Works

Here’s a simple explanation of what each property does:

  • place-items: center center; - This makes all boxes go to the center of each cell by default, both horizontally and vertically.
  • Now, let's change the position of specific boxes using align-self and justify-self:

Explanation of Individual Boxes:

  • Box 1:
    • align-self: start; - Moves it to the top of the cell (vertical alignment).
    • justify-self: left; - Moves it to the left side of the cell (horizontal alignment).
  • Box 2:
    • align-self: center; - Keeps it in the middle, both vertically and horizontally. Since it’s already centered by default, it stays in the middle of the cell.
  • Box 3:
    • align-self: end; - Moves it to the bottom of the cell, so it looks like it’s at the bottom.
  • Box 5:
    • align-self: start; - Moves it to the top of the cell (vertical alignment).
    • justify-self: left; - Moves it to the left side of the cell (horizontal alignment).
  • Box 6:
    • align-self: center; - Keeps it in the middle of the cell, just like Box 2.
  • Box 7:
    • align-self: end; - Moves it to the bottom of the cell, like Box 3.

Code Summary


.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(2, 1fr);
  gap: 1rem;
  place-items: center center; /* Centers all boxes in their cells */
}

.Box1 {
  align-self: start;
  justify-self: left;
}
.Box2 {
  align-self: center;
}
.Box3 {
  align-self: end;
}
.Box5 {
  align-self: start;
  justify-self: left;
}
.Box6 {
  align-self: center;
}
.Box7 {
  align-self: end;
}

By using align-self and justify-self, we can move boxes to different parts of each cell. align-self is for vertical movement (up or down), and justify-self is for horizontal movement (left or right).
