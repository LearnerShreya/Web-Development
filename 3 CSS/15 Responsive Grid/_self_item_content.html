CSS Grid: Justify and Align Properties

This guide explains the differences between the justify and align properties in CSS, specifically covering content, items, and self variants. These properties are used to align grid or flexbox elements along either the horizontal or vertical axes.

1. Justify vs. Align

Justify properties align elements along the inline (horizontal) axis, while Align properties align elements along the block (vertical) axis.

2. Content, Items, and Self Variants

  • justify-content / align-content: Aligns the entire grid or flex container within its parent.
  • justify-items / align-items: Aligns items within each grid cell.
  • justify-self / align-self: Aligns individual items within their cell or container.

3. justify-content and align-content

These properties control how the entire grid or flex container is positioned within its parent container.

.container {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  justify-content: center; /* Positions the whole grid container horizontally */
  gap: 10px;
}

4. justify-items and align-items

These properties align all items inside each grid cell. Here, justify-items centers items horizontally within each cell, while align-items centers them vertically.

.container {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  justify-items: center; /* Horizontally centers items in each cell */
  align-items: center;   /* Vertically centers items in each cell */
  gap: 10px;
}

5. justify-self and align-self

These properties control alignment of individual items within their cell, overriding any justify-items or align-items settings on the container.

.item:nth-child(1) {
  justify-self: start; /* Aligns item to the start horizontally */
  align-self: start;   /* Aligns item to the start vertically */
}
.item:nth-child(2) {
  justify-self: center; /* Centers item horizontally */
  align-self: center;   /* Centers item vertically */
}
.item:nth-child(3) {
  justify-self: end;    /* Aligns item to the end horizontally */
  align-self: end;      /* Aligns item to the end vertically */
}

Summary

  • justify-content: Positions the whole grid or flex container horizontally within its parent.
  • align-content: Positions the whole grid or flex container vertically within its parent.
  • justify-items: Aligns items horizontally within each grid cell.
  • align-items: Aligns items vertically within each grid cell.
  • justify-self: Aligns a single item horizontally within its cell, overriding justify-items.
  • align-self: Aligns a single item vertically within its cell, overriding align-items.

Alignment Properties

  • justify-content and align-content: Align the entire container within its parent.
    • justify-content: Aligns the container horizontally within the parent.
    • align-content: Aligns the container vertically within the parent.
  • justify-items and align-items: Align items within each cell of a grid or flex container.
    • justify-items: Aligns items horizontally within each cell.
    • align-items: Aligns items vertically within each cell.
  • justify-self and align-self: Set alignment for individual items within their cells, overriding container-level settings.
    • justify-self: Aligns a single item horizontally within its cell.
    • align-self: Aligns a single item vertically within its cell.
