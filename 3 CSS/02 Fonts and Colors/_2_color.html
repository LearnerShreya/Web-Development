CSS Color Guide

  1. Named Colors

    CSS allows you to use predefined color names like red, blue, green, etc., directly in your code. Named colors are easy to remember and great for basic styling.

    Example: color: red; or background-color: green;

    This would apply red text color or green background color.

  2. RGB Colors

    RGB stands for Red, Green, and Blue. Each color value ranges from 0 to 255, allowing you to create millions of color combinations. Use this format when you want precise color control.

    Example: color: rgb(255, 0, 0);

    This would produce a pure red color, with maximum red (255) and no green or blue.

  3. Hexadecimal Colors

    Hexadecimal colors start with a # followed by six characters. The characters represent red, green, and blue values in hexadecimal format (00-FF). This format is commonly used and supported widely in CSS.

    Example: color: #ff0000;

    This hex code creates red, where ff is the maximum red value, and both green and blue are 00.

  4. Alpha Transparency

    The alpha component adds transparency to colors in RGB and HSL formats, specified as RGBA or HSLA. Alpha ranges from 0 (completely transparent) to 1 (fully opaque).

    Example: background-color: rgba(255, 0, 0, 0.5);

    This would create a semi-transparent red background color, allowing underlying elements to partially show through.

  5. HSL Colors

    HSL stands for Hue, Saturation, and Lightness. Hue specifies the color (0-360 degrees), saturation represents intensity (0-100%), and lightness adjusts brightness (0% for black, 100% for white).

    • Hue: The actual color type (e.g., red, green, blue), represented by degrees on the color wheel (0 for red, 120 for green, 240 for blue).
    • Saturation: The color's intensity, from 0% (grayscale) to 100% (full color).
    • Lightness: The brightness level of the color, where 0% is black and 100% is white.
    Example: color: hsl(0, 100%, 50%);

    This produces a bright red color, where hue is 0 (red), saturation is fully intense (100%), and lightness is balanced at 50%.

  6. Background Color

    The background-color property applies color to an element's background. Any color format (named, RGB, hex, HSL) can be used.

    Example: background-color: lightblue;

    This would create a light blue background color.

  7. Background Properties

    These properties offer more control over background images:

    • background-size: cover;: Scales the background image to cover the entire element area.
    • background-repeat: no-repeat;: Prevents the background image from repeating.
    Example: background-size: cover; and background-repeat: no-repeat;

    Using these properties ensures the background image covers the entire element without repeating.
