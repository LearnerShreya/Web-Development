Complete Guide to CSS Font Properties (in Simple Terms)

CSS font properties help control the look of text on a webpage. Let’s go through each property step-by-step.

1. Font Family

Definition: The font-family property lets you choose the style of text, like "Arial," "Times New Roman," or "Verdana."

How it Works: You list several fonts as options. If the first font isn’t available, the browser tries the next one.

Example:

font-family: Arial, Helvetica, sans-serif;

Output: If "Arial" isn’t available, it will try "Helvetica," and if that’s also unavailable, it will use any sans-serif font.

This is an example of font-family with Arial, Helvetica, or sans-serif as fallback options.

2. Font Size

Definition: The font-size property changes the text size. You can use different units to adjust the size, like px, em, %, vh, and vw.

Common Units:

  • px - Sets a fixed size in pixels, like "16px".
  • em - Relative to the parent element.
  • rem - Relative to the root HTML element.
  • % - Relative to the parent element's font size.
  • vw and vh - Relative to the viewport width and height, respectively.

Example:

font-size: 24px;
font-size: 2em;
font-size: 5vw;
font-size: 5vh;

Output: Each line demonstrates different font sizes.

This text is 24px.
This text is 2em.
This text is 5vw.
This text is 5vh.

3. Font Weight

Definition: The font-weight property controls how thick or bold the text appears.

Values: `normal`, `bold`, or numeric values (100–900).

Example:

font-weight: bold;
font-weight: 300;

Output: Notice the difference in thickness.

This text is bold.
This text has a font weight of 300.

4. Font Style

Definition: The font-style property changes text style to regular, italic, or slanted (oblique).

Values: `normal`, `italic`, `oblique`.

Example:

font-style: italic;
font-style: oblique;

Output: Both examples show different types of slanted text.

This text is italic.
This text is oblique.

5. Font Variant

Definition: The font-variant property can display text in different styles, like small capital letters.

Values: `normal`, `small-caps`.

Example:

font-variant: small-caps;

Output: The text appears in small caps.

This text is in small-caps.

6. Line Height

Definition: The line-height property controls space between lines of text.

Values: `normal`, numeric values (like `1.5`).

Example:

line-height: 1.5;
line-height: 2;

Output: Notice the increased line spacing for better readability.

This text has a line height of 1.5.
Line height controls spacing between lines.
This text has a line height of 2.
Line height is helpful for readability in paragraphs.
