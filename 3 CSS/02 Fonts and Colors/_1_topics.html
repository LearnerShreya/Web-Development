    Selects only direct child elements of a specified parent element. Example: div > p { } styles <p> tags that are direct children of a <div>.

    General Rules for HTML Parent-Child Relationships

    1. Block Elements (<div>, <section>, <article>, <header>, <footer>, <main>, etc.):
      • Can contain both block and inline elements.
      • Used for large structure and layout sections.
    2. Inline Elements (<span>, <a>, <strong>, <em>, etc.):
      • Should contain only other inline elements or text.
      • Cannot directly contain block elements.
    3. Paragraphs (<p>):
      • Only inline elements or text should be inside <p>.
      • Block elements (like <div>, <ul>, or <h1>) are not allowed inside <p>.
    4. Headings (<h1> to <h6>):
      • Should contain only inline elements or text.
      • Block elements should not be placed inside headings.
    5. Lists (<ul>, <ol>):
      • Only <li> elements should be direct children of <ul> and <ol>.
      • <li> elements can contain both block and inline elements.
    6. Form (<form>):
      • Can contain various elements like <input>, <button>, <label>, <div>, and other block or inline elements for form layout.
    7. Document Structure:
      • <html> should contain <head> and <body> only.
      • <head> should contain metadata tags (<title>, <meta>, <style>, <link>, <script>).
      • <body> contains all visible content for the page.

    These rules help keep HTML well-structured, ensuring compatibility and accessibility across devices and browsers.

  2. CSS Color
    1. Named Color - Use color names like "red," "blue," "green," etc., to specify colors directly.
    2. RGB Color - Specify colors using Red, Green, Blue values. Example: rgb(255, 0, 0) for red.
    3. Hexadecimal Colors - Define colors using hex codes. Example: #ff0000 for red.
    4. Alpha - Controls transparency in colors. RGBA and HSLA are used, with values from 0 (fully transparent) to 1 (fully opaque).
    5. HSL Colors - Stands for Hue, Saturation, and Lightness.
      • Hue - The color type, measured as an angle from 0 to 360 degrees on the color wheel.
      • Saturation - The intensity of the color. 0% is grayscale; 100% is fully saturated.
      • Lightness - The brightness of the color. 0% is black; 100% is white.
      Example: hsl(0, 100%, 50%) for red.
    6. Background Color - Sets the background color of an element.
    7. Background Properties
      • background-size: cover; - Makes the background image cover the entire element.
      • background-repeat: no-repeat; - Prevents the background image from repeating.
  3. CSS Fonts

    Used to style text with different font properties like family, size, weight, and style. Here are some important CSS font properties:

    1. Font Family

      Defines the typeface of the text. Common choices are sans-serif, serif, monospace, etc. Example: font-family: Arial, sans-serif;

    2. Font Size

      Specifies the size of the text. You can use various units:

      • 10px - Pixels, fixed size
      • 2em - Relative to the parent element's font size
      • 3rem - Relative to the root element's font size
      • 120% - Percentage of the parent element's font size
      • 20vw - Viewport width, 20% of the viewport's width
      • 20vh - Viewport height, 20% of the viewport's height
    3. Font Weight

      Specifies the thickness of the text characters. Options include:

      • normal - Standard weight
      • bold - Bold weight
      • Numerical values (100 to 900) - Allows more control over the font's weight (e.g., font-weight: 300; for light, font-weight: 700; for bold)
    4. Font Style

      Specifies the style of the font. Options include:

      • normal - Default style
      • italic - Italicizes the text
      • oblique - A slanted version of the font, different from italic but visually similar
    5. Font Variant

      Specifies a variant of the font, such as small caps. Example: font-variant: small-caps;
