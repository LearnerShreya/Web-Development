JavaScript Notes: Numbers and Math

1. Numbers in JavaScript

In JavaScript, numbers can be of two types:

  • Primitive Number: A simple numeric value.
  • Number Object: A complex object created using the Number constructor.

Examples:


let num1 = 231; // Primitive Number
let num2 = new Number(231); // Number Object

Key differences:

  • num1 === num2 returns false because a primitive is not strictly equal to an object.
  • Use num1 == num2 for value comparison, which ignores the type difference.

2. Useful Number Methods

  • toFixed(n): Rounds a number to n decimal places.

    • Example:

    
let num = 231.6789;
console.log(num.toFixed(2)); // Output: 231.68
  • toPrecision(n): Formats the number to n significant digits.

    • Example:

    
console.log(num.toPrecision(3)); // Output: 232
  • toExponential(n): Converts the number to exponential notation.

    • Example:

    
console.log(num.toExponential(2)); // Output: 2.32e+2
  • toString(): Converts the number to a string.

    • Example:

    
console.log(num.toString()); // Output: "231.6789"
console.log(typeof num.toString()); // Output: "string"
  • valueOf(): Returns the primitive value of a Number object.

3. Math Object

3.1 Mathematical Constants

  • Math.E: Euler's number (~2.718).
  • Math.PI: Pi (~3.14159).
  • Math.LN10: Natural logarithm of 10 (~2.302).
  • Math.LOG10E: Logarithm base 10 of Euler's number (~0.434).

3.2 Common Math Methods

  • Math.floor(x): Rounds x down to the nearest integer.
  • Math.ceil(x): Rounds x up to the nearest integer.
  • Math.random(): Generates a random number between 0 (inclusive) and 1 (exclusive).

Examples:

Floor and Ceil:


let num = 29.7;
console.log(Math.floor(num)); // Output: 29
console.log(Math.ceil(num));  // Output: 30

Generate Random Numbers:


// Generate a random number between 1 and 10
console.log(Math.floor(Math.random() * 10) + 1);

// Generate a random number between 40 and 50
console.log(Math.floor(Math.random() * (50 - 40 + 1)) + 40);

4. Practical Applications

Using random numbers in games like a dice roll:


// Simulating a dice roll (1 to 6)
console.log(Math.floor(Math.random() * 6) + 1);
