Comprehensive JavaScript Notes: Numbers and Math

Understanding Numbers in JavaScript

In JavaScript, numbers can be represented in two ways:

  • Primitive Number: A simple numeric value like 231.
    Example: 
    let num1 = 231; // A primitive number
  • Number Object: A wrapped object created using the new Number() constructor.
    Example: 
    
let num2 = new Number(231); // A Number object
let num3 = new Number(231); // Another Number object
  1. Primitive vs Object Representation:
    • num1 is a primitive value directly holding the number 231.
    • num2 and num3 are Number objects with their own memory references.
  2. Output of Values:
    • num1 directly outputs the value: 231.
    • num2 and num3 display their wrapped representation: [Number: 231].
    
console.log(num1); // Output: 231
console.log(num2); // Output: [Number: 231]
console.log(num3); // Output: [Number: 231]
  3. Equality (==) vs Strict Equality (===):
    • Loose Equality (==): Converts both operands to the same type before comparing. Example: 
      console.log(num1 == num2); // true
    • Strict Equality (===): Compares both value and type without type conversion. Example: 
      console.log(num1 === num2); // false
  4. Object Reference Comparison:
    • When comparing Number objects like num2 and num3, JavaScript checks their references, not their values.
    console.log(num2 == num3); // false
  5. Type Checking with typeof:
    • num1 is a primitive number: typeof num1 returns "number".
    • num2 and num3 are Number objects: typeof returns "object".
    
console.log(typeof num1); // Output: number
console.log(typeof num2); // Output: object
console.log(typeof num3); // Output: object

    6. Summary

    - Primitive numbers are simple values (e.g., 231).
    - Number objects are special wrapped objects with unique references.
    - Use == for loose comparison and === for strict comparison.
    - Objects are compared by reference, not value.

2. Number Methods

JavaScript provides several methods to work with numbers. Here are some common ones:

2.1. toFixed(n)

Rounds the number to n decimal places and returns it as a string.


let num = 231.6789;
console.log(num.toFixed(2));  // Output: "231.68"

2.2. toPrecision(n)

Formats the number to n significant digits and returns it as a string.


console.log(num.toPrecision(3));  // Output: "232"

2.3. toExponential(n)

Converts the number to exponential notation with n digits after the decimal point.


console.log(num.toExponential(2));  // Output: "2.32e+2"

2.4. toString()

Converts the number to a string.


console.log(num.toString());  // Output: "231.6789"
console.log(typeof num.toString());  // Output: "string"

2.5. valueOf()

Returns the primitive value of a Number object.


let numObject = new Number(42);
console.log(numObject.valueOf());  // Output: 42

3. The Math Object

The Math object in JavaScript provides a set of built-in methods for performing mathematical tasks such as rounding, generating random numbers, and more.

3.1. Mathematical Constants

  • Math.E: Euler's constant (~2.718).
  • Math.PI: The value of Pi (~3.14159).
  • Math.LN10: The natural logarithm of 10 (~2.302).
  • Math.LOG10E: The logarithm base 10 of Euler's constant (~0.434).

3.2. Random Numbers

Math.random() generates a random floating-point number between 0 (inclusive) and 1 (exclusive). To generate random numbers in a specific range, we can scale the result.


// Generate a random number between 1 and 10
console.log(Math.floor(Math.random() * 10) + 1);

// Generate a random number between 40 and 50
console.log(Math.floor(Math.random() * (50 - 40 + 1)) + 40);

// Generate a random number between 1 and 6 (for a dice roll)
console.log(Math.floor(Math.random() * 6) + 1);

3.3. Rounding Methods

  • Math.floor(x): Rounds x down to the nearest integer.
  • Math.ceil(x): Rounds x up to the nearest integer.
  • Math.round(x): Rounds x to the nearest integer.

let num1 = 29.7;
console.log(Math.floor(num1));  // Output: 29
console.log(Math.ceil(num1));   // Output: 30
console.log(Math.round(num1));  // Output: 30

3.4. Absolute Value

Math.abs(x) returns the absolute value of a number.


console.log(Math.abs(-42));  // Output: 42
console.log(Math.abs(42));   // Output: 42

3.5. Maximum and Minimum

Math.max(...values) returns the largest value, while Math.min(...values) returns the smallest value in a list of numbers.


console.log(Math.max(1, 2, 3, 4, 5));  // Output: 5
console.log(Math.min(1, 2, 3, 4, 5));  // Output: 1

4. Practical Examples

4.1. Generating Random Numbers Between Two Values

To generate a random number between two values, min and max, you can use the following formula:


let min = 40;
let max = 50;
console.log(Math.floor(Math.random() * (max - min + 1)) + min);

4.2. Simulating a Dice Roll

To simulate a dice roll (numbers between 1 and 6), we can use:


console.log(Math.floor(Math.random() * 6) + 1);

4.3. Converting Degrees to Radians

To convert an angle from degrees to radians, use the formula:


let degree = 45;
let radians = degree * Math.PI / 180;
console.log(radians);  // Output: 0.7853981633974483
