Type Conversion in JavaScript - Notes

1. Types of Type Conversion

Type conversion in JavaScript can be classified into two types:

  • Implicit Type Conversion (Type Coercion): Automatically done by JavaScript.
  • Explicit Type Conversion (Type Casting): Manually done by the programmer.

2. Implicit Type Conversion

JavaScript automatically converts one data type to another during certain operations.

Examples:

"5" - 2: Converts "5" (String) to Number. Result: 3.

"5" + 2: Converts 2 (Number) to String. Result: "52".

true + 1: Converts true (Boolean) to 1. Result: 2.

null + 1: Converts null to 0. Result: 1.

undefined + 1: Result: NaN (Undefined cannot be converted to a valid number).

Examples and Explanations

  1. "5" - 2

    • The - operator expects numbers.
    • JavaScript converts the string "5" into a number 5.
    • Performs subtraction: 5 - 2 = 3.
    Result: 3.

  2. "5" + 2

    • The + operator is used for both:
      • Concatenation (if one operand is a string).
      • Addition (if both operands are numbers).
    • Since "5" is a string, JavaScript converts 2 into a string "2".
    • Concatenates the two strings: "5" + "2" = "52".
    Result: "52".

  3. true + 1

    • The + operator expects numbers for addition.
    • JavaScript converts true (boolean) into its numeric equivalent: 1.
    • Adds the two numbers: 1 + 1 = 2.
    Result: 2.

  4. null + 1

    • The + operator expects numbers for addition.
    • JavaScript converts null into its numeric equivalent: 0.
    • Adds the two numbers: 0 + 1 = 1.
    Result: 1.

  5. undefined + 1

    • The + operator expects numbers for addition.
    • JavaScript tries to convert undefined into a number, but undefined cannot be converted to a valid number.
    • Result is NaN (Not a Number).
    Result: NaN.

Why These Conversions Happen

JavaScript is a loosely typed language, meaning it automatically converts (coerces) data types during operations.

The conversion depends on:

  • Operator: Different operators like + or - expect specific types (numbers or strings).
  • Operand Types: The presence of strings, booleans, null, or undefined influences how coercion happens.

3. Explicit Type Conversion

Explicit type conversion is performed using built-in methods in JavaScript.

3.1 Convert to String

String(123): Converts Number to String. Result: "123".

(123).toString(): Another way to convert Number to String. Result: "123".

3.2 Convert to Number

Number("123"): Converts String to Number. Result: 123.

parseInt("123px"): Extracts integer value. Result: 123.

parseFloat("123.45px"): Extracts decimal value. Result: 123.45.

3.3 Convert to Boolean

Boolean(1): Converts 1 to true.

Boolean(0): Converts 0 to false.

Boolean("hello"): Converts non-empty string to true.

4. Common Use Cases

4.1 String Concatenation

"The result is: " + 42: Converts Number to String. Result: "The result is: 42".

4.2 Arithmetic Operations

"10" - 5: Converts "10" to Number. Result: 5.

"10" * 2: Converts "10" to Number. Result: 20.

4.3 Comparison

"123" == 123: Performs type coercion. Result: true.

"123" === 123: Strict comparison, no coercion. Result: false.
