Primitive Data Types in JavaScript

Primitive data types are the most basic data types in JavaScript. They represent single immutable values and are directly assigned to a variable.

Key Features:

  • Simple structure: Represent a single value (e.g., a number, string, or boolean).
  • Immutable: Their values cannot be altered after creation.
  • Stored by value: The variable directly holds the data.

Examples:

  1. Number: Represents numeric values (e.g., 42, 3.14).
  2. String: Represents a sequence of characters (e.g., "Hello", 'World').
  3. Boolean: Represents true or false values.
  4. Undefined: A variable that has been declared but not assigned a value.
  5. Null: Represents the absence of any value.
  6. Symbol: A unique and immutable value used as object keys.
  7. BigInt: Represents integers larger than Number.MAX_SAFE_INTEGER.

Non-Primitive Data Types in JavaScript

Non-primitive data types, also known as reference types, are objects that can store collections of values or more complex entities.

Key Features:

  • Complex structure: Can store multiple values or represent collections.
  • Mutable: Their properties or contents can be changed.
  • Stored by reference: The variable holds a reference to the memory location.

Examples:

  1. Object: A collection of key-value pairs (e.g., {name: "John", age: 30}).
  2. Array: An ordered list of values (e.g., [1, 2, 3]).
  3. Function: A reusable block of code.
  4. Class: A blueprint for creating objects.
  5. Date: Represents dates and times.

Non-Primitive Data Types in JavaScript

JavaScript provides several non-primitive data types that allow developers to store and manipulate complex data structures. These data types include Arrays, Objects, and Functions. Let’s explore each in detail.

1. Array

Definition: An Array is a collection of elements that are stored in a single variable and are accessed using an index. Arrays can hold values of any data type, such as strings, numbers, objects, or even other arrays.

Example: let arr = [10, 20, 50, "Rohit", "Mohit"];

Key Features:

  • Arrays are indexed, starting from 0.
  • They can store heterogeneous data types (e.g., numbers, strings, objects).
  • Support dynamic resizing, i.e., you can add or remove elements.
  • Provide various built-in methods like push(), pop(), map(), and filter().

Common Array Methods:

  • push(): Adds an element to the end of the array.
  • pop(): Removes the last element.
  • shift(): Removes the first element.
  • unshift(): Adds an element to the beginning.
  • map(): Creates a new array by applying a function to each element.

Example:

const fruits = ['Apple', 'Banana', 'Cherry'];
console.log(fruits[1]); // Output: Banana

fruits.push('Orange'); // Adds Orange to the array
console.log(fruits); // Output: ['Apple', 'Banana', 'Cherry', 'Orange']

fruits.pop(); // Removes the last element
console.log(fruits); // Output: ['Apple', 'Banana', 'Cherry']

2. Object

Definition: An Object is a data structure that represents a collection of properties. Each property is defined as a key-value pair. Objects are widely used to model real-world entities and store structured data.

Key Features:

  • Properties are defined using key: value pairs.
  • Keys are typically strings or symbols, while values can be of any data type.
  • Objects are mutable, meaning their properties can be added, modified, or deleted.
  • They can have methods, i.e., functions as values.

Creating Objects:

  • Using Object Literals: const obj = { key: value };
  • Using Constructor: const obj = new Object();

Example:

const car = {
    brand: 'Tesla',
    model: 'Model S',
    year: 2023,
    drive: function() {
        console.log('The car is driving');
    }
};

console.log(car.brand); // Output: Tesla
car.drive(); // Output: The car is driving

car.color = 'Red'; // Adding a new property
console.log(car); // Output: { brand: 'Tesla', model: 'Model S', year: 2023, drive: [Function: drive], color: 'Red' }

3. Function

Definition: A Function is a reusable block of code designed to perform a specific task. Functions are used to organize code, reduce redundancy, and improve reusability.

Key Features:

  • Functions can take parameters and optionally return a value.
  • They can be named or anonymous.
  • Arrow functions (=>) provide a concise syntax.
  • Functions can be passed as arguments to other functions (higher-order functions).

Types of Functions:

  • Named Function: Declared with a name and invoked using that name.
  • Anonymous Function: Does not have a name and is often assigned to a variable.
  • Arrow Function: A shorthand syntax for functions using =>.

Example:

// Named Function
function greet(name) {
    return `Hello, ${name}!`;
}
console.log(greet('Shreya')); // Output: Hello, Shreya!

// Anonymous Function
const add = function(a, b) {
    return a + b;
};
console.log(add(5, 3)); // Output: 8

// Arrow Function
const multiply = (x, y) => x * y;
console.log(multiply(4, 2)); // Output: 8

Conclusion

Non-primitive data types in JavaScript such as Arrays, Objects, and Functions provide the flexibility to handle complex data and functionalities. Mastering these concepts is crucial for effective JavaScript programming.
