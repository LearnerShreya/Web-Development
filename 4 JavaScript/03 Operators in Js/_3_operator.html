JavaScript Operation Rules

JavaScript is a versatile language that follows specific rules while performing operations. Understanding how JavaScript handles different types of operations, precedence, type conversion, and evaluation rules is critical for writing correct and efficient code. This document explains the core operation rules in JavaScript.

1. Operator Precedence

Operator precedence determines the order in which operators are evaluated in an expression. Operators with higher precedence are evaluated first. If operators have the same precedence, they are evaluated based on their associativity (either left-to-right or right-to-left).

The following table lists the operators in order of precedence, from highest to lowest:

Operator Precedence Level Associativity Example Result
() [] . Highest Left to Right 5 + (2 * 3) 11
++ -- Higher Right to Left ++x Increment variable x before use
! ~ typeof void Higher Right to Left !true false
* / % Medium Left to Right 5 * 3 15
+ - Medium Left to Right 5 - 2 3
&& || Lower Left to Right true && false false
== != === !== Low Left to Right 5 == '5' true
= += -= *= /= Lowest Right to Left x = 5 x is assigned 5

2. Type Coercion and Conversion

JavaScript performs automatic type conversion (also known as coercion) when performing operations with different data types. This means that JavaScript will try to convert one type into another when needed. Below are some common rules of type conversion:

String + Number

If one of the operands is a string, the other operand is converted to a string, and concatenation occurs.

Expression Result
'5' + 2 '52' (String)
'Hello' + 5 'Hello5' (String)

String - Number

If one of the operands is a string and the other is a number, JavaScript will attempt to convert the string to a number. If conversion fails, the result is NaN.

Expression Result
'5' - 2 3 (Number)
'5' - '2' 3 (Number)
'5' - 'hello' NaN (Not-a-Number)

Boolean to Number

Boolean values are coerced to numbers when used in arithmetic operations. True becomes 1 and false becomes 0.

Expression Result
true + 1 2 (Number)
false + 1 1 (Number)

Null to Number

Null is coerced to 0 when used in numeric operations.

Expression Result
null + 1 1 (Number)

Undefined to Number

Undefined results in NaN when coerced to a number.

Expression Result
undefined + 1 NaN (Not-a-Number)

NaN Behavior

The value NaN (Not-a-Number) is returned when an operation cannot produce a valid number. It's important to note that NaN is not equal to any other number, even itself.

Expression Result
NaN === NaN false
isNaN(NaN) true

Equality Comparison

In JavaScript, the == operator performs type coercion, while === checks both value and type equality.

Expression Result
5 == '5' true (Loose equality)
5 === '5' false (Strict equality)

Short-circuit Evaluation

In logical operations, JavaScript can evaluate expressions with short-circuit behavior. For example, in an OR operation, if the first operand is true, the second operand is not evaluated.

Expression Result
true || false true
false && true false

3. Comparison Operators

JavaScript provides comparison operators that allow you to compare values. These operators include:

Operator Meaning Example Result
== Loose Equality 5 == '5' true
=== Strict Equality (checks value and type) 5 === '5' false
!= Loose Inequality 5 != '5' false
!== Strict Inequality (checks value and type) 5 !== '5' true
> Greater than 5 > 3 true
< Less than 5 < 3 false
>= Greater than or equal to 5 >= 3 true
<= Less than or equal to 5 <= 3 false

Note:

Be cautious when using loose equality (==) because it performs type coercion. It is generally recommended to use strict equality (===) to avoid unexpected behavior.

JavaScript Operators - Detailed Notes

In JavaScript, operators are symbols that perform operations on values and variables. They are classified into various types:

1. Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

Operator Description Example Output
+ Addition: Adds two operands. 5 + 3 8
- Subtraction: Subtracts the right operand from the left operand. 5 - 3 2
* Multiplication: Multiplies two operands. 5 * 3 15
/ Division: Divides the left operand by the right operand. 5 / 2 2.5
% Modulus: Returns the remainder of a division operation. 5 % 2 1
** Exponentiation: Raises the base (left operand) to the power of the exponent (right operand). 5 ** 2 25

2. Assignment Operators

Assignment operators are used to assign values to variables.

Operator Description Example Output
= Simple Assignment: Assigns the value on the right to the variable on the left. let a = 5 a = 5
+= Addition Assignment: Adds the right operand to the left operand and assigns the result to the left operand. a += 3 a = 8
-= Subtraction Assignment: Subtracts the right operand from the left operand and assigns the result to the left operand. a -= 3 a = 2
*= Multiplication Assignment: Multiplies the left operand by the right operand and assigns the result to the left operand. a *= 3 a = 15
/= Division Assignment: Divides the left operand by the right operand and assigns the result to the left operand. a /= 3 a = 1.6667
%= Modulus Assignment: Assigns the remainder of the division of the left operand by the right operand to the left operand. a %= 3 a = 2

3. Comparison Operators

Comparison operators are used to compare two values or expressions.

Operator Description Example Output
== Equal to: Returns true if the operands are equal. 5 == 5 true
=== Strict equal to: Returns true if the operands are equal and of the same type. 5 === "5" false
!= Not equal to: Returns true if the operands are not equal. 5 != 3 true
!== Strict not equal to: Returns true if the operands are not equal or not of the same type. 5 !== "5" true
> Greater than: Returns true if the left operand is greater than the right operand. 5 > 3 true
< Less than: Returns true if the left operand is less than the right operand. 5 < 3 false
>= Greater than or equal to: Returns true if the left operand is greater than or equal to the right operand. 5 >= 3 true
<= Less than or equal to: Returns true if the left operand is less than or equal to the right operand. 5 <= 3 false

4. Logical Operators

Logical operators are used to perform logical operations, mostly with Boolean values.

Operator Description Example Output
&& Logical AND: Returns true if both operands are true. true && false false
|| Logical OR: Returns true if at least one of the operands is true. true || false true
! Logical NOT: Reverses the logical state of its operand. Returns true if the operand is false, and false if the operand is true. !true false

5. Ternary Operator

The ternary operator is a shorthand for the if-else statement. It takes three operands.

Operator Description Example Output
condition ? expr1 : expr2 Returns expr1 if the condition is true; otherwise, returns expr2. 5 > 3 ? "Yes" : "No" Yes

6. Type Operators

Type operators are used to check or convert the data types of values.

Operator Description Example Output
typeof Returns the type of a variable. typeof 5 number
instanceof Checks whether an object is an instance of a particular class. [1, 2, 3] instanceof Array true

7. Increment and Decrement Operators

These operators are used to increase or decrease the value of a variable by 1.

Operator Description Example Output
++ Increment: Increases the value of a variable by 1. let a = 5; a++ a = 6
-- Decrement: Decreases the value of a variable by 1. let a = 5; a-- a = 4

8. Bitwise Operators

These operators perform bit-level operations on operands.

Operator Description Example Output
& Bitwise AND: Performs a logical AND operation on each pair of corresponding bits in two numbers. let a = 5; let b = 3; a & b 1 (Binary: 0101 & 0011 = 0001)
| Bitwise OR: Performs a logical OR operation on each pair of corresponding bits in two numbers. let a = 5; let b = 3; a | b 7 (Binary: 0101 | 0011 = 0111)
^ Bitwise XOR: Performs a logical XOR operation on each pair of corresponding bits in two numbers. let a = 5; let b = 3; a ^ b 6 (Binary: 0101 ^ 0011 = 0110)
~ Bitwise NOT: Inverts each bit of a number. let a = 5; ~a -6 (Binary: ~0101 = 1010, in two's complement = -6)
<< Left Shift: Shifts bits of a number to the left, filling with zeros. let a = 5; a << 1 10 (Binary: 0101 << 1 = 1010)
>> Right Shift: Shifts bits of a number to the right, keeping the sign bit intact. let a = 5; a >> 1 2 (Binary: 0101 >> 1 = 0010)
>>> Zero-fill Right Shift: Shifts bits of a number to the right, filling with zeros. let a = 5; a >>> 1 2 (Binary: 0101 >>> 1 = 0010)

Note: JavaScript's dynamic typing means you don't need to declare a variable's type explicitly. The type of a variable is determined based on the value it holds. Operators like typeof help you check a variable's type at runtime.

Conclusion

Understanding these operators and their behavior is essential for writing clean and efficient JavaScript code. They help in manipulating data, making decisions, and performing mathematical, logical, and comparison operations.
