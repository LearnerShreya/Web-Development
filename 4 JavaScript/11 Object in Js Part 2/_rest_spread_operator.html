Difference Between Rest and Spread Operator

The ... operator in JavaScript can act as either the rest or spread operator, depending on the context.

1. Rest Operator (...)

Purpose: Collects multiple elements or properties into a single entity (e.g., an array or object).

Use Cases: Used in array/object destructuring or function arguments to group remaining items.

Examples:

// In Array Destructuring
const arr = [1, 2, 3, 4];
const [first, ...rest] = arr; 
// 'first' = 1, 'rest' = [2, 3, 4]
// In Function Parameters
function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}
console.log(sum(1, 2, 3)); // Output: 6
// In Object Destructuring
const obj = { a: 1, b: 2, c: 3 };
const { a, ...rest } = obj;
// 'a' = 1, 'rest' = { b: 2, c: 3 }

2. Spread Operator (...)

Purpose: Expands elements or properties from an array or object into individual items.

Use Cases: Used in function calls, array/object literals to distribute the items/properties.

Examples:

// In Arrays
const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = [...arr1, ...arr2];
// 'combined' = [1, 2, 3, 4]
// In Objects
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };
const combined = { ...obj1, ...obj2 };
// 'combined' = { a: 1, b: 2, c: 3, d: 4 }
// In Function Calls
const numbers = [1, 2, 3];
console.log(Math.max(...numbers)); // Output: 3

Key Differences

Aspect Rest Operator Spread Operator
Purpose Combines multiple elements into one (e.g., collect remaining array items). Expands one entity into multiple elements (e.g., split an array into arguments).
Context Used in destructuring or function arguments. Used in literals or function calls.
Output Creates an array or object from remaining items. Distributes elements or properties as individual items.

Quick Summary: Rest combines, Spread expands!

  1. Rest (...): Combines multiple elements into one (e.g., collect remaining array items).
  2. Spread (...): Expands one entity into multiple elements (e.g., split an array into arguments).
