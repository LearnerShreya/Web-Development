Understanding Primitive and Non-Primitive Data Types

Primitive Data Types

Primitive data types represent single values such as numbers, strings, booleans, etc. Variables declared with const for primitive data types cannot be reassigned after initialization.

Key Points:

  • const ensures immutability for primitive values.
  • Attempting to reassign a constant primitive value throws a TypeError.

Example:


// Declaring a constant primitive value
const num = 10;

// Trying to reassign the constant value
// num = 20; // Uncommenting this line will cause a TypeError: Assignment to constant variable.

console.log(num); // Output: 10

Non-Primitive Data Types

Non-primitive data types, such as objects and arrays, store references rather than values. While a const object or array reference cannot be reassigned, its contents (properties or elements) can be modified.

Key Points:

  • Objects declared with const allow modifications to their properties but not their reference.
  • The structure of the object or array remains the same, while individual elements or properties can change.

Example:


// Declaring a constant object
const obj = {
    id: 10,
    balance: 7654321
};

// Modifying the properties of the object
obj.id = 20;

console.log(obj); // Output: { id: 20, balance: 7654321 }

// Attempting to reassign the constant reference
let obj2 = { id: 15, balance: 87654321 };
// obj = obj2; // Uncommenting this line will cause a TypeError: Assignment to constant variable.

String Literals

Strings can be defined using double quotes ("), single quotes ('), or template literals (`).

Template literals allow multi-line strings and string interpolation using ${...}.

Example:


let str1 = "Hello, World!";
let str2 = 'I am learning JavaScript.';
let str3 = `This is a template literal.
It can span multiple lines.`;

console.log(str1); // Output: Hello, World!
console.log(str2); // Output: I am learning JavaScript.
console.log(str3); // Output: This is a template literal.
// It can span multiple lines.

Conclusion

Using const ensures immutability for primitive values and prevents reassignment of references for non-primitive types. However, non-primitive types allow property or element modification. Template literals provide a flexible way to handle strings, especially when multiline strings or interpolations are required.
