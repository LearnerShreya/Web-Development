Comprehensive Notes on JavaScript Date and Time

A Detailed Guide to Master Date and Time Handling in JavaScript

Introduction to Date and Time

The Date object in JavaScript is used to work with dates and times. It is a built-in object that provides various methods to create, manipulate, and format date and time values.

All dates are calculated in **milliseconds** since January 1, 1970, UTC (Unix Epoch Time).

Creating Dates

You can create a date using the Date constructor in different ways:

  • Current Date and Time: new Date()
  • Specific Date: new Date("2024-12-01")
  • Date Components: new Date(year, month, day, hour, minute, second, millisecond)
  • Milliseconds since Epoch: new Date(1609459200000)
// Example
const currentDate = new Date();
const specificDate = new Date("2024-12-01");
const componentsDate = new Date(2024, 11, 1, 10, 30, 15);
const epochDate = new Date(1609459200000);

console.log(currentDate);  // Current Date
console.log(specificDate); // Dec 01, 2024
console.log(componentsDate); // Dec 01, 2024, 10:30:15
console.log(epochDate);     // Jan 01, 2021

Retrieving Date and Time Components

Use the following methods to retrieve parts of a date:

Method Description Example
getFullYear() Returns the year. 2024
getMonth() Returns the month (0-11). 11
getDate() Returns the day of the month (1-31). 1
getDay() Returns the day of the week (0-6). 3
getHours() Returns the hour (0-23). 10

Formatting Dates

JavaScript provides several methods to format dates:

  • toDateString(): Converts the date to a readable format.
  • toLocaleDateString(): Converts the date to a locale-specific format.
  • toISOString(): Converts the date to ISO format.
// Example
const date = new Date();
console.log(date.toDateString());    // "Wed Dec 02 2024"
console.log(date.toLocaleDateString()); // "12/2/2024" (varies by locale)
console.log(date.toISOString());    // "2024-12-02T10:30:15.000Z"

Working with Time Zones

By default, JavaScript works in the local timezone. You can use UTC methods to work with UTC dates:

  • toUTCString(): Converts the date to UTC format.
  • getTimezoneOffset(): Returns the timezone difference in minutes.
