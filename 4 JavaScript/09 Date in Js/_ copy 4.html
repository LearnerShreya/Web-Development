Introduction

The Date object in JavaScript is a powerful tool for handling dates and times. It allows developers to create, format, and manipulate time values with ease.

Creating Dates

You can create a date using the following methods:

Constructor Example Description
Current Date new Date() Creates the current date and time.
Specific Date new Date("2024-12-01") Creates a date from a string.
Milliseconds new Date(1609459200000) Creates a date from a timestamp.

Retrieving Components

Use the following methods to extract parts of a date:

  • getFullYear(): Returns the year.
  • getMonth(): Returns the month (0-11).
  • getDate(): Returns the day of the month (1-31).

Manipulating Dates

To modify a date, use setter methods like setFullYear(), setMonth(), or setDate().

Formatting Dates

To display dates in readable formats, use methods like toDateString() or toLocaleDateString().

Working with Timezones

JavaScript dates are timezone-aware and can be adjusted to UTC using toUTCString().

Code Examples


const date = new Date();
console.log(date.toString());
