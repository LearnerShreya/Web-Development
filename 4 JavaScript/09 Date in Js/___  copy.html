Comprehensive JavaScript Date Object Notes

Creating Dates

The Date object in JavaScript allows you to work with dates and times. Here are various ways to create a Date object:

  • Current Date and Time: 
    const now = new Date();
    Retrieves the current date and time.
  • Specific Date: 
    const specificDate = new Date(2024, 10, 29);
    Creates a date object for November 29, 2024 (months are 0-indexed, so 10 = November).
  • Date from String: 
    const dateFromString = new Date("2024-11-29");
    Parses a date string and creates the corresponding date object.
  • Using Timestamps: 
    const fromTimestamp = new Date(1732845690000);
    Creates a date object from a timestamp in milliseconds since January 1, 1970 (Unix Epoch).

Accessing Date & Time Components

The Date object provides methods to access individual components of the date and time:

  • Year: now.getFullYear(); – Returns the year (e.g., 2024).
  • Month: now.getMonth(); – Returns the month (0-11, where 0 = January).
  • Day of the Month: now.getDate(); – Returns the day of the month (1-31).
  • Day of the Week: now.getDay(); – Returns the day of the week (0-6, where 0 = Sunday).
  • Hour: now.getHours(); – Returns the hour (0-23).
  • Minutes: now.getMinutes(); – Returns the minutes (0-59).
  • Seconds: now.getSeconds(); – Returns the seconds (0-59).
  • Milliseconds: now.getMilliseconds(); – Returns the milliseconds (0-999).

Setting Date Components

You can modify the components of an existing date using the set methods:

  • Set Year: date.setFullYear(2030); – Updates the year.
  • Set Month: date.setMonth(5); – Updates the month to June (5 = June).
  • Set Day: date.setDate(15); – Updates the day of the month to 15.
  • Set Hour: date.setHours(10); – Updates the hour to 10 AM.
  • Set Minutes: date.setMinutes(45); – Updates the minutes to 45.
  • Set Seconds: date.setSeconds(30); – Updates the seconds to 30.

Example:


const date = new Date();
date.setFullYear(2030);
console.log(date); // Updated date

Formatting Dates

The Date object offers various methods to format dates:

  • Full String: date.toString(); – e.g., Fri Nov 29 2024 10:30:00 GMT+0530 (India Standard Time)
  • ISO Format: date.toISOString(); – e.g., 2024-11-29T05:00:00.000Z
  • UTC Format: date.toUTCString(); – e.g., Fri, 29 Nov 2024 05:00:00 GMT
  • Locale Date: date.toLocaleDateString(); – e.g., 11/29/2024
  • Locale Time: date.toLocaleTimeString(); – e.g., 10:30:00 AM
  • Locale Date & Time: date.toLocaleString(); – e.g., 11/29/2024, 10:30:00 AM

Date Calculations

You can perform arithmetic operations on dates:

  • Difference Between Dates:
    • 
const date1 = new Date("2024-11-01");
const date2 = new Date("2024-11-29");
const difference = date2 - date1; // Difference in milliseconds
console.log(difference / (1000 * 60 * 60 * 24)); // Days difference
  • Add Days to a Date:
    • 
const date = new Date();
date.setDate(date.getDate() + 7); // Adds 7 days
console.log(date); // Updated date
