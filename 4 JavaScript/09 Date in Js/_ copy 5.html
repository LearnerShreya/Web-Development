JavaScript Date and Time

A Comprehensive Guide to Working with Dates and Times

What is the JavaScript Date Object?

The Date object in JavaScript is used to work with dates and times. It allows you to create, retrieve, and manipulate date and time values efficiently.

  • Introduced in ECMAScript 1 (ES1).
  • Handles both local time and UTC (Coordinated Universal Time).
  • Stored internally as the number of milliseconds since January 1, 1970 (Unix Epoch).

Creating Date Objects

You can create a Date object using the following methods:

Constructor Syntax Description
Current Date and Time new Date() Creates a Date object with the current date and time.
Specific Date new Date("YYYY-MM-DD") Creates a Date object from a string.
Year, Month, Day new Date(year, month, day) Creates a Date object using numeric components.
Milliseconds new Date(milliseconds) Creates a Date object from a Unix timestamp.

Retrieving Date Components

You can extract specific parts of a date using getter methods:

  • getFullYear(): Retrieves the year (e.g., 2024).
  • getMonth(): Retrieves the month (0-based: 0 for January, 11 for December).
  • getDate(): Retrieves the day of the month (1-31).
  • getDay(): Retrieves the day of the week (0 for Sunday, 6 for Saturday).
  • getHours(), getMinutes(), getSeconds(), getMilliseconds(): Retrieves time components.

const now = new Date();
console.log(now.getFullYear()); // Outputs: 2024
console.log(now.getMonth());    // Outputs: 11 (December)
console.log(now.getDate());     // Outputs: 1

Manipulating Date and Time

Use setter methods to modify date components:

  • setFullYear(year): Sets the year.
  • setMonth(month): Sets the month (0-based).
  • setDate(day): Sets the day of the month.
  • setHours(hours), setMinutes(minutes): Sets time components.

const myDate = new Date();
myDate.setFullYear(2025);
myDate.setMonth(0); // January
myDate.setDate(15);
console.log(myDate); // Outputs: "2025-01-15T..."

Formatting Dates

JavaScript provides methods to format dates:

  • toDateString(): Returns a readable string (e.g., "Mon Dec 1 2024").
  • toISOString(): Returns a date in ISO format (e.g., "2024-12-01T00:00:00.000Z").
  • toLocaleDateString(): Returns a localized date string based on your locale.

const today = new Date();
console.log(today.toDateString());       // Outputs: "Sun Dec 1 2024"
console.log(today.toISOString());        // Outputs: "2024-12-01T00:00:00.000Z"
console.log(today.toLocaleDateString()); // Outputs a localized string

Working with Timezones

JavaScript dates are timezone-aware. You can work with UTC or local time:

  • getUTCFullYear(), getUTCHours(): Retrieve UTC components.
  • toUTCString(): Converts the date to a UTC string.
