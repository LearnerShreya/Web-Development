JavaScript Date and Time

Introduction

The Date object in JavaScript is used to handle dates and times. It provides methods to perform operations like getting and setting dates, manipulating time zones, and more.

Creating Date Objects

There are several ways to create a Date object:

  • Current Date and Time:
    • let currentDate = new Date();
  • Specific Date:
    • let specificDate = new Date("2024-12-01");
  • Using Year, Month, Day, etc.:
    • let customDate = new Date(2024, 11, 1, 10, 30, 0);

Getting Date and Time Components

Methods to retrieve specific components of the date:

  • getFullYear(): Returns the year.
  • getMonth(): Returns the month (0-11).
  • getDate(): Returns the day of the month.
  • getDay(): Returns the day of the week (0-6).
  • getHours(), getMinutes(), getSeconds(), getMilliseconds(): Return respective time components.

let now = new Date();
console.log(now.getFullYear()); // Example: 2024
console.log(now.getMonth());    // Example: 11 (December)
console.log(now.getDate());     // Example: 1
console.log(now.getDay());      // Example: 0 (Sunday)

Formatting Date and Time

JavaScript allows formatting using various methods:

  • toDateString(): Converts the date to a readable string.
  • toISOString(): Returns ISO format (e.g., 2024-12-01T00:00:00.000Z).
  • toLocaleDateString(): Formats the date based on locale settings.

let today = new Date();
console.log(today.toDateString());  // Example: "Sun Dec 1 2024"
console.log(today.toISOString());  // Example: "2024-12-01T00:00:00.000Z"
console.log(today.toLocaleDateString("en-US")); // Example: "12/1/2024"

Manipulating Date and Time

You can modify date components using setter methods:

  • setFullYear(), setMonth(), setDate()
  • setHours(), setMinutes(), setSeconds()

let eventDate = new Date();
eventDate.setFullYear(2025);
eventDate.setMonth(0); // January
eventDate.setDate(15);
console.log(eventDate.toDateString()); // Example: "Wed Jan 15 2025"

Advanced Date Operations

Use Date.now() to get the current timestamp in milliseconds since January 1, 1970.


let timestamp = Date.now();
console.log(timestamp); // Example: 1704067200000

To calculate date differences, subtract two Date objects.


let date1 = new Date("2024-12-01");
let date2 = new Date("2024-12-10");
let difference = date2 - date1; // Difference in milliseconds
console.log(difference / (1000 * 60 * 60 * 24)); // Days: 9
