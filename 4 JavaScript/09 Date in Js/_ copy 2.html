JavaScript Date and Time: Comprehensive Notes

Master Date and Time Manipulation in JavaScript

1. Introduction

JavaScript's Date object allows developers to work with dates and times. It can represent a specific date, time, or a moment in time down to the millisecond. All date objects store time in milliseconds since the Unix Epoch (January 1, 1970, 00:00:00 UTC).

2. Creating Date Objects

Here are the common ways to create dates in JavaScript:

  • Current Date and Time: new Date()
  • Specific Date String: new Date("YYYY-MM-DD")
  • Date Components: new Date(year, month, day, hours, minutes, seconds, milliseconds)
  • Milliseconds since Epoch: new Date(milliseconds)

Example:

// Current Date
const now = new Date();

// Specific Date
const specificDate = new Date("2024-12-02");

// Components Date
const componentsDate = new Date(2024, 11, 2, 15, 30, 45);

// Epoch Milliseconds
const epochDate = new Date(0);

3. Retrieving Date Components

You can retrieve specific parts of a date using these methods:

Method Description Example
getFullYear() Returns the 4-digit year. 2024
getMonth() Returns the month (0-11). 11 (December)
getDate() Returns the day of the month (1-31). 2
getHours() Returns the hour (0-23). 15

4. Formatting Dates

Use these methods to format a date:

  • toDateString(): Converts the date to a readable string.
  • toLocaleDateString(): Converts to a locale-specific date format.
  • toISOString(): Converts to ISO 8601 format.
// Example
const today = new Date();
console.log(today.toDateString());    // "Mon Dec 02 2024"
console.log(today.toLocaleDateString()); // "12/2/2024"
console.log(today.toISOString());    // "2024-12-02T10:30:45.000Z"
