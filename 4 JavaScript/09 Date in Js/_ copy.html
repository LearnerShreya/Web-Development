JavaScript Date and Time Notes

Introduction

The JavaScript Date object is a powerful tool for working with dates and times. It offers methods for creating, retrieving, and manipulating date and time values.

Creating Date Objects

Here are some ways to create date objects:

Method Example Output
Current Date and Time new Date() Current date and time
Specific Date new Date("2024-12-01") 1st December 2024
Year, Month, Day new Date(2024, 11, 1) 1st December 2024

Working with Date Components

Retrieve specific parts of a date:

  • getFullYear(): Returns the year.
  • getMonth(): Returns the month (0-based).
  • getDate(): Returns the day of the month.

Formatting Dates

JavaScript provides methods to format dates:

  • toDateString(): Returns a readable date string.
  • toISOString(): Returns the date in ISO format.

let today = new Date();
console.log(today.toDateString());  // "Sun Dec 1 2024"
console.log(today.toISOString());  // "2024-12-01T00:00:00.000Z"

Manipulating Dates

Use setter methods to change date components:

  • setFullYear(): Changes the year.
  • setMonth(): Changes the month.
  • setDate(): Changes the day.
