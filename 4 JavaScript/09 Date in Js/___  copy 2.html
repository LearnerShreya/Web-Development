JavaScript Date Object Notes

Creating Dates

In JavaScript, the Date object is used to handle dates and times. Here are various ways to create a Date object:

  • Current Date and Time: 
    const now = new Date();

    Output: Fri Dec 03 2024 10:00:00 GMT+0530 (India Standard Time)

  • Specific Date: 
    const specificDate = new Date(2024, 10, 29);

    Output: Fri Nov 29 2024 00:00:00 GMT+0530 (India Standard Time)

  • Date from String: 
    const dateFromString = new Date("2024-11-29");

    Output: Fri Nov 29 2024 00:00:00 GMT+0530 (India Standard Time)

  • Using Timestamps: 
    const fromTimestamp = new Date(1732845690000);

    Output: Fri Nov 29 2024 10:34:50 GMT+0530 (India Standard Time)

Accessing Date & Time Components

You can access specific components of a date using methods:

  • now.getFullYear(); – Returns the year.

    • Output: 2024

  • now.getMonth(); – Returns the month (0-11, 0 = January).

    • Output: 11

  • now.getDate(); – Returns the day of the month (1-31).

    • Output: 3

  • now.getDay(); – Returns the day of the week (0-6, 0 = Sunday).

    • Output: 2 (Tuesday)

  • now.getHours(); – Returns the hour (0-23).

    • Output: 10

  • now.getMinutes(); – Returns the minutes (0-59).

    • Output: 0

  • now.getSeconds(); – Returns the seconds (0-59).

    • Output: 0

Setting Date Components

You can modify the components of a date using set methods:


const date = new Date();
date.setFullYear(2030);
date.setMonth(5);
date.setDate(15);
date.setHours(10);
date.setMinutes(45);
date.setSeconds(30);
console.log(date);

Output: Sat Jun 15 2030 10:45:30 GMT+0530 (India Standard Time)

Formatting Dates

JavaScript provides various methods to format a date:

  • date.toString(); – Full string representation.

    • Output: Fri Nov 29 2024 10:30:00 GMT+0530 (India Standard Time)

  • date.toISOString(); – ISO format.

    • Output: 2024-11-29T05:00:00.000Z

  • date.toUTCString(); – UTC format.

    • Output: Fri, 29 Nov 2024 05:00:00 GMT

  • date.toLocaleDateString(); – Locale-specific date.

    • Output: 11/29/2024

  • date.toLocaleTimeString(); – Locale-specific time.

    • Output: 10:30:00 AM

Date Calculations

You can perform arithmetic operations on dates:

  • Difference Between Dates: 
    
const date1 = new Date("2024-11-01");
const date2 = new Date("2024-11-29");
const difference = date2 - date1;
console.log(difference / (1000 * 60 * 60 * 24));

    Output: 28 days

  • Add Days to a Date: 
    
const date = new Date();
date.setDate(date.getDate() + 7);
console.log(date);

    Output: Tue Dec 10 2024 10:00:00 GMT+0530 (India Standard Time)
