JavaScript Date Object Notes

Creating Dates

  • Current Date and Time: const now = new Date();
  • Specific Date: const specificDate = new Date(2024, 10, 29);
  • Date from String: const dateFromString = new Date("2024-11-29");
  • Using Timestamps: const fromTimestamp = new Date(1732845690000);

Accessing Date & Time Components

  • Year: now.getFullYear();
  • Month (0-11, 0 = January): now.getMonth();
  • Day of the Month (1-31): now.getDate();
  • Day of the Week (0-6, 0 = Sunday): now.getDay();
  • Hour (0-23): now.getHours();
  • Minutes (0-59): now.getMinutes();
  • Seconds (0-59): now.getSeconds();
  • Milliseconds (0-999): now.getMilliseconds();

Setting Date Components

  • Set Year: date.setFullYear(2030);
  • Set Month (0 = January): date.setMonth(5);
  • Set Day of the Month: date.setDate(15);
  • Set Hour: date.setHours(10);
  • Set Minutes: date.setMinutes(45);
  • Set Seconds: date.setSeconds(30);

Example: console.log(date); (Displays the modified date)

Formatting Dates

  • Full String: date.toString(); e.g., Fri Nov 29 2024 10:30:00 GMT+0530 (India Standard Time)
  • ISO Format: date.toISOString(); e.g., 2024-11-29T05:00:00.000Z
  • UTC Format: date.toUTCString(); e.g., Fri, 29 Nov 2024 05:00:00 GMT
  • Locale Date: date.toLocaleDateString(); e.g., 11/29/2024
  • Locale Time: date.toLocaleTimeString(); e.g., 10:30:00 AM
  • Locale Date & Time: date.toLocaleString(); e.g., 11/29/2024, 10:30:00 AM

Another way to create a date: new Date(year, month, day, hours, minutes, seconds, milliseconds);

Date Calculations

  • Difference Between Two Dates: 
    
const date1 = new Date("2024-11-01");
const date2 = new Date("2024-11-29");
const difference = date2 - date1; // Difference in milliseconds
  • Add Days to a Date: 
    
date.setDate(date.getDate() + 7);
console.log(date); // Updated date after adding 7 days
