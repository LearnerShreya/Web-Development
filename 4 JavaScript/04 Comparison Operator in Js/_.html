JavaScript Comparison and Logical Operators with Examples

1. Loose Equality (==) and Strict Equality (===)

let a1 = 2;
let a2 = "2";
console.log(a1 == a2); // true (loose equality checks value only)
console.log(a1 === a2); // false (strict equality checks value and type)

Reason: Loose equality converts both operands to the same type before comparing, while strict equality does not.

2. Relational Operators

console.log(a1 >= a2); // true
console.log(a1 <= a2); // true
console.log(a1 > a2);  // false
console.log(a1 < a2);  // false

Reason: Relational operators automatically convert the string "2" to a number for comparison.

3. Inequality Operators

console.log(a1 != a2);  // false (value is the same after type coercion)
console.log(a1 !== a2); // true (strict inequality checks type and value)

Reason: Loose inequality compares values only, while strict inequality checks both type and value.

4. null and undefined

console.log(null === undefined); // false
console.log(null == undefined);  // true
console.log(null != undefined);  // false

Reason: null is loosely equivalent to undefined, but they are not strictly equal.

console.log(null === 0);  // false
console.log(null !== 0);  // true
console.log(null == 0);   // false
console.log(null != 0);   // true
console.log(null < 0);    // false
console.log(null > 0);    // false
console.log(null <= 0);   // true
console.log(null >= 0);   // true

Reason: Comparisons involving null convert it to 0 for relational comparisons, except for equality checks.

5. undefined and Comparisons

console.log(undefined === 0); // false
console.log(undefined !== 0); // true
console.log(undefined == 0);  // false
console.log(undefined != 0);  // true
console.log(undefined < 0);   // false
console.log(undefined > 0);   // false
console.log(undefined <= 0);  // false
console.log(undefined >= 0);  // false

Reason: undefined is not equivalent to any value and cannot be meaningfully compared to numbers.

6. Special Case: NaN

console.log(NaN == NaN); // false

Reason: NaN is not equal to itself.

7. String to Number Conversion

let str3 = "Rohit";
let str4 = "Mohit";
console.log(Number(str3)); // NaN
console.log(Number(str4)); // NaN
console.log(Number(str3) == Number(str4)); // false

Reason: Non-numeric strings convert to NaN, which is not equal to any value, including itself.

8. Chained Comparisons

let abc1 = 123;
let abc2 = "123";
let abc3 = 123;
let abc4 = true;
console.log(abc1 == abc2); // true
console.log(abc1 == abc2 == abc3); // false
console.log(abc1 == abc2 == abc4); // true

Reason: Chained comparisons are evaluated left-to-right. The second comparison checks a boolean against a number.

9. Logical Operators

let age = 18;
let money = 420;
console.log(age >= 18 && money > 200); // true
console.log(age < 18 || money > 200);  // true
console.log(!(age > 10));              // false

Reason: Logical operators return true or false based on the conditions provided.

10. Bitwise Operators

console.log(4 & 5);   // 4 (0100 & 0101 = 0100)
console.log(11 & 14); // 10 (1011 & 1110 = 1010)
console.log(11 | 14); // 15 (1011 | 1110 = 1111)
console.log(5 ^ 7);   // 2 (0101 ^ 0111 = 0010)
console.log(5 << 3);  // 40 (5 * 2^3 = 40)
console.log(5 >> 2);  // 1 (5 / 2^2 = 1)

Reason: Bitwise operators work at the binary level, applying logical operations to individual bits.
