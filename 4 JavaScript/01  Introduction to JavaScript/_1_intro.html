Introduction to JavaScript

JavaScript is a versatile, high-level programming language primarily used for creating dynamic and interactive content on web pages. It is one of the core technologies of the web alongside HTML and CSS.

Basic Syntax and Examples

1. Output to the Console

Use console.log() to print messages or data to the browser console:

console.log("Hello, World!");

2. Declaring Variables

JavaScript provides three ways to declare variables:

  • let: Block-scoped, can be updated but not re-declared within the same scope.
  • const: Block-scoped, cannot be updated or re-declared.
  • var: Function-scoped, can be updated and re-declared (considered outdated).

Characteristics of Block Scope

  • Variables defined with let and const inside a block cannot be accessed outside of it.
  • Each block has its own independent scope.
  • Variables declared with var are function-scoped, not block-scoped. Hence, they can "leak" out of a block.

When to Use Block Scope

  • let is preferred when you need a variable whose value will change but want to limit its scope.
  • const is preferred when you need a variable whose value should remain constant within a block.
  • By using block scope with let and const, you avoid unexpected behaviors caused by variable leakage, making your code more robust and predictable.

Examples of Block Scope

  1. let and const are Block-Scoped:
    2. { let x = 10; // Block-scoped variable
    const y = 20; // Block-scoped constant
    console.log(x); // 10
    console.log(y); // 20
    }
    // Outside the block:
    console.log(x); // Error: x is not defined
    console.log(y); // Error: y is not defined
  2. var is Not Block-Scoped:
    3. {
    var z = 30; // Function-scoped variable
    console.log(z); // 30
    }
    console.log(z); // 30 (accessible outside the block)

Examples:

// Using 'let': Block-scoped, can be updated but cannot be re-declared in the same scope
let num = 10; // Declaring a variable 'num' using let
console.log(num); // Output: 10

let ar = "Shreya"; // Declaring a variable 'ar' using let
console.log(ar); // Output: Shreya

ar = "Shrey"; // Updating the value of 'ar'
console.log(ar); // Output: Shrey

// Attempting to re-declare 'ar' using let within the same scope
// This will throw a SyntaxError: Identifier 'ar' has already been declared
// Uncommenting the below lines will cause an error
// let ar = "Seru";
// console.log(ar);

// Using 'const': Block-scoped, cannot be updated or re-declared
const ids = 20; // Declaring a constant 'ids' using const
console.log(ids); // Output: 20

// Attempting to update a 'const' variable will throw a TypeError
// Uncommenting the below line will cause an error
// ids = 30;
// console.log(ids);

// Using 'var': Function-scoped, can be updated and re-declared
var x = 10; // Declaring a variable 'x' using var
x = 20; // Updating the value of 'x'
console.log(x); // Output: 20

3. Comments

Comments are ignored by the JavaScript engine and help document your code:

  • // for single-line comments.
  • /* ... */ for multi-line comments.
// This is a single-line comment
/* This is a
multi-line comment */

Why Learn JavaScript?

  • It's essential for web development.
  • Enables interactive and dynamic user interfaces.
  • Used in modern frameworks like React, Angular, and Vue.
  • Works on both frontend and backend (e.g., Node.js).

Start Practicing!

Open your browser's developer tools (usually F12) to access the console, and start experimenting with the examples provided above.
