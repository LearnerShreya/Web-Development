Comprehensive JavaScript Notes for Beginners

1. How Variables are Stored

What is a Variable?

A variable is like a labeled box in memory that holds data you can use and update in your program. For example, storing your name, age, or a list of items.

How are Variables Stored?

  • When you declare a variable in JavaScript, the program reserves space for it in memory.
  • Memory is allocated based on the type of data stored: simple (primitive) or complex (non-primitive).

Types of Variable Storage

  • Primitive Data: Stored directly in the memory (stack). Examples include numbers, strings, and booleans.
  • Non-Primitive Data: Stored in the heap, with a reference (pointer) stored in the stack. Examples include objects, arrays, and functions.

Example:

let age = 25; // Primitive: value directly stored in memory
let person = { name: "Shreya" }; // Non-Primitive: reference to object stored

2. Memory Allocation

What is Memory Allocation?

Memory allocation is the process of assigning memory space for variables and programs to run.

How Does JavaScript Allocate Memory?

  • Stack: Quick access memory for storing primitive data types and references.
  • Heap: Larger, slower memory area for storing complex objects like arrays or functions.

Why Does This Matter?

Understanding memory allocation helps avoid issues like memory leaks, where unused objects take up memory unnecessarily.

Example:

let x = 42; // Stored in stack
let obj = { name: "Shreya" }; // Object in heap, reference in stack

3. Types of Memory

  • Primary Memory: Fast and temporary memory, like RAM, used during program execution.
  • Secondary Memory: Permanent storage like SSDs and HDDs for long-term data.
  • Cache: A small, fast memory for frequently accessed data, improving speed.

4. SSD vs HDD in Simple Terms

What Are They?

  • SSD (Solid State Drive): Like a USB pen drive with no moving parts. Faster, more reliable, and consumes less power.
  • HDD (Hard Disk Drive): Like a spinning record player. Slower but cheaper with larger storage capacity.

Why is This Important?

SSD improves speed for coding tasks and file transfers, while HDD is useful for large-scale storage on a budget.

5. Data Types in JavaScript

What Are Data Types?

Data types define the kind of data a variable can store. JavaScript has two main categories:

  • Primitive Data Types: Single values, like numbers or strings.
  • Non-Primitive Data Types: Complex structures, like objects or arrays.

Primitive Data Types

  • Number: Holds any numerical value. Example: let age = 25;
  • String: Holds text. Example: let name = "Shreya";
  • Boolean: True or false values. Example: let isStudent = true;
  • Null: Represents an empty value. Example: let value = null;
  • Undefined: Variable declared but not assigned a value. Example: let x;
  • Symbol: Unique, immutable identifiers. Rarely used.
  • BigInt: For numbers larger than 2^53-1. Example: let big = 123456789123456789n;

Non-Primitive Data Types

  • Object: Key-value pairs. Example: let person = { name: "Shreya", age: 20 };
  • Array: Ordered lists. Example: let colors = ["red", "blue", "green"];
  • Function: Reusable blocks of code. Example: function greet() { alert("Hi!"); }

6. Semicolons in JavaScript

Do You Need Them?

JavaScript uses Automatic Semicolon Insertion (ASI), so semicolons aren’t always necessary. However, adding semicolons avoids potential errors.

7. Single vs Double Quotes

What’s the Difference?

Both work the same. The choice is based on style preference. For example:

let name1 = "Shreya";
let name2 = 'Singh';

8. How Numbers Are Stored in JavaScript

What Are Numbers in JavaScript?

JavaScript uses a single data type for numbers, called Number. This means both whole numbers (e.g., 5, 42) and decimal numbers (e.g., 3.14, 0.1) are treated the same.

How Are Numbers Represented?

Numbers in JavaScript are stored using the IEEE 754 double-precision 64-bit format. This format divides each number into three parts:

  • Sign Bit (1 bit): Determines if the number is positive or negative.
  • Exponent (11 bits): Represents the scale or size of the number.
  • Mantissa (52 bits): Stores the actual digits of the number in binary form.

This structure lets JavaScript represent numbers as small as 5e-324 (a very tiny number) and as large as 1.8e+308 (a very large number).

Why Does JavaScript Store Numbers This Way?

JavaScript uses this format because it:

  • Allows efficient storage and calculation of a wide range of numbers.
  • Supports both whole numbers and decimals in one format.
  • Follows a standard used by most programming languages, making interoperability easier.

Common Issues with Numbers in JavaScript

Since JavaScript stores numbers using this system, it comes with some quirks:

  1. Precision Errors:

    Numbers with decimals (floating-point numbers) sometimes lose precision.

    
console.log(0.1 + 0.2); // Outputs: 0.30000000000000004

    This happens because some decimal numbers can't be represented perfectly in binary.

  2. Safe Integer Limit:

    JavaScript can only safely represent integers between -(2^53 - 1) and (2^53 - 1), which is about -9007199254740991 to 9007199254740991.

    
console.log(9007199254740991 + 1); // Outputs: 9007199254740992
console.log(9007199254740991 + 2); // Outputs: 9007199254740992 (wrong result)

    For numbers beyond this range, use BigInt.

  3. Infinity:

    If a number is too large or too small for JavaScript to handle, it will return Infinity or -Infinity.

How to Work Around These Issues?

Here are some ways to deal with JavaScript number quirks:

  • Use BigInt for Large Numbers: 
    
let bigNumber = 9007199254740991n + 2n;
console.log(bigNumber); // Outputs: 9007199254740993n
  • Fix Floating-Point Errors:

    Use rounding techniques or libraries like math.js for precise calculations.

    
console.log((0.1 + 0.2).toFixed(2)); // Outputs: 0.30

Key Takeaways

  • All numbers in JavaScript are stored in a single data type called Number, using a 64-bit format.
  • Precision errors and safe integer limits are common issues to watch out for.
  • Use BigInt or rounding techniques to handle these limitations.

JavaScript Notes - Data Types

1. Variable Declaration

Variables are declared using the let keyword. Attempting to redeclare the same variable results in an error.

2. Primitive Data Types

Number

Numbers represent any kind of numeric value. Example: let account_balamce = 7654321;

String

A string is a sequence of characters, enclosed in quotes. Example: let balamce = "Seventy-six lakh fifty-four thousand three hundred twenty-one rupees";

Boolean

A boolean represents either true or false. Example: let insta_pe_dash_ko_block_kara_hai = false;

Undefined

A variable declared but not assigned a value has an undefined value. Example: let account;

Null

null represents the intentional absence of any object value. Example: let bal = null;

BigInt

BigInt is used to represent numbers larger than Number. BigInt values are denoted by appending n to the number. Example: let b = 43769576213575487698765n;

3. Non-Primitive Data Types

Non-primitive data types include arrays, objects, and functions.
