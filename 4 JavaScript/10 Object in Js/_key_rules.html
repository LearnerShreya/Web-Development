Rules for Writing Keys of an Object in JavaScript

1. Key Types

Keys in JavaScript objects are always strings or symbols. If you use a non-string key (e.g., a number or an object), it will automatically be converted to a string.

let obj = {
    1: "value1",       // Numeric key is converted to a string ("1").
    true: "value2"     // Boolean key is converted to a string ("true").
};
console.log(obj["1"]); // "value1"
console.log(obj["true"]); // "value2"

2. Quotes Around Keys

Keys can be written with or without quotes:

  • Without Quotes: If the key is a valid identifier (alphanumeric, underscores, no spaces).
  • With Quotes: If the key contains spaces, special characters, or starts with a number.
let obj = {
    name: "John",          // Valid identifier, no quotes needed.
    "first name": "John",  // Contains a space, must be in quotes.
    "123key": "value"      // Starts with a number, must be in quotes.
};

3. Uniqueness

Each key in an object must be unique. If duplicate keys are defined, the last one will overwrite previous entries.

let obj = {
    key: "value1",
    key: "value2" // Overwrites the first key-value pair.
};
console.log(obj.key); // "value2"

4. Reserved Keywords

Object keys can use reserved JavaScript keywords (e.g., class, return), but it’s better to avoid them for clarity.

let obj = {
    class: "A",    // Valid, but can be confusing.
    return: "yes"  // Valid as a key.
};
console.log(obj.class); // "A"

5. Symbols as Keys

Symbols can also be used as unique object keys. Symbol keys do not conflict with string keys.

let sym = Symbol("uniqueKey");
let obj = {
    [sym]: "value"
};
console.log(obj[sym]); // "value"

6. Dynamic Keys

You can use square brackets [] to create dynamic keys in objects.

let keyName = "dynamicKey";
let obj = {
    [keyName]: "value"
};
console.log(obj.dynamicKey); // "value"

By following these rules, you can effectively define and manage object keys in JavaScript.
