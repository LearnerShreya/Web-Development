Shallow Copy vs Deep Copy

Shallow Copy

A shallow copy creates a new object but only copies the references of nested objects instead of duplicating them. As a result, changes made to the nested objects in the copied object reflect in the original object.

  • Shallow copies are faster but less safe when working with nested data.
  • Common methods for shallow copying include using the spread operator (...) or Object.assign().
  • It is commonly used when deep copying is not necessary, and data sharing between objects is intended.

Example:

    
const original = { name: "Shreya", details: { age: 21 } };
const shallowCopy = { ...original }; // Shallow copy using spread operator

shallowCopy.details.age = 22; // Changes in nested object reflect in original
console.log(original.details.age); // Outputs: 22

Deep Copy

A deep copy creates a completely independent copy of an object, including all nested objects. Changes to the copied object do not affect the original object.

  • Deep copies ensure data safety for nested structures.
  • Common methods include using JSON.parse(JSON.stringify()) or utility libraries like Lodash.
  • It is suitable when complete isolation between the original and copied data is required.

Example:

    
const original = { name: "Shreya", details: { age: 21 } };
const deepCopy = JSON.parse(JSON.stringify(original)); // Deep copy using JSON

deepCopy.details.age = 22; // Changes in copied object do not affect the original
console.log(original.details.age); // Outputs: 21

Constructor and Destructor

Constructor

A constructor is a special method in a class that is automatically invoked when an object is created. Its purpose is to initialize object properties and perform any setup required during object creation.

  • Automatically called when creating an object of the class.
  • Typically used to set default values or initialize properties.
  • In some languages, constructors can be overloaded to handle different initializations.

Example in JavaScript:

    
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  display() {
    console.log(`Name: ${this.name}, Age: ${this.age}`);
  }
}

const person1 = new Person("Shreya", 21); // Constructor called automatically
person1.display(); // Outputs: Name: Shreya, Age: 21

Destructor

A destructor is a special method used in some programming languages (e.g., C++) to clean up resources (like memory or file handles) when an object is destroyed or goes out of scope. While JavaScript doesn't have destructors, you can simulate resource cleanup using custom methods or hooks.

  • In C++, destructors are called automatically when an object goes out of scope.
  • In JavaScript, cleanup is typically handled using event listeners or cleanup functions.
  • Destructors are particularly useful in resource-intensive applications like file handling and database connections.

Example in C++:

    
#include 
using namespace std;

class Person {
public:
  Person() {
    cout << "Constructor called" << endl;
  }
  ~Person() {
    cout << "Destructor called" << endl;
  }
};

int main() {
  Person p; // Constructor is called
} // Destructor is called automatically when 'p' goes out of scope
