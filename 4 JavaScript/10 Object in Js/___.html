JavaScript Objects - Comprehensive Notes

1. Creating Objects

1.1 Object Literal Syntax

The object literal is the simplest and most common way to create an object. It's useful for defining a single object with known properties.

    
const car = {
  brand: "Toyota",
  model: "Corolla",
  year: 2020
};
console.log(car);

Output:

    
{ brand: 'Toyota', model: 'Corolla', year: 2020 }

1.2 Using the new Object() Syntax

This syntax creates an object using the built-in Object constructor. Properties are added to the object one by one.

    
const car = new Object();
car.brand = "Toyota";
car.model = "Corolla";
car.year = 2020;
console.log(car);

Output:

    
{ brand: 'Toyota', model: 'Corolla', year: 2020 }

1.3 Using Class Syntax

The class syntax is a more structured and scalable way to create objects, especially for multiple instances of the same type.

    
class Car {
  constructor(brand, model, year) {
    this.brand = brand;
    this.model = model;
    this.year = year;
  }
}
const myCar = new Car("Ford", "Mustang", 2021);
console.log(myCar);

Output:

    
Car { brand: 'Ford', model: 'Mustang', year: 2021 }

2. Accessing Object Properties

2.1 Dot Notation

Dot notation is the most straightforward way to access object properties.

    
console.log(car.brand); // Outputs: Toyota

2.2 Square Bracket Notation

Square brackets allow access to properties using strings or variables.

    
console.log(car["model"]); // Outputs: Corolla

2.3 Special Cases

Properties with special characters, numbers, or reserved words require square brackets.

    
const obj = { 123: "number", null: "null", undefined: "undefined" };
console.log(obj[123]); // Outputs: number
console.log(obj["null"]); // Outputs: null

2.4 Computed Property Names

Dynamic property names can be computed using square brackets.

    
const key = "name";
const person = { [key]: "Shreya" };
console.log(person.name); // Outputs: Shreya

3. Common Methods for Objects

3.1 Object.keys()

Returns an array of an object's property names.

    
console.log(Object.keys(car)); // Outputs: [ 'brand', 'model', 'year' ]

3.2 Object.values()

Returns an array of an object's property values.

    
console.log(Object.values(car)); // Outputs: [ 'Toyota', 'Corolla', 2020 ]

3.3 Object.entries()

Returns an array of key-value pairs from an object.

    
console.log(Object.entries(car));
// Outputs: [ ['brand', 'Toyota'], ['model', 'Corolla'], ['year', 2020] ]

3.4 Object.assign()

Merges one or more source objects into a target object.

    
const target = { a: 1 };
const source = { b: 2 };
Object.assign(target, source);
console.log(target); // Outputs: { a: 1, b: 2 }

3.5 Object.freeze()

Prevents modifications to an object.

    
Object.freeze(car);
car.year = 2021; // No effect
console.log(car.year); // Outputs: 2020

3.6 Object.seal()

Allows modification of existing properties but prevents adding or removing properties.

    
Object.seal(car);
car.brand = "Honda"; // Allowed
car.color = "red"; // Not allowed
console.log(car);

4. Nested Objects

Objects can have other objects as their values.

    
const car = {
  brand: "Toyota",
  details: {
    model: "Corolla",
    year: 2020
  }
};
console.log(car.details.model); // Outputs: Corolla

5. Destructuring

Destructuring simplifies extracting properties into variables.

    
const { brand, details: { model } } = car;
console.log(brand, model); // Outputs: Toyota Corolla

6. Spread Operator

The spread operator is useful for copying or merging objects.

    
const carCopy = { ...car };
console.log(carCopy);
