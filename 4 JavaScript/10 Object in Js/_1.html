JavaScript Objects and Arrays

Creating an Object

Objects store data in key-value pairs. Here's an example of creating an object:

const obj = {
    0: 20,
    1: 50,
    2: 70,
    name: "Shreya",
    account_balance: 987654321,
    gender: "Female",
    "age": 30,
    "account number": 73569156
};

Notes:

  • Keys like name, account_balance, gender, and age are strings, not variables.
  • Keys with spaces (e.g., "account number") must be accessed using square bracket notation.

Accessing Object Properties

console.log(typeof obj);             // Outputs: "object"
console.log(obj.name);               // Outputs: "Shreya"
console.log(obj.age);                // Outputs: 30
console.log(obj.gender);             // Outputs: "Female"
// console.log(obj[gender]);        // Wrong: ReferenceError
console.log(obj["gender"]);        // Right: Outputs "Female"
console.log(obj["name"]);          // Right: Outputs "Shreya"
console.log(obj["account number"]);// Outputs: 73569156
console.log(obj[0]);                // Outputs: 20
console.log(obj);                   // Outputs the full object

Creating an Array

Here's an example of creating an array:

const arr = ["Shreya", 987654321, "Female", 30];
console.log(arr); // Outputs: ["Shreya", 987654321, "Female", 30]

Another Object Example

Accessing Array and Object Elements

console.log(obj[0]); // Outputs: 20
console.log(obj[1]); // Outputs: 50
console.log(obj[2]); // Outputs: 70

console.log(arr[0]); // Outputs: "Shreya"
console.log(arr[1]); // Outputs: 987654321
console.log(arr[2]); // Outputs: "Female"

By following these examples, you can create and work with objects and arrays in JavaScript effectively.
