Comprehensive Notes on JavaScript Arrays

1. One-Dimensional Arrays

A one-dimensional array is a simple list of elements. It is the most basic form of an array in JavaScript.

Key Points:

  • Declared using square brackets [].
  • Indexing starts from 0 (zero-based indexing).
  • Elements can be accessed using their index.

Example:

let arr = [10, 20, 30, 40, 50];
console.log(arr);         // Output: [10, 20, 30, 40, 50]
console.log(arr[2]);      // Access third element: 30
💡 Arrays can store multiple data types, e.g., let arr = [1, "text", true];

2. Two-Dimensional Arrays (Matrix Representation)

A 2D array is an array of arrays, useful for representing tabular data or matrices.

Key Points:

  • Each element of a 2D array is an array itself.
  • Access elements using two indices: arr[row][column].

Example:

let matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
console.log(matrix[1]);     // Output: [4, 5, 6] (second row)
console.log(matrix[1][2]);  // Output: 6 (third element of second row)
💡 Use 2D arrays for grids, spreadsheets, or chess boards.

3. Three-Dimensional Arrays

A 3D array extends the concept of 2D arrays by nesting arrays within arrays.

Key Points:

  • Useful for representing complex data structures like cubes.
  • Access elements using three indices: arr[layer][row][column].

Example:

let arr3D = [
    [[1, 2], [3, 4]],
    [[5, 6], [7, 8]]
];
console.log(arr3D[1][0][1]); // Output: 6 (second layer, first row, second column)

4. Flattening Arrays

Flattening converts multi-dimensional arrays into a one-dimensional array.

Key Points:

  • Use arr.flat(level) to flatten an array up to the specified depth.
  • level = 1 by default.
  • Use Infinity to flatten deeply nested arrays.

Example:

let nestedArray = [[1, 2], [3, [4, 5]]];
console.log(nestedArray.flat());         // Output: [1, 2, 3, [4, 5]]
console.log(nestedArray.flat(Infinity)); // Output: [1, 2, 3, 4, 5]

5. Checking Array Type

JavaScript arrays are objects, but there are specific ways to check if a variable is an array.

Methods:

  • typeof arr: Returns "object".
  • Array.isArray(arr): Returns true for arrays.

Example:

let sample = [1, 2, 3];
console.log(typeof sample);         // Output: "object"
console.log(Array.isArray(sample)); // Output: true
⚠️ Always prefer Array.isArray() for checking arrays.

6. Creating Arrays Using the Array Constructor

The Array constructor creates arrays but can behave unpredictably with a single argument.

Key Points:

  • Use new Array(value1, value2, ...) for multiple values.
  • Single argument creates an empty array of that length.

Example:

let arr1 = new Array(1, 2, 3);
console.log(arr1); // Output: [1, 2, 3]

let arr2 = new Array(5);
console.log(arr2); // Output: [ <5 empty slots> ]
💡 Prefer literal syntax [] over new Array() for clarity.

7. Memory Considerations for Arrays

JavaScript arrays are dynamic and non-contiguous, unlike low-level arrays in C/C++.

Advantages:

  • Can store mixed data types.
  • Flexible sizing and dynamic allocation.

Tradeoffs:

  • Slower access speed compared to C/C++ arrays.
  • Uses more memory due to non-contiguous storage.
