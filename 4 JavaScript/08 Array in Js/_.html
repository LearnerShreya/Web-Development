JavaScript Arrays - Topics and Subtopics

Array Methods

  • length: Number of elements in the array.
  • push(): Adds an element at the end.
  • pop(): Removes the last element.
  • unshift(): Adds an element at the beginning.
  • shift(): Removes the first element.
  • indexOf(): Returns the index of the first occurrence of an element.
  • includes(): Checks if an element exists in the array.
  • slice(): Extracts a portion of the array without modifying it.
  • splice(): Modifies an array by adding, removing, or replacing elements.
  • toString(): Converts an array to a string of comma-separated values.
  • at(): ES2022 introduced this method to access elements with negative indexing.
  • join(): Joins all array elements into a string.
  • concat(): Creates a new array by merging (concatenating) existing arrays.
  • flat(): Creates a new array with sub-array elements concatenated to a specified depth.
