Comprehensive Notes on JavaScript Arrays

1. Array Initialization

JavaScript arrays are versatile and can store elements of various data types, such as numbers, strings, booleans, and even objects.

const arr = [2, 35, 1, 8, "rohit", true];
  • Access Elements: Use square brackets or the .at() method.
    • arr[0]: Access the first element (Output: 2).
    • arr.at(-1): Access the last element (Output: true).
  • Array Length: Use the .length property to get the total number of elements. 
    console.log(arr.length); // Output: 6

2. Reference Copying

When assigning one array to another variable, they both reference the same memory location. Any changes made to one array reflect in the other.

const newarr = arr;
console.log(arr == newarr); // True
Key Point: This is a shallow copy. To create an independent copy, use cloning methods like structuredClone().

3. Array Comparison

In JavaScript, arrays are compared by reference, not by value. Two arrays with identical elements are considered unequal unless they reference the same memory location.

const ar1 = [1, 2, 3];
const ar2 = [1, 2, 3];
console.log(ar1 == ar2); // Output: False
  • Deep Copy: Use structuredClone() for creating an independent copy. 
    const clone = structuredClone(ar2);
console.log(clone == ar2); // Output: False

4. Array Modifications

JavaScript provides methods for adding, removing, and modifying elements in arrays.

Adding Elements

arr.push(30); // Adds to the end
arr.unshift(100); // Adds to the beginning

Removing Elements

arr.pop(); // Removes the last element
arr.shift(); // Removes the first element

Deleting Elements

delete removes an element but leaves an empty slot.

delete arr[0];
console.log(arr); // Output: [empty, 35, 1, 8, "rohit", true]

5. Search Operations

  • Find Index: Use indexOf or lastIndexOf to locate elements. 
    arr.indexOf(1); // First index of '1'
  • Check Existence: Use includes(). 
    arr.includes(10); // Output: False

6. Slicing and Splicing

Slice

slice() extracts a portion of the array without modifying it.

const sliced = arr.slice(2, 4);
console.log(sliced); // Elements from index 2 to 3

Splice

splice() modifies the array by removing or replacing elements.

arr.splice(2, 3, "new1", "new2"); // Replace 3 elements at index 2

7. Array to String Conversion

Convert arrays to strings using toString or join.

arr.toString(); // Comma-separated string
arr.join(" * "); // Custom separator

8. Concatenating Arrays

Combine multiple arrays using concat().

const merged = arr1.concat(arr2, arr3);
console.log(merged);
Nested Arrays: Use push() to nest an array within another array.

Key Points

  • Arrays can store diverse data types and support extensive operations.
  • Array references affect equality and copying. Use structuredClone() for deep copies.
  • Methods like slice and splice offer flexible ways to manipulate arrays.
  • Searching methods include indexOf, lastIndexOf, and includes.
  • Use concat() for merging arrays and join() for creating strings.
