JavaScript Arrays: Detailed Notes

1. Array Initialization

Arrays in JavaScript can hold elements of different data types.

const arr = [2, 35, 1, 8, "rohit", true];
  • arr[0]: Access first element (output: 2).
  • arr.at(-1): Access last element using modern method (output: true).
  • arr.length: Total elements in the array (output: 6).

2. Reference Copying

When assigning an array to another variable, both reference the same memory location.

const newarr = arr;
  • arr == newarr: True, as both reference the same object.

3. Array Comparison

Arrays are compared by reference, not by value.


const ar1 = [1, 2, 3];
const ar2 = [1, 2, 3];
console.log(ar1 == ar2); // False
  • structuredClone(ar2): Creates a deep copy.

4. Array Modifications

Adding Elements

arr.push(30); // Adds to end
arr.unshift(100); // Adds to beginning

Removing Elements

arr.pop(); // Removes last element
arr.shift(); // Removes first element

Deleting Elements

delete arr[0] deletes the element but retains an empty slot.

5. Search Operations

Search for values in the array:

  • arr.indexOf(1): First index of 1.
  • arr.lastIndexOf(1): Last index of 1.
  • arr.includes(10): Checks for existence.

6. Slicing and Splicing

Slice

Extracts a portion of the array (non-destructive).

arr.slice(2, 4); // Extracts elements 2 to 3

Splice

Removes and optionally replaces elements (destructive).

arr.splice(2, 3, "new1", "new2");

7. Array to String Conversion

Convert arrays to strings:

arr.toString(); // Comma-separated string
arr.join(" * "); // Custom separator

8. Concatenating Arrays

Merge arrays:

let merged = arr1.concat(arr2, arr3);

Nested arrays:

arr1.push(arr3);

Key Points

  • Arrays can store elements of mixed types.
  • Array references affect comparison and copying.
  • Search methods include indexOf, lastIndexOf, and includes.
  • Use slice for non-destructive operations and splice for destructive modifications.
  • Concatenation and nesting are useful for combining arrays.
