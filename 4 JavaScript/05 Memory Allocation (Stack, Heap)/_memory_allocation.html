Memory Management in JavaScript

Understanding how JavaScript handles memory is crucial for efficient programming. Let's dive deep into concepts like Stack, Heap, Call by Value, Call by Reference, Mutable and Immutable objects, and how memory allocation and deletion work.

1. Stack

The stack is a linear memory structure used to store primitive values (number, string, boolean, etc.) and references to objects. Data in the stack is managed in a last in, first out (LIFO) manner.

Example:

let a = 10; // Stored in the stack
let b = a;    // Copy of 'a' is created in the stack
b = 20;
console.log(a); // Output: 10 (remains unchanged)

2. Heap

The heap is a large memory pool used for storing objects and dynamic data. Objects, arrays, and functions are allocated memory in the heap.

Example:

let obj1 = { name: "Shreya" }; // Memory allocated in the heap
let obj2 = obj1; // Reference to the same object
obj2.name = "Gaurav";
console.log(obj1.name); // Output: "Gaurav" (shared reference)

3. Call by Value

Call by Value means that when a variable is passed to a function, its value is copied, and any changes within the function do not affect the original variable.

Example:

function updateValue(val) {
    val = val + 10;
}
let num = 20;
updateValue(num);
console.log(num); // Output: 20 (unchanged)

4. Call by Reference

Call by Reference means passing a reference to the actual memory location. Changes made inside the function affect the original object.

Example:

function updateObject(obj) {
    obj.name = "Updated";
}
let myObj = { name: "Original" };
updateObject(myObj);
console.log(myObj.name); // Output: "Updated"

5. Mutable and Immutable

- Mutable: Objects whose state can be modified after creation (e.g., objects, arrays).
- Immutable: Objects that cannot be modified after creation (e.g., strings, numbers).

Example:

// Immutable
let str = "Hello";
str[0] = "h";
console.log(str); // Output: "Hello" (unchanged)

// Mutable
let arr = [1, 2, 3];
arr[0] = 99;
console.log(arr); // Output: [99, 2, 3]

6. Memory Allocation System

Memory is allocated in two steps:

  • Declaration: Space is reserved for the variable.
  • Initialization: Values are assigned to variables.

JavaScript uses garbage collection to free memory by removing unreferenced objects from the heap.

7. File or Folder Deletion

When a file or folder is deleted, it is marked as "free space" in the storage system. The actual data remains until it is overwritten by new data.

In a soft delete, the file is moved to a trash/recycle bin. In a hard delete, pointers to the data are removed.

Example:

// Deleting a file (pseudo-code)
fs.unlink('file.txt', (err) => {
    if (err) console.error("Error deleting file");
    else console.log("File deleted");
});

Key Points

  • Stack is faster but limited in size; used for primitives.
  • Heap is larger and used for complex data structures.
  • Call by Value does not affect the original variable.
  • Call by Reference modifies the original object.
  • Garbage collection handles unused memory.
  • Deleted files are not immediately erased but marked for reuse.

Stack vs Heap in Memory Management

In the context of memory management, the terms stack and heap refer to two different memory areas used by the system to manage data during program execution. This is different from data structures like stack and queue, which are logical structures used to organize and process data.

How Stack and Heap Work in Memory

Stack (Memory)

  • Linear, organized memory structure.
  • Handles static memory allocation.
  • Used for storing:
    • Primitive values (e.g., numbers, strings).
    • Function calls and their local variables.
  • Operates on a Last In, First Out (LIFO) basis.

Heap (Memory)

  • Unstructured and unordered memory space.
  • Handles dynamic memory allocation.
  • Used for storing:
    • Objects and arrays.
    • Complex or flexible data structures requiring variable sizes.
  • Managed by garbage collection in JavaScript to reclaim unused memory.

Difference Between Heap (Memory) and Queue (Data Structure)

  • Heap (Memory) is part of how the system allocates space for large or dynamic data.
  • Queue is a logical data structure that operates on a First In, First Out (FIFO) principle.

When discussing memory allocation, stack and heap are the correct terms because they describe how the program's data is managed at runtime, not the data structure used in code.
